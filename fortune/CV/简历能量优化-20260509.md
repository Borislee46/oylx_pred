# 简历能量优化 — 2027 投递版

> 从"天机太阴防守型堡垒" → "廉贞七杀进攻型堡垒"
> 保留所有可验证性，姿态从"请检验我"调整为"这就是我"

---

## 能量诊断

当前 v2 是**天机太阴**的简历：缜密、专业、防守严密。每个数字都有城墙，每个表述都有护城河。面试官打不穿。

但 2027 年进入子女宫大限（廉贞七杀擎羊）——需要**出击**能量。不是推翻重写，是在关键位置做能量转换。

| 维度 | 当前 (v2) | 目标 (v3) |
|------|----------|----------|
| 姿态 | "请检验我" | "这就是我，你看看合不合适" |
| 叙事 | 我做了什么 | 我做了什么 + 我为什么现在出现在市场上 |
| 动词 | 设计、搭建、构建 | 主导、决定、选择（保留设计/搭建的精确性） |
| 数字 | 部分缺 baseline | 全部可验证 |
| 空白 | 东莞纯空白（略像隐藏） | 一笔带过（主动叙事） |

---

## 具体改动清单

### 1. 顶部加方向声明

```
方向：搜索/推荐/教育科技 · 算法 DS（ML 全链路）
```

### 2. 自我评价拆成三行节奏

- 第一行：背景 + 定位（高代价低频决策场景）
- 第二行：证据（独立交付 + AB 实验）
- 第三行：为什么现在（战略转移叙事）

### 3. 数字审计

- "准确率提升 30%" → 补 baseline 或换表述
- "处理效率 +300%" → 补具体时间或删除

### 4. 字节段动词升级

- 加"主导""推动"等决策动词，主语从任务变成"我"

### 5. 东莞 — 一笔带过

- 一行：教学规模 + 离开原因（"因职业方向回归数据实践"）

### 6. 项目经验去重

- RAG 在"新东方·其他工作"和"项目经验"重复出现 → 删一处

### 7. 链接节

- 投递时 Blog/Demo 已上线 → 移到顶部
- 仍是占位符 → 删除（"说了一年还没做"的信号）

### 8. 可迁移性钩子

- 自我评价或新增位置埋一个信号：教育 ML 全链路 → 搜索/推荐场景的映射线索
- 不在简历展开，面试时讲

## 已落地

### 技术栈

- `resume.html` — 简历正文（语义化 HTML，日常改这个）
- `resume.css` — 排版/打印样式（A4，暖色 section 线，Chrome headless 兼容）
- `export_pdf.py` — 零依赖 PDF 导出（Chrome headless，支持 `--watch` 监控自动导出）
  - `python export_pdf.py` → 导出 `简历-李佳鹏-DS-2027.pdf`
  - `python export_pdf.py --open` → 浏览器预览
  - `python export_pdf.py --watch` → 改 HTML/CSS 自动重导
