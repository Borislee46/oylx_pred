# 整体设计原则

## 1. 关键词埋点策略

简历有两个读者：HR（6秒扫读）和面试官（2分钟精读）。

- **对 HR**：标题行（数据科学家）、公司名（字节跳动）、学校名（UNSW QS Top 50）、技术栈（XGBoost/Agent/RAG）
- **对面试官**：monotonic constraints、sigmoid calibration、5层调整链、NSGA-III、Sobol QMC——每个词你都真的写过代码，面试时能展开

## 2. 可验证性优先

原版"选校合理比例 30%→90%"是不可验证的——面试官追问一轮就穿帮。Brier Score 0.185 是标准指标，召回率 +8.2% 是字节 Libra 面板上能查到的。**每个数字都必须能回答"这个数字怎么算的"。**

## 3. 叙事密度不均

不是每段经历都一样重要。这份简历的资源分配是：
- 选校系统：40%（4 bullet + 每个都长）
- 字节搜索：25%（3 bullet）
- RAG + BI + CV Extractor：20%（各 1 bullet）
- 教育背景 + 自我评价：15%

这个比例直接反映了一件事：**你要面的是 DS 岗，你的选校系统就是你最重要的 DS 证据。**

## 4. 空白是信息

东莞城市学院不写 bullet、递归聚类项目整个砍掉——这不是在隐瞒，是在告诉面试官"我知道什么重要什么不重要"。能判断什么不用写，和能判断什么该写成，是同一种能力。
