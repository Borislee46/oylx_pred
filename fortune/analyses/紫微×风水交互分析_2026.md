## 一、方法论

### 1.1 为什么不能紫微+风水并排讲

紫微和风水共享一个核心假设：**能量有其位置、时间和强度**。区别在于：
- 紫微：能量在天上，按"出生时刻→十二宫→大限流年"映射到人生领域
- 风水：能量在地上，按"方位→飞星→空间功能"映射到日常生活

并排讲 = "命盘说X，风水说Y"。交互讲 = "命盘的X流到地上，被空间的Y塑形，最终表现成Z"。

### 1.2 交互公式

```
净效应 = 紫微信号强度 × 空间调节系数(K)

K > 1  → 空间放大信号（吉更吉/凶更凶）
K = 1  → 空间中性（信号原样传递）
K < 1  → 空间缓冲信号（凶被减半/吉被稀释）
K ≈ 0  → 空间几乎拦住信号的表达
```

### 1.3 空间调节的来源

空间调节系数K来自以下因素的乘积：

| 因素 | 说明 | 示例 |
|------|------|------|
| 方位相生克 | 星曜所在宫位的五行与方位五行的关系 | 酉宫金→兑宫金=同气相求，K>1 |
| 飞星叠加 | 流年飞星在对应方位的吉凶 | 5黄煞在正南→K>1(凶) |
| 空间功能 | 该空间拿来做什么 | 厕所压财帛宫→K<1(吉被压) |
| 物理结构 | 隔断/门窗/家具布局 | L型+隔断缓冲酉戌→K<1(凶被制) |
| 居住者本命 | 你的命盘与空间的五行交互 | 癸酉金入兑宫=本命位→K>1(制煞) |
| 作息节律 | 何时使用该空间 | 22:00睡→亥时来因宫被保护 |

## 六、2026.05.11 实地验证补充

> 以下发现来自实地回顾空间配置、宠物行为和已放置物品的五行反查。每条均基于原始数据+现场事实。

### 6.1 狗子的实际角色：比变压器更精准

**原分析(§二·课题1)**：狗卡在两人之间=变压器，土泄火生金，缓冲酉戌相害。

**实际情况**：狗不卡中间。晚上她搂着睡，白天关窝里。拉屎在窝、尿乱撒。

**五行重算**：

```
原框架: 狗(土)卡在酉(金)←→戌(火)之间

实际:   狗(土)直接被戌(火)抱着睡
        ↓
        土直接接触火源 → 泄火效率 = 最高
        ↓
        不是"变压器放两根电线中间"
        是"变压器直接贴在发电厂上"
```

**为什么"她不出门"效果更好**：
- 5黄煞在她卧室→出门=外部刺激→增加火输入→回家火更大
- 狗锚她在家里→外部刺激减少→火源输入降低
- 狗土持续泄火+减少新火输入=双路径降温

**代价评估**：拉屎在窝、乱尿——但不抵消狗的核心泄火功能。排泄正常代谢，不影响土泄火的五行本质。

**与原分析的偏差**：原分析说狗"在中间变压缓冲酉戌相害"。实际狗直接跑火源旁边去了——它不是工程师，是消防员。灭火效率更高。
