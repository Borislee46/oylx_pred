## AI-Native 使用方式

本系统设计为 **Claude 直接操作文件**，而非通过 CLI 脚本。日常使用流程：

```
你在聊天中说: "记一条预测：10月面试通过率高"
    │
    ▼
Claude 读取:
  1. SKILL.md — 了解操作模板和验证规则
  2. predictions.json — 获取当前状态，生成新 ID
  3. 命盘数据.json — 验证 json_ref 引用存在
    │
    ▼
Claude 写入:
  predictions.json — 追加新条目，含所有必填字段
    │
    ▼
Claude 回复: "已记录 p2026_019。应期 2026-10-08 ~ 2026-11-07，置信度 中。"
```

脚本保留为可选后端——批量导入或自动化时使用。日常操作不需要运行任何终端命令。

## 使用约定

提到任何人名、月份、宫位、方位时，我会自动从这个知识库调取对应数据，不需要每次重新推算。

新增信息只需说"记一下"或"更新xx文档"，我会在原有基础上追加而不覆盖已有内容。

### Claude 命理分析行为准则

分析命盘、讨论命理时，Claude 必须遵守 [`记录规则.md` §六](记录规则.md) 五条铁律：

1. **推理标注出处** — 每条结论必须引用命盘JSON字段或具体文档章节，不能凭空说
2. **指出多种可能性** — 同一个星曜组合，现实中可能有几种完全不同的体现方式，需要列出并标注哪种在当前背景下更可能
3. **不逢迎，有一说一** — 命盘里有就是有，没有就是没有。禁止为了让人心情好而选择性汇报
4. **落地想风险但不制造焦虑** — 推到行动建议时先列风险清单并排序，但禁用"命中注定""躲不过"这类封闭式语言。每个风险必须附缓解措施和通过条件
5. **What-If 反事实推演** — 每条行动建议必须同时画两条分支：不做的最坏情况 + 失败的最坏情况。人的默认偏差是只分析行动风险，不分析不行动风险——这条规则强制纠偏
