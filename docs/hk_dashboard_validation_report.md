## 已知差异根因

### 续费率: 系统 vs Excel

- **根因**: 教师归属逻辑不同
  - 系统: `主带课教师` 优先 (108/258 班有值) → 兜底取 `教师` 列第一位
  - Excel: 人工指定主教师
- **影响**: 整体续费率偏差 < 2%, 个别教师差异可能较大
- **建议**: 业务方确认教师映射表后二次修正, 或接受当前口径

### TMK 管道 vs 签约管道

- **根因**: 两表通过资源ID无法全量关联 (零交集), 是两根独立管道
- **影响**: 签约转换率无法从 TMK 直接计算
- **建议**: 业务方确认数据关系, 或接受当前双管道独立展示
