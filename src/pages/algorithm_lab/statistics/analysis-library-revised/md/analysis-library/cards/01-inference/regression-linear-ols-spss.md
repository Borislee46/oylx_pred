# 线性回归（OLS）

- **slug**: regression-linear-ols-spss
- **aliases**: 多元线性回归、最小二乘法、Ordinary Least Squares、REGRESSION

## 1. 回答什么问题

在**连续因变量** \(Y\) 与一组预测变量 \(X\) 之间，估计呈线性组合的**条件均值** \(\mathrm{E}(Y|X)=X\beta\)。基于普通最小二乘法（OLS）进行**系数推断**（显著性检验 \(t\)/全局检验 \(F\)）、评估模型**拟合优度**（\(R^2\)），并提供个案级别的**残差诊断**与预测。

## 2. 不适用与易滥用场景

- **混淆相关与因果**：OLS 估计的系数 \(\beta\) 仅代表**条件关联**（即控制模型中其他变量后的边际差异）。因果推断不依赖于 OLS 本身，而依赖于严格的**研究设计**（如随机化实验）或**识别策略**（混杂控制、工具变量等）。
- **因变量有界、计数或分类**：若 \(Y\) 为二分类、多分类、计数（如泊松分布）或严格受限比例，OLS 的残差假设必然破裂，且可能产生无意义的越界预测值。应考虑 **广义线性模型（GLM）**（如逻辑回归、泊松回归）或 **Beta回归**。
- **非独立样本（聚类/重复测量）**：面板数据、纵向数据或多层抽样会导致默认的 **i.i.d.（独立同分布）**残差假设不成立。应使用 **混合效应模型（HLM/LMM）**、**广义估计方程（GEE）** 或 **聚类稳健标准误（Cluster-Robust SE）**。
- **强非线性关系**：若 \(X\) 与 \(Y\) 呈复杂的非线性关系，直接纳入 \(X\) 会导致拟合偏差。需考虑加入**高次项/交互项**、使用**样条函数（Splines）**、**变量变换**，或改用**非线性回归**。

## 3. 数据与设计前提

- **样本量要求**：需满足 \(n\) 显著大于模型参数个数。经验法则（Rule of Thumb）常建议每增加一个预测变量，至少需要 10-15 个有效观测值；在**高维数据**（\(p \approx n\) 或 \(p > n\)）下，OLS 估计量矩阵不可逆或极不稳定，需改用正则化方法（岭回归、Lasso）。
- **缺失值处理**：默认的列表删除（Listwise Deletion）会大幅降低统计功效并可能引入偏差（若非完全随机缺失 MCAR）。建议报告最终纳入分析的有效 \(n\)，并在必要时采用**多重插补（Multiple Imputation）**。

## 4. 模型与检验统计量

- **总体模型**：\(y = X\beta + \varepsilon\)；其 OLS 闭式解为 \(\hat\beta = (X'X)^{-1}X'y\)。
- **全局 F 检验**：检验所有非截距项系数是否联合为零。
  \[ F = \frac{MSR}{MSE} \sim F_{p-1,\,n-p} \]
  *(注：此处 \(p\) 定义为**包含截距项在内的模型参数总数**。若模型有 \(k\) 个自变量，则 \(p = k+1\)。不同教材对 \(p\) 与 \(k\) 的符号使用可能存在差异。)*
- **单系数 t 检验**：检验特定自变量对 \(Y\) 的边际贡献。
  \[ t = \frac{\hat\beta_j}{SE(\hat\beta_j)} \sim t_{n-p} \]
  通常报告**双侧**检验的 \(p\) 值。
- **分层/块回归（Hierarchical Regression）**：用于嵌套模型比较，通过 \(\Delta R^2\) 及其对应的 **F 变化量（F-change）** 评估新增变量块的额外解释力。

## 5. 假设与核心诊断

| 假设/问题 | 推荐检查方式 | 违背时的典型后果 | 补救思路/宽容度 |
| :--- | :--- | :--- | :--- |
| **线性设定** | **偏回归图** (Partial plot)、**残差 vs 拟合值图** | 估计呈系统性偏差、模型预测极差。 | 加入多项式或非线性变换。 |
| **残差独立性** | 基于数据生成机制（研究设计）；**Durbin–Watson** (仅针对时序数据)。 | 系数估计无偏，但 **SE 偏小**，导致第一类错误率失控（\(t/F\) 检验无效）。 | 聚类稳健 SE、混合模型、时间序列模型。 |
| **同方差性** | **标准化残差 vs 拟合值图**呈漏斗状；**Breusch–Pagan** 检验。 | 系数估计无偏，但 **SE 有偏**，置信区间与假设检验不可靠。 | 使用 **稳健标准误（Robust SE / HC0-HC3）**。 |
| **残差正态性** | **Q–Q 图**、残差直方图。 | 导致**小样本**下参数的精确 \(t\) 分布和 \(F\) 分布不成立，区间覆盖率差。 | **大样本下极度宽容**（依中心极限定理，\(\hat\beta\) 渐近正态）；无需过度纠结 SW 检验结果。 |
| **多重共线性** | **方差膨胀因子（VIF）**、**容忍度（Tolerance）**。 | 并非严格假设违背，但会导致系数方差剧增（极不稳定）、符号反常或无法解释。 | 剔除高共线变量、主成分回归、Lasso/岭回归。 |
| **强影响点** | **Cook's D** (综合影响)、**杠杆率 \(h_{ii}\)** (X空间异常)、**DfBeta** (单系数影响)。 | 极个别极端样本主导整个回归平面的斜率（尤其在小样本中）。 | 核查数据录入错误；使用**稳健回归（Robust Regression）**。 |

## 6. 效应量与置信区间

- **模型解释力**：
  - **\(R^2\) / 调整后 \(R^2\)**：模型对因变量方差的解释比例。调整后 \(R^2\) 惩罚了无意义的变量堆砌。
  - **RMSE（均方根误差）**：以因变量原单位衡量预测精度的绝对指标。
- **变量相对重要性与增量**：
  - **标准化系数（Standardized \(\beta\) / Beta）**：将自变量与因变量均标准化后拟合的系数，消除了量纲影响，常用于社会科学中比较同一模型内各变量的**相对重要性**。
  - **偏相关 / 部分相关（Partial / Semipartial correlation）**：衡量单个自变量在控制其他变量后，对因变量方差的**唯一解释增量**（SPSS 菜单中译为“部分相关”）。
- **推断区间（需严格区分）**：
  - **系数置信区间（Coefficient CI，常取 95%）**：估计总体参数 \(\beta\) 的不确定性范围。
  - **均值响应区间（Confidence Interval for Mean Response）**：给定 \(X\) 时，对总体**平均 \(Y\)** 的估计范围。
  - **单值预测区间（Prediction Interval for New Observation）**：给定 \(X\) 时，对**单个新个案 \(Y\)** 的预测范围（由于包含了个体不可观测误差 \(\varepsilon\)，**预测区间永远宽于均值响应区间**）。

## 7. 与相关方法的取舍

- **GLM（广义线性模型）**：当因变量严重偏离连续正态设定（如离散、偏态且有界）时使用。
- **稳健回归（Robust Reg） / 分位数回归（Quantile Reg）**：当残差重尾、数据包含大量无法剔除的真实异常值时，以牺牲部分效率换取结果的稳定性。
- **岭回归（Ridge） / Lasso Regression**：当模型以**高维预测**为主任务，且面临严重多重共线性（\(VIF \gg 10\)）时使用。

## 8. 实现速查与代码范例

### SPSS 操作路径
- **菜单**：`分析 (Analyze)` -> `回归 (Regression)` -> `线性 (Linear)`
- **统计 (Statistics)**：勾选**估算值**（\(B\)、\(SE\)、\(t\)、\(p\) 及 标准化 \(\beta\)）、**置信区间**、**模型拟合**（\(R^2\)）、**R 方变化**（嵌套模型比较）、**共线性诊断**（VIF）、**个案诊断**（通常设定检出超过 3 个标准差的离群值）。
- **图 (Plots)**：将 `*ZRESID` (标准化残差) 放入 Y 轴，`*ZPRED` (标准化预测值) 放入 X 轴，用于诊断异方差与非线性；勾选直方图和正态概率图。
- **保存 (Save)**：可将预测值、残差、**Cook 距离 (Cook's D)** 存为数据集中新变量，便于后续剔除或单独分析。
- ⚠️ **注意**：SPSS 的 `REGRESSION` 过程**原生不支持 HC 稳健标准误**（HC0–HC4）。如需异方差稳健推断，应改用 **GLM 单变量过程**（可勾选稳健标准误选项）或转向 R/Python。

### R 语言实现

```r
# 1. 拟合基础 OLS 模型
fit <- lm(y ~ x1 + x2 + x3, data = d)
summary(fit) # 输出非标准化系数、SE、t、p、R^2及全局F检验

# 2. 诊断工具箱 (共线性、异方差检验与综合诊断图)
car::vif(fit)                             # 多重共线性诊断
lmtest::bptest(fit)                       # Breusch-Pagan 异方差检验
performance::check_model(fit)             # 极佳的综合目视诊断面板 (推荐)

# 3. 获取稳健标准误 (当存在异方差时修正推断)
# 使用 HC3 估计量重新计算系数的 t 检验和 p 值
lmtest::coeftest(fit, vcov = sandwich::vcovHC(fit, type = "HC3"))

# 4. 提取标准化系数
lm.beta::lm.beta(fit)
```

### Python 实现 (statsmodels)

```python
import statsmodels.api as sm
from statsmodels.stats.outliers_influence import variance_inflation_factor

# 1. 拟合 OLS 模型 (statsmodels 不默认加截距，需手动添加)
X = sm.add_constant(d[["x1", "x2", "x3"]])
y = d["y"]
ols_model = sm.OLS(y, X).fit()

# 输出完整摘要 (包含 B, SE, t, p, CI, R^2 等)
print(ols_model.summary())

# 若存在异方差，使用稳健标准误 (HC3) 重新拟合
ols_robust = sm.OLS(y, X).fit(cov_type='HC3')
print(ols_robust.summary())

# 2. 计算 VIF (多重共线性)
vif_data = {X.columns[i]: variance_inflation_factor(X.values, i) for i in range(X.shape[1])}
print("VIF 结果:", vif_data)

# 3. 强影响点诊断 (Cook's D 等)
influence = ols_model.get_influence()
cooks_d = influence.cooks_distance[0]
```

## 9. 报告撰写清单 (Checklist)

在学术论文的“结果”或“统计分析”小节，通常需报告以下要素：
- [ ] **样本信息**：实际纳入分析的有效样本量 \(N\) 及缺失值处理方式。
- [ ] **全局模型信息**：模型解释力 \(R^2\) 及调整后 \(R^2\)；全局 \(F\) 检验统计量、自由度（回归自由度与残差自由度）及 \(p\) 值。
- [ ] **系数推断表**：需包含非标准化系数（\(B\) 或 \(\hat\beta\)）、**标准化系数（\(\beta\)）**、标准误（\(SE\)）、检验统计量（\(t\)）、精确 \(p\) 值及 95% 置信区间（CI）。
- [ ] **诊断说明**：简述多重共线性是否在可接受范围内（如：“所有自变量 VIF 均 < 5”）；简述残差的正态性与同方差性目视检查结果。
- [ ] **稳健性说明（如适用）**：若发现异方差，说明采用了何种稳健标准误（如 HC3）；若存在极端影响点（Cook's D 异常），简述剔除前后的敏感性分析结果。

## 附录：SPSS “线性回归”核心对话框选项对照

### 统计 (Statistics)

| 勾选项 (中文字面) | 统计学含义 / 报告用途 |
| :--- | :--- |
| **估算值(E)** | 输出回归方程的核心参数：**B** (非标准化)、**SE**、标准化 **\(\beta\)**、**t**、**p**。 |
| **置信区间(N)** | 默认计算 \(\beta\) 的 95% CI。发表必备。 |
| **协方差矩阵(C)** | 系数间的协方差，用于高阶的多重假设检验或荟萃分析。 |
| **模型拟合(M)** | 输出 **R²、调整 R²、估计的标准误 (RMSE)** 及 ANOVA 表 (全局 F 检验)。 |
| **R 方变化(S)** | 分层回归中评估自变量块增加的解释力 (**\(\Delta R^2\)** 与 **F 变化**)。 |
| **部分相关和偏相关(P)**| 用于计算特定自变量的独立方差贡献率 (Zero-order, Partial, Part)。 |
| **共线性诊断(O)** | 输出容忍度 (Tolerance) 与核心指标 **VIF**。 |
| **个案诊断(C)** | 根据设定的标准差倍数 (如 `超出 3 个标准差`) 自动标记极端离群值。 |

### 图 (Plots)

用于生成各类残差诊断图。通常建议：
- **Y 轴**填入 **`*ZRESID`** (标准化残差) 或 `*SRESID` (学生化残差)
- **X 轴**填入 **`*ZPRED`** (标准化预测值)
- 勾选 **直方图** 和 **正态概率图(P)** 用于评估正态性。

| 轴变量代码 | 具体含义 | 备注 |
| :--- | :--- | :--- |
| **`*ZPRED`** | 标准化预测值 | 用于代替原始 \(X\) 以综合评估线性与同方差。 |
| **`*ZRESID`** | 标准化残差 | 常用残差指标，方差近似为 1。 |
| **`*SRESID`** | 学生化残差 | 比 `*ZRESID` 更精确的标准化方式，考虑了各点杠杆率的不同。 |
| **`*DRESID`** | 删除残差 | 计算该个案残差时，不将其纳入回归拟合（用于评估影响）。 |

### 保存 (Save)

将计算结果直接追加回原数据表格中：
- **预测值**：未标准化 (即 \(\hat{y}\))、标准化、调整 (预测时不包含该点自身)。
- **距离**：**马氏距离** (Mahalanobis，评估自变量空间距离)、**Cook 距离** (综合影响度，常用阈值 \(4/n\) 或 \(1\))、**杠杆值** (Leverage，自变量极端程度)。
- **预测区间**：可分别保存 **均值 (Mean)** 响应区间和 **个别 (Individual)** 单值预测区间的上限与下限。
