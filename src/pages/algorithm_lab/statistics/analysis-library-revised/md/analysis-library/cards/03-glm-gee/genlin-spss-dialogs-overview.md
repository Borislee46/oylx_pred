# 广义线性模型（GENLIN）

- **slug**: genlin-spss
- **菜单**：**分析 → 广义线性模型 → 广义线性模型**（Analyze → Generalized Linear Models → Generalized Linear Models）

## 1. 回答什么问题

广义线性模型（Generalized Linear Models, GLM）在**指数族分布**（Exponential Family）与**单调链接函数**（Link Function, $g(\mu)=X\beta$）的统一框架下，对传统线性回归进行了拓展。
它主要用于处理**非正态因变量**的建模问题，包括但不限于：**二分类/多分类**结局、**计数**结局（含过度离散）、**正偏态连续**结局等。该程序提供基于最大似然（MLE）或拟似然的参数估计，输出全局拟合优度、模型效应检验（Wald/LR）以及具有流行病学意义的效应量（如 OR 值、率比 IRR）。

## 2. 不适用 / 易滥用

- **聚类 / 纵向重复测量数据（高风险）**：基础的 GENLIN 假设观测值之间相互独立。如果数据存在明显的嵌套、聚类或重复测量结构，必须改用 **GEE（广义估计方程）** 或 **GLMM（广义线性混合模型）**。
- **完全分离（Complete Separation）**：在二项分布（Logistic 回归）中，若某预测变量的组合能完美预测结局（如某亚组的成功率为 100%），会导致极大似然估计不收敛、系数和标准误趋于无穷大。需通过检查交叉表识别，并考虑惩罚似然（Firth Logistic）或合并类别。
- **过度离散（Overdispersion）**：在泊松回归中，常出现方差大于均值的情况。**经验法则：若 Pearson $\chi^2 / df$ 显著大于 1（如 > 1.5 或 2.0），提示存在过度离散**，此时强行使用泊松分布会低估标准误（增加第一类错误），应改用**负二项分布**或带有离散参数的**准泊松（Quasi-Poisson）**模型。

## 3. 数据与设计前提

- **二项分布的输入格式**：因变量既可以是聚合格式（「成功数 / 试验总数」的频数权重模式），也可以是个案级原始数据（0/1 编码）。
- **偏移量（Offset）的正确设定（易错点）**：在泊松或负二项模型中计算率（Rates）时，需要引入「暴露量」（如人年数、观察时间）作为分母。**注意：在对数链接（Log link）下，必须先对原始暴露量取自然对数（即 $ln(T)$），然后将该对数转换后的变量放入 Offset 框**。偏移量本质上是一个回归系数被强制固定为 1 的特殊预测变量。

## 4. 假设与诊断

GLM 放宽了正态性和方差齐性假设，但仍需满足以下前提。其残差诊断体系较普通线性回归更为复杂：

| 假设检查点 | 推荐的诊断工具/统计量 | 违背时的典型后果与应对 |
| :--- | :--- | :--- |
| **分布与链接设定** | **Deviance 偏差残差**（查总体拟合优度）、<br>**Pearson 残差**（查异方差与离群值） | 估计有偏。需尝试其他分布或链接函数（如正偏数据对比 Gamma 与逆高斯）。 |
| **离群/分布拟合诊断** | **Anscombe 残差** | GLM 推断基于似然理论，**不需要残差正态性**。Anscombe 残差是诊断工具（偏度修正效果优于 Pearson/Deviance 残差），用于识别离群值和评估分布拟合，非模型前提。 |
| **观测值独立性** | 抽样设计与数据结构审查 | 标准误严重低估。必须转用 GEE/GLMM。 |
| **方差-均值关系** | 均值-方差散点图、Pearson $\chi^2 / df$ | 存在异方差或轻度违背时，可启用**稳健协方差**（Robust HC SE）；若过度离散严重，需更改分布设定。 |

> **⚠️ 关于「稳健协方差」的澄清**：单层 GLM 菜单中的稳健协方差（Huber-White/Sandwich 估计）仅用于修正**潜在的异方差**或**分布轻微错设**带来的标准误偏差，它**不能**解决由于数据聚类（Clustering）导致的非独立性问题。解决聚类需在 GEE 中指定工作相关矩阵。

## 5. 模型与检验统计量

- **全局拟合优度**：主要通过 **偏差（Deviance）** 和 **Pearson $\chi^2$** 评估，其自由度（$df$）通常为残差自由度（样本量减去模型参数个数）。值越小（与其 $df$ 的比值越接近 1）代表拟合越好。模型比较可参考 AIC/BIC。
- **全模型综合检验（Omnibus Test）**：通常基于似然比检验（Likelihood Ratio Test, LRT），对比包含所有预测变量的拟合模型与仅含截距的零模型。这是判断「模型整体是否有效」的首要指标。
- **参数效应检验**：
  - **Wald 检验**：计算快，但在参数接近参数空间边界（如极端的概率）时可能不准确。
  - **似然比检验（LR）与轮廓似然置信区间（Profile LR CI）**：理论上比 Wald 更精确、更对称，但计算成本更高（需多次迭代）。

## 6. 效应量与区间解读

GLM 的输出系数 $\beta$ 处于链接函数的尺度上，为了解释上的直观，通常报告指数化系数 **$\exp(\beta)$** 及其 95% 置信区间：
- **在二项分布 + Logit 链接下**：$\exp(\beta)$ 为 **优势比（Odds Ratio, OR）**。
- **在泊松/负二项分布 + Log 链接下**：$\exp(\beta)$ 为 **率比 / 发病密度比（Incidence Rate Ratio, IRR）**。
- **置信区间**：若软件允许，优先报告基于轮廓似然（Profile Likelihood）的 95% CI。

## 7. SPSS 菜单操作避坑指南

在使用 SPSS `GENLIN` 界面时，最易导致结果谬误的操作在于「预测变量」的分类设定：
1. **因子（Factors） vs. 协变量（Covariates）**：分类变量**必须**放入「因子」框，连续变量放入「协变量」框。
2. **参考类别的隐蔽设定**：SPSS 会自动为「因子」生成哑变量，但**默认将「最后一个类别（按字母或数字排序）」作为参考组**。这往往与临床直觉（如以「正常/0」组为参考）相反。必须在「预测变量 -> 选项」中手动核对并修改参考类别（改为「第一个」或「定制」）。

## 8. 报告清单（科研写作要素）

标准的学术论文应当在「统计方法」与「结果」部分明确交代以下要素：
- [ ] **模型设定**：明确声明所用的**响应分布**（如负二项分布）与**链接函数**（如对数链接）。
- [ ] **偏移量设定**：若计算发生率，需注明所用的人时（Person-time）及其对数转换过程。
- [ ] **模型整体检验**：报告 Omnibus Test（似然比检验）的 $\chi^2$ 值、自由度与 $p$ 值，以及 AIC/BIC（若涉及模型比较）。
- [ ] **效应量估计**：报告关键预测变量的 $\exp(\beta)$（标明是 OR 还是 IRR）、95% 置信区间及对应检验的 $p$ 值（注明是 Wald 还是 LR 检验）。
- [ ] **诊断说明**：若进行了过度离散诊断或使用了稳健标准误（Robust SE），需明确报告其统计学理由。

## 9. 跨软件实现代码

- **SPSS**：`GENLIN`（详见附录对话框逻辑）。
- **R**：
  - 基础族：`glm(y ~ x, family = binomial(link="logit"), data=df)`
  - 负二项：`MASS::glm.nb()`
  - 拟似然/准泊松：`family = quasipoisson()`
- **Python**：`statsmodels.genmod.generalized_linear_model.GLM`，通过 `families` 模块指定分布体系。

## 附录 A：模型类型（分布与链接预设）

SPSS 将常用的「分布+链接」组合封装成了预设类型，方便快速调用：

| 类型（SPSS 预设） | 对应设定（分布 + 链接） | 典型用法 |
| :--- | :--- | :--- |
| **线性** | 正态 + 恒等（Identity） | 经典的多元线性回归/ANOVA |
| **伽玛与对数联接** | Gamma + 对数（Log） | 严格大于 0 且极度正偏的连续变量（如医疗费用） |
| **泊松对数线性** | Poisson + 对数（Log） | 标准计数数据，方差≈均值 |
| **负二项与对数联接** | Negative Binomial + 对数（Log）| **过度离散**的计数数据，方差>均值 |
| **有序 Logistic** | 多项式 + 累积 Logit | 有序分类因变量（需满足比例优势假设） |
| **二元 Logistic** | 二项 + Logit | 经典的二分类结局 |
| **区间删失生存** | （视特定模块提供） | 结局为生存时间但仅知区间的生存数据 |
| **Tweedie** | Tweedie + 对数（Log） | 含有大量精确零值的正偏连续数据（如保险索赔额） |
| **定制** | 自选分布、链接、尺度参数 | 高级玩法。通常推荐使用**规范链接（Canonical Link）**以保证充分统计量存在并加速算法收敛（如二项对应 Logit，泊松对应 Log）。 |

## 附录 B：参数估计选项

- **估计方法**：默认为「混合」或「Fisher 评分（Fisher Scoring / IRLS）」，通常收敛极快。若遇到分离现象，可能达到「最大迭代」上限。
- **标度参数（Scale Parameter）**：控制残差方差的估计方式。通常设定为默认选项（如泊松/二项固定为 1），但在处理过度离散时，可选择基于 Pearson $\chi^2$ 或 Deviance 进行自由估计（即转化为准似然模型）。
- **协方差矩阵**：提供「基于模型（Model-based）」与「稳健（Robust）」两种估计器。
- **分离检查**：在分析 Logistic 模型时务必勾选，软件可预警完全分离问题。
- **奇异性容差**：设计矩阵求逆的容差阈值，提示多重共线性问题。

## 附录 C：输出与打印要素

在「保存」或「输出」选项卡中，推荐关注：
1. **模型信息与拟合优度**：获取 Deviance、Pearson $\chi^2$ 及其比值。
2. **参数估计与 $\exp(\beta)$**：必须勾选包含指数化参数（即 OR/IRR 值），否则需手动计算。
3. **连续变量的边际均值（EM Means）**：有助于非线性模型（如 Logit 尺度）结果向原始概率/均值尺度的逆向解释。
