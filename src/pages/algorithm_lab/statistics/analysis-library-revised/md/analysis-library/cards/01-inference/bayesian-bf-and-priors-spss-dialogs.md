# SPSS 贝叶斯 — 贝叶斯因子与先验（多过程）

- **slug**: bayesian-bf-priors-spss
- **前提**：需安装/启用 SPSS **贝叶斯 (Bayesian)** 附加组件；各统计过程的 JZS / Rouder / Zellner / g 先验等具体数学形态与参数化，以当前使用版本的**帮助文档与 Syntax 参考**为准。

## 1. 回答什么问题

在独立样本推断（$t$ 检验）、单因素 ANOVA、线性回归、皮尔逊相关以及对数线性等模型中，设定原假设 $H_0$ 与备择假设 $H_1$（通常为嵌套模型），计算 **贝叶斯因子 (Bayes Factor, BF)**。BF 量化了**数据在两种竞争模型下的边际似然比 (Marginal Likelihood Ratio)**，代表了数据对某一假设的相对支持强度。本模块也允许用户干预模型比较的核心——先验分布的设定（如 g 先验族、拉伸参数 $c$、共轭先验等）。

## 2. 不适用 / 易滥用

- **极其依赖先验设定**：贝叶斯因子对参数先验的方差（尺度）高度敏感。更换先验参数（如拉伸因子）可导致 BF 发生数量级变化。必须进行**敏感性分析**或报告**默认/稳健先验**的依据。
- **任意比较不可比的模型**：BF 是相对证据。若他人定义的 $H_0$ 或 $H_1$（如先验分布或包含的协变量）与你不同，则两者的 BF **不可直接横向比较**。
- **数据分割偏差（分数/内在 BF）**：在使用分数贝叶斯因子或内在贝叶斯因子时，若数据分割比例或训练集选取不当，可能导致对某一假设的过度乐观。
- **对数线性的似然错配**：离散数据的抽样方案决定了似然函数。若实际为多项抽样（总数固定），却误选独立泊松模型，或边际固定选项与实际设计不符，将导致推断完全无效。

## 3. 数据与设计前提

- **结构同构**：与对应的频率学派模型（如 OLS 回归、Pearson 相关）具有相同的样本独立性、变量测量尺度与数据结构前提。
- **大样本下的 Lindley 悖论 (Lindley's Paradox)**：在极大样本下，若备择假设的先验过于弥散（方差极大），BF 会极度偏好原假设 $H_0$（即使经典 $p$ 值显著）。因此，解释大样本的 BF 时务必结合后验效应量及其可信区间 (CrI)。

## 4. 模型与检验统计量

- **$BF_{10}$ 与 $BF_{01}$（防呆预警）**：
  - **$BF_{10}$**：数据支持备择假设 ($H_1$) 相对于原假设 ($H_0$) 的证据强度。
  - **$BF_{01}$**：数据支持原假设相对于备择假设的证据强度（$BF_{01} = 1 / BF_{10}$）。
  - **务必在报告时明确下标方向，极易解释反转！** 常取 $\log(BF_{10})$ 以对称化展示。
- **后验胜率 (Posterior Odds)** = $BF_{10} \times$ **先验胜率 (Prior Odds)**。若认为两模型先验等可能（先验胜率=1），则后验胜率等于 BF。
- **Jeffreys 证据尺度**：如 $BF_{10} > 3$ 为「实质性证据 (Substantial)」，$> 10$ 为「强证据 (Strong)」。此为**启发式 (Heuristic) 标签**，绝非等同于 $p < 0.05$ 的二分决策绝对阈值。

## 5. 假设与诊断

| 假设/前提 | 检查/诊断方式 | 违背时的典型后果 |
| :--- | :--- | :--- |
| **似然/联结函数正确** | 残差图、Q-Q 图（与频率学派诊断通用） | 模型设定错误，BF 失去业务意义 |
| **先验与参数化一致** | 查阅手册中 $g, c$ 及共轭参数的具体数学定义 | 错误量化证据强度（如过度偏好 $H_0$） |
| **数值积分/MCMC 收敛** | 检查容差选项、提升 MCMC 迭代次数、固定随机种子 | 同一数据集多次运行的 BF 数值跳动不稳定 |

## 6. 效应量与区间

- 仅报告 BF 是不够的（BF 只做模型比较）。必须同时报告在支持的模型（或全模型）后验分布下，目标参数（如 $\delta, \rho, \beta$）的**后验均值/中位数**以及 **95% 贝叶斯可信区间 (Credible Interval, CrI)**。若存在多个有竞争力的模型，可考虑报告**贝叶斯模型平均 (BMA)** 的效应量。

## 7. 与相关方法的取舍

- **$p$ 值 (NHST)**：$p$ 值检验的是在 $H_0$ 下出现当前或更极端数据的概率；**BF** 衡量的是两模型预测当前数据的相对能力。两者哲学范式不同，不可相互换算。
- **BIC 近似**：在大样本且特定先验下，$\Delta BIC \approx -2 \ln(BF)$。BIC 是一种粗略但易得的近似，但与精确推导的 BF **非严格等价**。

## 8. 实现速查

- **SPSS**：在各统计过程对应的 **Bayesian (贝叶斯)** 菜单下，进入 **Bayes Factor (贝叶斯因子)** 或 **Priors (先验)** 子对话框；Syntax 命令以 `BAYES` 开头（如 `BAYES REGRESSION`, `BAYES INDEPENDENT`）。
- **R**：使用权威的 `BayesFactor` 包（`ttestBF`, `correlationBF`, `regressionBF`, `anovaBF` 等），其底层数学逻辑与 SPSS 的 JZS/g 先验族高度一致。
- **Python**：原生的 `pymc` 计算边际似然较为繁琐。推荐使用基于 PyMC 构建的高级接口 **`bambi` (BAyesian Model-Building Interface)**，可用类似 R 的公式语法快速设定并抽取后验；或通过 `rpy2` 调用 R 的 `BayesFactor` 包。

## 9. 报告清单与示范

**【应报告要素】**
1. **BF 方向**：明确是 $BF_{10}$ 还是 $BF_{01}$。
2. **先验分布族与全部超参数**：JZS / 分数 / Rouder 等；以及具体参数值（拉伸参数 $c$、$g$ 值、形状参数、共轭先验的均值与方差等）。
3. **$H_0$ 与 $H_1$ 模型定义**：进入比较的具体变量。
4. **计算方法细节**：若使用 MCMC 或数值积分，附上**迭代次数、容差与随机种子**（确保可复现）。
5. **敏感性分析简述**：改变先验宽度后结论是否稳健。

**【标准报告模板（填空式）】**
> “使用 JZS 先验（拉伸参数 $r = 0.707$）计算贝叶斯因子。结果显示 $BF_{10} = 15.2$，表明数据支持备择假设（存在组间差异）的证据强度是原假设的 15.2 倍，达到实质性证据水平。效应量的后验中位数为 $\delta = 0.45$ [95% CrI: 0.12, 0.78]。MCMC 积分设定为 10,000 次迭代（Seed=123）。先验敏感性分析表明，当拉伸参数 $r$ 在 0.5 至 1.0 之间变动时，定性结论保持稳健。”

## 10. 参考文献与手册

- Ly, A., Verhagen, J., & Wagenmakers, E. J. (2016). Harold Jeffreys's default Bayes factor hypothesis tests: Explanation, extension, and application in psychology. *Journal of Mathematical Psychology*, 72, 19-32. (详述 JZS 与默认 g 先验逻辑)

# 附录：各统计过程选项的统计学映射

> 编者注：SPSS 将不同的先验族分散在不同的统计对话框中。为便于理解其底层逻辑，以下按「统计族」对对话框选项进行逻辑归类。

## 【线性模型族：共享 g 先验逻辑】
*涵盖：独立样本 $t$ 检验、单因素 ANOVA、线性回归。此处核心在于如何设定多元回归系数的先验协方差矩阵（Zellner's $g$-prior 及其衍生）。*

### 附录 A：独立样本推论 / 单因素 ANOVA — 贝叶斯因子
| 选项名称 | 统计学含义与实务建议 |
| :--- | :--- |
| **JZS / Rouder 方法** | Rouder 等人基于 Jeffreys-Zellner-Siow (JZS) 框架对效应量与方差先验的标准化。**推荐作为默认的无信息/客观先验**。 |
| **Gonen 方法** | 基于不同数学分布的先验族；通常可与 Rouder 方法**并列报告**，作为敏感性分析的一环。 |
| **超先验方法(H) + 形状参数** | 对应 Hyper-$g$ 或 Hyper-$g/n$ 先验。形状参数控制分布尾部的厚度，赋予模型更大的灵活性。 |
| **效应大小的平均值/方差** | （仅 $t$ 检验）对 Cohen's $\delta$ 赋予正态的主观信息先验。需明确的主观/历史文献依据。 |

### 附录 B：线性回归 — 先验与模型比较
| 选项名称 | 统计学含义与实务建议 |
| :--- | :--- |
| **原假设下的模型 / 全模型(M)** | **核心定义**：BF 的值完全依赖于你如何定义这两者（例如：仅截距模型 vs. 包含全部预测变量的模型；或嵌套模型的比较）。 |
| **参考先验(E)** | 弱信息 (Weakly Informative) 先验，通常用于仅需后验分布而不侧重严苛模型比较的场景。 |
| **共轭先验(O)** | 使用 **NIG (正态-逆伽马)** 联合先验。需用户手动输入先验均值与先验协方差矩阵（如使用恒等矩阵）。 |
| **Zellner 方法 + g 先验值** | 经典的 Zellner's $g$-prior。用户直接指定固定常数 $g$。由于固定 $g$ 存在悖论，现多被 JZS 或 Hyper-$g$ 取代。 |

## 【关联与分类族】
*涵盖：皮尔逊相关、对数线性模型。这些模型处理关联性或频数分布，采用与线性模型不同的共轭逻辑或抽样分割逻辑。*

### 附录 C：皮尔逊相关 — 贝叶斯因子与先验拉伸
| 选项名称 | 统计学含义与实务建议 |
| :--- | :--- |
| **JZS 贝叶斯因子** | 检验 $\rho = 0$ (原假设) vs. $\rho \neq 0$ (备择假设)。 |
| **分数贝叶斯因子 (Fractional BF)** | 使用一小部分数据（**分数(E)** 设定的比例）将无信息先验更新为恰当先验，再用剩余数据计算 BF。需防范数据分割带来的不稳定性。 |
| **均匀 (c=0) / 杰弗里斯 (c=-1.5)** | **c (拉伸参数)** 决定了相关系数 $\rho$ 先验分布的形态。Jeffreys 建议值为 -1.5。**注意：此 $c$ 为相关分析专用超参数，勿与分类变量的类别数混淆。** |
| **设置定制 c 值(M)** | 强烈建议在此输入不同的 $c$ 值运行多次，以完成先验敏感性分析。 |

### 附录 D：对数线性模型 — 贝叶斯推论
*实务关键：此处的先验设定必须严格匹配数据的实际收集/抽样方式。*

| 选项名称 | 统计学含义与实务建议 |
| :--- | :--- |
| **泊松模型 (Poisson)** | 假设列联表中每个单元格的频数是独立泊松分布产生的（总样本量 $N$ 未在设计中固定）。 |
| **多项模型 (Multinomial)** | 假设总样本量 $N$ 固定，数据分配到各单元格中。最常见的列联表抽样假定。 |
| **固定边际 (行/列/总计)** | 与抽样方案强绑定。如果实验设计固定了某些边际和（如分层抽样），必须在此勾选。 |
| **先验：共轭(J) + 形状(A)** | 泊松模型使用 Gamma 先验；多项模型使用 **Dirichlet 分布 (Dirichlet Distribution)**。形状参数即为伪计数 (Pseudo-counts)。 |
| **内在贝叶斯因子 (Intrinsic BF)** | *[对应 OCR 的“内在”]* 逻辑类似分数 BF，利用最小训练样本将不恰当先验转换为恰当先验，从而实现稳健的模型比较。计算开销较大，细节依赖 SPSS 特定版本的内置积分器。 |
