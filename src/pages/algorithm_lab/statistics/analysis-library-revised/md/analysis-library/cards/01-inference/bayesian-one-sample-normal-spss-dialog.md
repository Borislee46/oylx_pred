# 贝叶斯单样本推论：正态（Bayesian One-Sample: Normal）

- **slug**: bayesian-one-sample-normal
- **aliases**: 贝叶斯单样本 t 检验、正态似然单均值推断
- **前提**：需统计软件包含**贝叶斯（Bayesian）**高级组件（如 SPSS 需额外授权或安装对应模块，JASP/Jamovi 为原生内置）。

## 1. 回答什么问题

在**正态似然（Normal Likelihood）**假设下，结合先验分布对**单样本均值** $\mu$（及方差未知时的 $\sigma^2$）给出**后验分布（Posterior Distribution）**与 **95% 可信区间（Credible Interval, CrI）**。同时，可通过计算**贝叶斯因子（Bayes Factor, BF）**，对「总体均值是否等于特定假设值（如 $H_0: \mu = \mu_0$）」提供量化的证据强度。

## 2. 不适用 / 易滥用

- **混淆 CrI 与频率学 CI**：贝叶斯的 **CrI**（可信区间）指「在给定数据下，参数落在该区间的概率为 95%」，解释直观；而频率学 **CI**（置信区间）指多次抽样的长程覆盖率，不可直接作概率解释。二者不仅概念不同，在引入强信息先验时数值也会产生显著差异。
- **明显非正态或存在极端异常值**：正态似然对重尾分布或极端值敏感。建议考虑数据变换、改用学生 $t$ 似然（稳健贝叶斯推断），或使用非参数贝叶斯方法。
- **未做先验敏感性分析（Prior Sensitivity Analysis）直接下结论**：信息先验（Informative Prior）或不同的无信息/扩散先验（Diffuse Prior）宽度可能显著改变后验结果与 BF 值。仅报告单一先验下的结果是常见的滥用。

## 3. 数据与设计前提

- **独立同分布观测**：假定数据点相互独立。若数据存在聚类或嵌套结构（如重复测量、多中心数据），则不满足独立性假设，需升级为**贝叶斯多层模型（Bayesian Hierarchical Models）**。
- **方差已知 vs 未知设定**：模型需明确总体方差 $\sigma^2$ 是已知常量，还是需作为未知参数进行联合估计。方差未知时，通常需为 $\sigma^2$ 指定先验（如逆伽马分布或 Jeffreys 先验）。

## 4. 模型或检验统计量

- **后验推断**：通过贝叶斯定理 $P(\mu, \sigma^2 | Y) \propto P(Y | \mu, \sigma^2) P(\mu, \sigma^2)$，在共轭先验（正态–逆伽马）下可得到解析解；否则依赖数值积分或马尔可夫链蒙特卡洛（MCMC）进行抽样逼近。
- **贝叶斯因子（BF）**：边缘似然比（Marginal Likelihood Ratio）。需严格区分方向：
  - **$BF_{10}$**：数据支持备择假设（$H_1$）相比原假设（$H_0$）的程度。
  - **$BF_{01}$**：数据支持原假设相比备择假设的程度（$BF_{01} = 1 / BF_{10}$）。
  - *证据分级参考（Lee & Wagenmakers）*：$BF_{10} \in (1, 3]$ 为弱（Anecdotal）证据；$(3, 10]$ 为中等（Moderate）证据；$>10$ 为强（Strong）证据。**务必标注方向**（$BF_{10}$ vs $BF_{01}$），不标方向读者可能理解反。

## 5. 假设与诊断

| 假设检查点 | 检查/诊断方式 | 违背时的典型后果 |
| :--- | :--- | :--- |
| **正态似然假设** | Q-Q 图、Shapiro-Wilk 检验、厚尾诊断 | 后验分布有偏，贝叶斯因子可能严重失真。 |
| **先验稳健性** | **先验敏感性分析**（改变先验分布的宽度或超参数，观察结果变化） | 结论高度依赖主观设定的先验，缺乏客观说服力。 |
| **计算收敛性（数值或 MCMC）** | **数值积分**：检查容差值。<br>**MCMC**：检查 $\hat{R}$（需 $< 1.01$ 或 $\approx 1.0$）、有效样本量（ESS）。 | 积分失效或抽样未收敛，导致后验估计数值不可靠、无法复现。 |

## 6. 效应量与区间

- **参数估计**：报告 $\mu$ 的**后验均值（Mean）或中位数（Median）**，以及 **95% CrI**。
- **贝叶斯标准化效应量**：现代统计极度强调报告效应量。建议补充报告**后验 Cohen's $\delta$** 及其 95% CrI（即 $(\mu - \mu_0)/\sigma$ 的后验分布）。
- **假设检验**：报告具体的 $BF_{10}$ 或 $BF_{01}$，以及单侧概率如 $P(\mu > \mu_0 | y)$（若检验有方向性）。

## 7. 与相关方法的取舍

- **频率学单样本 t 检验**：若只关心 $p$ 值、遵循严格的 Neyman-Pearson 决策范式，可用频率 t 检验；若需量化支持原假设的证据（$p$ 值无法做到）、引入专家先验，或需直观的概率区间解释，则必须使用本过程。两者亦可**并列报告**以验证结果稳健性。
- **贝叶斯多层模型（Hierarchical Models）**：当样本违反独立性（如学生嵌套在班级内），本方法不再适用，需采用允许局部收缩（Partial Pooling）的多层模型。

## 8. 实现速查

- **JASP / Jamovi**：**强烈推荐用于贝叶斯推断**。`T-Tests -> Bayesian One Sample T-Test`。JASP 默认提供极佳的**先验敏感性图表**与标准化的 BF 解释。
- **SPSS**：菜单选择 `分析 -> 贝叶斯统计 -> 单一样本正态`（Syntax: `BAYES ONE SAMPLE`）。
- **R**：
  - `BayesFactor::ttestBF()`：专注于计算贝叶斯因子。
  - `easystats` 生态的 `bayestestR::describe_posterior()`：可直接输出符合 APA 格式的后验摘要。
  - `brms` 或 `rstanarm`：用于构建更复杂的自定义贝叶斯模型。
- **Python**：利用 `pymc` 构建显式概率模型，或使用 `bambi`（基于 PyMC 的高级接口）。

## 9. 报告清单与模板

**【报告清单】**
1. **似然函数**（正态）；
2. **先验设定**（务必明确：$\mu$ 的正态/无信息扩散先验及超参数；$\sigma^2$ 是已知还是用逆伽马分布）；
3. **后验摘要**（后验均值/中位数，以及 95% CrI）；
4. **贝叶斯效应量**（后验 Cohen's $\delta$ 及其 CrI）；
5. **贝叶斯因子**（明确指出是 $BF_{10}$ 还是 $BF_{01}$，并给出证据强度的解释）；
6. **算法设置**（若使用 MCMC 需报告迭代次数、种子设定、ESS 与 $\hat{R}$；若使用自适应高斯-洛巴托求积，说明容差设定）。

**【标准报告模板（示范）】**
> “本研究采用贝叶斯单样本推论评估总体均值。在假定正态似然的前提下，对参数 $\mu$ 与 $\sigma^2$ 采用默认的无信息先验（如 $\mu$ 用扩散先验 Diffuse prior，$\sigma^2$ 用 Jeffreys 或逆伽马先验；具体视软件而定）。分析结果显示，均值的后验中位数为 [XX] (95% CrI [LL, UU])，后验标准化效应量 Cohen's $\delta$ 为 [XX] (95% CrI [LL, UU])。贝叶斯因子 $BF_{10} = [XX]$，表明当前数据支持备择假设的证据强度是原假设的 [XX] 倍，达到 [弱/中等/强] 证据水平。先验敏感性分析表明该结论在合理设定的先验范围内保持稳健。”

## 10. 参考文献与手册

- Gelman, A., et al. (2013). *Bayesian Data Analysis* (3rd ed.). CRC Press. （贝叶斯建模圣经）
- Wagenmakers, E. J., et al. (2018). Bayesian inference for psychology. Part I: Theoretical advantages and practical ramifications. *Psychonomic Bulletin & Review*. （适合科研人员的贝叶斯及 BF 指南）

## 附录：SPSS 贝叶斯分析对话框结构对照表

> *注：以下表格已针对中文版 SPSS 中常见的机器翻译/OCR 错误（如“变里”、“罗巴脱”、“成列排除”）进行修正还原，以便准确对应软件中的实际统计学用语。*

### 1. 主对话框

| 菜单项名称 | 含义与操作指导 |
| :--- | :--- |
| **检验变量** | 填入需进行分析的连续型目标变量。 |
| **条件(C)** | （依软件版本）用于基于条件变量进行分层或过滤分析。 |
| **先验(P)...** | 打开子对话框，用于精确设定 $\mu$ 和 $\sigma^2$ 的先验分布形式与超参数。 |
| **表示后验分布的特征(Z)** | 仅输出参数的后验均值、方差及可信区间（CrI），不进行假设检验。 |
| **估算贝叶斯因子(E)** | 仅输出 $BF$ 用于假设检验。 |
| **使用上述两种方法** | **推荐默认选项**：同时输出后验分布特征（估计）与贝叶斯因子（检验）。 |

### 2. 数据方差和假设值 (H)

| 菜单项名称 | 含义与操作指导 |
| :--- | :--- |
| **已知方差 / 零值检验** | 若方差已知，在此填写；检验的理论值（$H_0$ 取值）也在本区域设定。 |
| **方差值** | 输入总体的已知方差精确数值（此时模型只估计均值）。 |

### 3. 条件 / 选项 (Options)

| 菜单项名称 | 含义与操作指导 |
| :--- | :--- |
| **置信区间百分比** | 实际为 **CrI（可信区间）**的水准，通常保持默认 95%。注意此处为软件翻译沿用习惯，非频率学概念。 |
| **缺失：按分析排除 / 按列表排除** | 成对删除（Pairwise） vs 整行删除（Listwise）。当有多个检验变量时影响有效样本量。 |

### 4. 数值方法 (Analysis Methods)

| 菜单项名称 | 含义与操作指导 |
| :--- | :--- |
| **自适应高斯-洛巴托求积(Q)** | (Adaptive Gauss-Lobatto Quadrature) 确定性数值积分方法，适合低维参数的标准模型。 |
| **容差 / 最大迭代** | 控制数值积分收敛的精度与计算时间。 |
| **蒙特卡洛近似值(A)** | (Monte Carlo Approximation) 利用随机抽样近似后验，复杂先验下的备用方案。 |
| **种子 / 蒙特卡洛样本数** | 设定随机数种子以保证**结果可复现**；样本数决定 MC 近似误差。 |

### 5. 正态先验子对话框 (Priors)

| 菜单项名称 | 含义与操作指导 |
| :--- | :--- |
| **方差(M) / 精度** | 参数化方式切换：方差 ($\sigma^2$) 还是精度 ($1/\sigma^2$)。 |
| **扩散** | (Diffuse) 即无信息先验，表示先验概率分布极为平缓，让“数据自己说话”。 |
| **形状 / 标度** | 设定方差先验为逆伽马分布 (Inverse-Gamma) 时的超参数 ($\alpha, \beta$)。 |
| **正态(N) / 扩散(D)** | 控制 $\mu$ 的先验是采用特定的正态分布（需填入先验均值），还是无信息扩散分布。 |
| **位置 / 标度** | 指定 $\mu$ 先验正态分布的具体均值（位置）与标准差（标度）。 |
| **将 Kappa 用于标度** | 根据设定的比例常数控制先验的集中度（查阅手册了解 $c \sigma^2$ 具体代数设定）。 |
