# 频率（Frequencies）

- **slug**: frequencies-spss
- **aliases**: 频数分析、FREQUENCIES
- **菜单**：**分析 → 描述统计 → 频率**（Analyze → Descriptive Statistics → Frequencies）

## 1. 回答什么问题

本过程是数据核查与描述性统计的核心枢纽。
- 对于**分类变量**或**离散取值较少**的连续变量，输出完整的频数分布表（包含频数、总百分比、**有效百分比**及累积百分比），并可生成**条形图**或**饼图**。其中“有效百分比（Valid Percent）”的计算精确依赖于系统缺失值与用户定义缺失值的设定。
- 对于**尺度（连续）变量**，可请求集中趋势、离散程度（如均值、标准差、分位数）、分布形态（偏度、峰度及其标准误），并输出附带正态曲线的**直方图**，主要用于**数据分布概览**与异常值诊断。

## 2. 不适用 / 易滥用

- **名义变量误算均值**：对无次序属性的分类变量（如“民族”编码 1/2/3）报告均值是严重的方法学错误。唯一的例外是 **0/1 编码的二分变量**（Dummy Variable），其均值具有明确的“比例（Proportion）”统计解释。
- **小样本下的形态统计量**：偏度（Skewness）与峰度（Kurtosis）的点估计在小样本（通常 $n < 50$）中极其不稳定，过度解读易导致对数据分布形态的误判。
- **忽视抽样权重**：对于来自复杂抽样设计（如分层、整群）的数据，未加权计算出的原始频数与总体比例推断可能存在系统性偏差。

## 3. 数据与设计前提

- **抽样设计独立性**：默认基于简单随机抽样（SRS）假设。复杂抽样设计必须在分析前配置**权重**（Weight Cases 或 Complex Samples 模块），并在报告中予以说明。
- **缺失值机制（重要）**：研究者需在数据字典中严谨区分**系统缺失（System Missing）**与**用户定义缺失（User Missing**，如用 99 代表“拒绝回答”）。Frequencies 过程的“有效百分比（Valid Percent）”严格以排除了这两类缺失值后的有效样本量为分母。
- **数据形态**：若是**组距编码**数据（如年龄段），可选用**组中值**参与数值型统计推断（详见附录）。

## 4. 模型或检验统计量（含推断铺垫逻辑）

虽然 Frequencies 过程本身以纯粹的描述统计为主，但其输出的统计量是后续假设检验的关键前置基础：
- **频数（$O_i$）**：是构建卡方检验（$\chi^2$）等非参数检验检验统计量的原始基石。
- **偏度与峰度标准误（SES / SEK）**：是描述分布形态的经验性工具。在适中的样本量下，若近似统计量 $Z = \text{Skewness} / \text{SES}$ 或 $Z = \text{Kurtosis} / \text{SEK}$ 的绝对值较大（如 $> 1.96$），可作为分布偏离正态的**描述性参考**。现代实践建议：**不以单一阈值机械决策**（如"Z>1.96 即转非参数"），应结合图形诊断（Q-Q 图、直方图）、效应量和研究目的综合判断。

## 5. 假设与诊断

| 环节 / 假设 | 检查方式 | 违背时的典型后果 / 修正路径 |
|------|----------|------------------|
| **编码与标签匹配** | 频数表交叉核对变量字典 | 产生无标签的幽灵类别；需返回清洗环节重新映射。 |
| **缺失值声明一致性** | 检查“系统缺失”与代码定义的频数 | 未声明用户缺失会导致（如代码 99）被视作合法数值计算均值，造成严重偏差。 |
| **分布合理性** | 极值（Min/Max）与频数分布 | 超出合理范围的异常录入（如年龄=999）将破坏后续所有的参数估计。 |

## 6. 效应量与区间

- 描述阶段通常直接报告**频数（$N$）、比例（$P$）**与**分位数**。
- Frequencies 过程不直接提供比例或均值的推断性置信区间（CI）。如需计算总体比例或均值的 CI，应移步 **Explore（探索）**、**Custom Tables（定制表格）** 或通过**Bootstrap（自助法）**模块获取。

## 7. 与相关方法的取舍

- **仅需连续变量摘要，无需频数表**：对于包含大量唯一值的连续变量，生成全频数表不仅耗时且无意义。此时应改用 **Descriptives（描述）** 或 **Explore（探索）** 过程。
- **多组别的特征比较**：如果需要按某分组变量（如性别）拆分描述，应使用 **Compare Means（比较均值）**、**Crosstabs（交叉表）** 或 **Split File（拆分文件）** 功能，而非反复执行单独的 Frequencies 过程。

## 8. 实现速查

- **SPSS**：语法 `FREQUENCIES VARIABLES= Var1 Var2 /STATISTICS= MEAN STDDEV SKEWNESS KURTOSIS /ORDER=ANALYSIS.`
- **R**：
  - 类别变量推荐：`janitor::tabyl(df, var)` （完美复刻 SPSS 的 N, Percent, Valid Percent 结构）。
  - 基础函数：`table()`, `prop.table()`, `quantile()`。连续变量推荐 `psych::describe()`。
- **Python**：
  - `pandas.Series.value_counts(dropna=False, normalize=True)`（`dropna=False` 是获取含缺失“总百分比”的关键，区分于默认的“有效百分比”）。
  - 连续变量：`Series.describe()`，分布形态：`Series.skew()`, `Series.kurt()`。

## 9. 报告清单

撰写学术论文时，通常采用 APA（American Psychological Association）或同等学术格式要求：
- **分类变量**：报告频数（$N$ 或 $n$）与有效百分比（%）。明确说明缺失值的处理情况。
- **连续变量**：报告样本量（$N$）、均值（*M*）、标准差（*SD*）、极值或分位数。均值和标准差使用斜体符号。
- **分布形态**：若需报告偏度和峰度，必须附注相应的样本量及软件版本（不同软件如 SPSS、SAS、R 对于峰度的默认计算公式有“过度峰度（Excess Kurtosis）”与“绝对峰度”之分），并保持小数位数统一（通常为 2 位或 3 位）。

## 10. 参考文献与手册

- **教材**：Howell, D. C. (2012). *Statistical Methods for Psychology* (8th ed.). Cengage Learning. (参见描述统计与分布探索相关章节)
- **软件文档**：IBM SPSS Statistics Algorithms (当前使用版本的 Base 模块，FREQUENCIES 词条，用于核对偏度与峰度的精确渐近方差公式)。

## 附录：核心子对话框选项深度解析

### A. 「统计 (Statistics)」子对话框

**百分位值 (Percentile Values)**
| 界面选项 | 统计学含义 |
|------|------|
| **四分位数** | 输出 $P_{25}$、$P_{50}$ (中位数)、$P_{75}$ |
| **分割点 + 相等组** | 基于等频逻辑的分位点（如输入 10 即输出十分位数） |
| **百分位数 + 添加** | 用户自定义任意分位数（如 5, 95, 99） |

**集中趋势 (Central Tendency) 与离散程度 (Dispersion)**
| 界面选项 | 统计学含义 |
|------|------|
| **平均值 (Mean)** | 算术平均。名义变量慎用。 |
| **中位数 (Median) / 众数 (Mode)** | 分别对应 $P_{50}$ 及频次最高的类别。 |
| **值为组的中点** | 对组距编码的数据，强行使用组中值进行数值型统计逼近。 |
| **标准差 (Std. deviation) / 方差 (Variance)** | 默认使用 $(n-1)$ 作为无偏估计的分母。 |
| **标准误差平均值 (S.E. mean)** | 公式为 $s/\sqrt{n}$，用于衡量样本均值估计的精度。 |
| **范围 / 最小值 / 最大值** | $\text{Max} - \text{Min}$ 及极值，数据清洗时核查越界值的首选指标。 |

**分布形态 (Distribution)**
| 界面选项 | 统计学含义 |
|------|------|
| **偏度 (Skewness)** | 衡量分布不对称性。输出表中会自动附带偏度标准误 (SES)。 |
| **峰度 (Kurtosis)** | 衡量分布尾部的厚度（相对正态分布）。输出表附带峰度标准误 (SEK)。注意：SPSS 默认输出的是“过度峰度 (Excess Kurtosis)”，即正态分布的期望值为 0。跨软件对比需查阅文档。 |

### B. 「图表 (Charts)」子对话框
* **条形图 (Bar charts)**：适用于类别有限的名义/有序变量。
* **饼图 (Pie charts)**：用于展示各部分占总体比例，类别数较多时（>5个）不推荐。
* **直方图 (Histograms)**：专用于连续变量，可勾选“在直方图上显示正态曲线 (Show normal curve)”用于视觉化检验正态性假设。

### C. 「格式 (Format)」子对话框
对于长尾分类变量（如：疾病编码、地区列表），推荐将排序方式（Order by）从默认的“按值升序 (Ascending values)”更改为**“按频率降序 (Descending counts)”**，可显著提升报表在阅读和清洗高频/低频错误时的效率。
