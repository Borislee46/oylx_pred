# 独立样本 t 检验 / Student's two-sample t-test

- **slug**: independent-samples-t
- **aliases**: 两样本 t、成组 t、between-subjects t；勿与配对 t 混淆

## 1. 回答什么问题

在两组**独立**单位上，比较连续型结果变量的**总体均值差**是否异于 0（或检验差值是否等于某先验值）。推断对象通常是**有限总体在随机抽样下**的均值差，或实验中**随机化分配**带来的因果均值差（因果解释高度依赖实验设计，而非统计方法本身）。

## 2. 不适用 / 易滥用

- **同一被试前后测、配对部位、匹配设计**：违反独立性假设。应使用**配对 t 检验**或混合模型。
- **多组比较（≥3组）**：反复进行两两 t 检验会导致**族错误率（Family-wise error rate, FWER）严重膨胀**。应使用 **ANOVA / 线性模型 + 适当的事后多重比较矫正**（如 Tukey, Bonferroni）。
- **严重偏态与极端离群值**：若样本量较小，均值易受极端值拉扯。此时可考虑**稳健统计（如 Yuen's 切尾 t 检验 / Trimmed t-test）**或**非参数检验**（注意：Mann-Whitney U 检验对比的是分布位置/随机占优，而非均值，二者解释具有本质区别）。
- **组内相关性（如嵌套/聚类、重复测量）**：独立样本 t 检验的 i.i.d.（独立同分布）前提不成立。需使用**多层线性模型（HLM / LMM）或广义估计方程（GEE）**。

## 3. 数据与设计前提

- **两组分配**：常见为实验随机分组或观察性截面两组。若存在混杂变量（Covariates），t 检验内部无法进行「调整」，需改用协方差分析（ANCOVA）或多元回归。
- **结果变量**：在区间（Interval）或比例（Ratio）尺度上可视为连续变量。若为离散分类计数，应使用列联表分析、对数线性模型或逻辑回归。

## 4. 模型与检验统计量

- **Welch's t 检验（现代统计学强烈推荐的默认方法）**：
  **不假定两组方差相等**。直接使用各组方差计算标准误，自由度（df）使用 Satterthwaite 近似公式向下调整，可能为小数。在方差齐性时效能与经典 t 检验几乎无异，在方差不齐时能严格控制第一类错误率。
  $$t = \frac{\bar{x}_1 - \bar{x}_2}{\sqrt{\frac{s_1^2}{n_1} + \frac{s_2^2}{n_2}}}$$
- **经典 Student's t 检验（历史遗留的默认方法）**：
  **假定等方差**。使用合并方差（Pooled variance, $s_p^2$），$t = \frac{\bar{x}_1-\bar{x}_2}{s_p\sqrt{1/n_1+1/n_2}}$，自由度为 $n_1+n_2-2$。当两组样本量相差较大且方差不齐时，该方法第一类错误率会严重失控。

## 5. 假设与诊断

现代统计实践中，最大的误区是「先合并两组数据做正态检验」，以及「先看 Levene 检验决定用哪种 t 检验（两步法陷阱）」。

| 假设 | 正确检查方式 | 违背时的典型后果与对策 |
|------|----------|------------------|
| **独立性** | 依据研究设计审查；若有时间/空间序列则检查残差自相关。 | 第一类错误率失控。对策：改用混合模型或重复测量分析。 |
| **正态性** | 分别对**各组内部**数据绘制 Q-Q 图，或直接检查**整体模型残差**的正态性。 | 小样本下显著性偏离。**补充：** 大样本（通常每组 $n > 30$）得益于中心极限定理，t 检验对轻微偏离正态极具鲁棒性。Shapiro-Wilk 在大样本下过于敏感，建议以可视化为主。 |
| **方差齐性** | 可视化（箱线图/小提琴图）；Levene 检验。 | 若误用经典 t，第一类错误率失控。**现代对策：放弃两步法测试，无论方差是否齐性，直接默认报告 Welch's t 检验。** |

## 6. 效应量与区间估计

仅报告 p 值不足以说明效应的实际意义，需同时报告：
- **均值差的 95% 置信区间（CI）**：解释时需回归原始物理/心理学尺度。
- **Cohen's d（标准化均值差）**：经典计算以合并标准差（Pooled SD）为分母。解释时需结合特定领域的经验分布，切忌机械套用「0.2小、0.5中、0.8大」的经验法则。
- **方差不齐时的调整**：当由于方差严重不齐而采用 Welch t 检验时，合并标准差可能失去基准意义。建议改用 **Glass's $\Delta$**（仅以对照组/基线组的标准差作为分母），或报告基于 Welch 自由度调整的 $d$ 值。

## 7. 与相关方法的取舍与拓展

- **与回归/GLM**：当分组变量编码为二元哑变量（Dummy variable）时，等方差 t 检验与简单线性回归的斜率系数检验完全等价。这一视角有助于平滑过渡到包含协变量的多元模型。
- **与非参数检验（Mann–Whitney U）**：当关心均值且样本量中等偏上时，即使偏态也可优先考虑**变量转换**或**稳健自助法（Bootstrapping）**，而非盲目降级为非参数检验。
- **贝叶斯推断拓展（Bayesian t-test）**：现代顶刊常要求评估原假设的证据强度。可通过计算**贝叶斯因子（$BF_{10}$）**，量化数据支持备择假设相对于原假设的程度（例如 $BF_{10} = 5$ 意味着数据支持有差异的强度是无差异的 5 倍）。

## 8. 实现速查

- **R**：基础包 `t.test(y ~ group, data = d, var.equal = FALSE)` 默认即为 Welch 检验；若需经典 t 设定 `var.equal = TRUE`。效应量非自带，建议使用 `effectsize::cohens_d()` 或 `rstatix::cohens_d()` 快速获取。
- **Python**：基础方法 `scipy.stats.ttest_ind(a, b, equal_var=False)` 对应 Welch。**推荐科研首选 `pingouin` 库**：执行 `pingouin.ttest(x, y)`，可一步输出带 Welch 调整的 t值、p值、贝叶斯因子、Cohen's d 和 CI，极其适合学术报告。
- **SPSS**：分析 → 比较平均值 → **独立样本 T 检验**。现代版本（27+）在「贝叶斯比例」模块下也原生支持计算贝叶斯因子。

## 9. 报告清单

可复现与可发表的报告应包含以下要素：
1. **描述性统计**：各组的样本量（$n$）、均值（$M$）、标准差（$SD$）。
2. **检验类型与统计量**：明确声明使用了 Welch 检验（或说明满足方差齐性后使用经典 t）。
3. **检验结果**：$t$ 值、自由度（Welch 下保留两位小数）、精确 $p$ 值（如 $p = .034$，而非 $p < .05$；若极小则报 $p < .001$）。格式如：$t(45.23) = 2.65, p = .011$。
4. **效应度量**：原始均值差及其 95% CI，标准化效应量（Cohen's $d$ 或 Glass's $\Delta$）。
5. **前提声明**：简述正态性或异方差的诊断方式及处理策略。观察性研究需避免使用「证明因果」、「导致」等词汇。

## 附录：SPSS 输出阅读要点与防坑指南

- **避免「Levene 显著才读下行」的两步法陷阱**：SPSS 的输出表格常包含「假定等方差」和「不假定等方差」两行。由于 Levene 检验在小样本下效能不足（最需要校正时查不出异方差），在大样本下过于敏感，**统计学界目前强烈建议：直接略过 Levene 检验的结果，永远读取第二行「不假定等方差」（Welch–Satterthwaite）的结果**。
- **自由度带小数**：当读取第二行时，df 通常为小数，这是 Satterthwaite 近似计算的正常现象，直接如实报告即可，切勿自行四舍五入。
- **自动化语法 (Syntax)**：
  ```spss
  T-TEST GROUPS=GroupVar(1 2) 
    /MISSING=ANALYSIS 
    /VARIABLES=OutcomeVar 
    /CRITERIA=CI(.95).
  ```
  *(注：分组变量 `GroupVar` 后括号内的数字需根据实际数据的编码替换)*
