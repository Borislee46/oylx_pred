# 分类（Classify）— 菜单总览

- **slug**: classify-menu-spss
- **菜单**：**分析 → 分类**（Analyze → Classify）
- **说明**：此菜单集成了模式识别中的两大核心任务。子项的呈现或命名（如 ROC 分析）因 SPSS 版本而异；**聚类轮廓**（Cluster Silhouettes）通常作为二阶聚类或 K-均值聚类的辅助输出图表出现。

## 1. 回答什么问题

本菜单下的方法旨在解决数据的“分组”与“归类”问题，从统计学习角度可分为两大类及一类评估工具：
- **无监督学习（聚类探索）**：在无预先已知标签的情况下，基于特征相似性发现数据内部的潜在群组结构（**二阶聚类、K-均值聚类、系统聚类**），并评估分类质量（**聚类轮廓**）。
- **有监督学习（分类预测）**：基于已带有明确组别标签的训练数据，建立分类规则，以预测新样本的归属（**判别分析、决策树、最近邻**）。
- **模型评估**：量化并比较二分类预测模型的区分能力，或确定最佳截断值（**ROC 曲线 / ROC 分析**）。

## 2. 不适用 / 易滥用

- **聚类无真标签的评估谬误**：由于聚类属无监督方法，**绝对不可**使用 ROC 曲线评估聚类效果。聚类质量应依赖**稳定性测试、轮廓系数（Silhouette）及领域内的可解释性**。
- **K-均值聚类（K-Means）的距离失真**：该算法强依赖欧氏距离，强制要求数据为连续型数值变量。若各变量**尺度（量纲）未统一**，距离计算将严重失真，必须提前进行 **Z-score 标准化**。同时，其对异常值极度敏感，且必须人为预设类数 $k$。
- **系统聚类（Hierarchical）的算力瓶颈**：其时间复杂度通常为 $O(n^3)$，**仅适用于小样本**，大样本下极易导致内存溢出或计算停滞；其优势在于无需预先指定 $k$。
- **决策树的过拟合**：树模型若不加限制，会持续分裂直至每个叶节点极其纯粹，导致严重的过拟合。必须设定**停止规则、剪枝策略**，并使用**验证集**进行评估。
- **判别分析 vs. Logistic 回归**：判别分析对数据分布有严格的参数假设（多元正态、等协方差）；若假设严重违背，应转向更为稳健的 Logistic 回归。

## 3. 数据与设计前提

- **可重复性控制**：对于涉及随机过程的算法（K-均值初始中心选择、决策树构建、kNN 随机平局打破、训练/验证集划分），**必须在软件中显式设置固定的随机种子（Random Seed）**，以确保结果可复核。
- **数据划分**：有监督分类必须将数据合理划分为**训练集（Training）**与**验证/测试集（Validation/Testing）**，避免在同一数据集上训练和评估导致性能虚高。
- **缺失值与异常值**：聚类与基于距离的模型（kNN）对异常值敏感，需事先进行清洗或截断；缺失值处理策略（如多重插补或列表删除）需在全样本中保持一致。
- **变量标准化**：所有依赖距离度量的方法（K-均值、系统聚类、kNN）通常要求特征处于同一量纲。

## 4. 模型或检验统计量

*（注：此处仅列核心统计量，具体公式、推导与自由度逻辑详见附录各子方法卡片）*

- **聚类评估**：
  - **类内平方和（WCSS）**：衡量聚类紧凑度（越小越好）。
  - **轮廓系数（Silhouette Coefficient）**：结合类内紧凑度与类间分离度，范围 $[-1, 1]$，接近 1 表示聚类合理。
- **判别分析**：
  - **Wilks' $\Lambda$**：检验各组在判别函数上的均值差异（越小差异越大）。
  - **F 统计量**：用于评估单个变量对组间分离的贡献。
- **决策树**：基于节点不纯度下降准则（如 CHAID 的**卡方检验**、C&RT 的 **Gini 指数**或**信息增益**）。
- **ROC 分析**：
  - **AUC（曲线下面积）**：评估整体分类性能。
  - **DeLong 检验**：用于统计学上比较两个相关 ROC 曲线（多分类器）的 AUC 差异（SPSS 26+ ROC Analysis 模块支持）。

## 5. 假设与诊断

*（注：无监督与有监督算法的前提差异巨大，以下为最容易导致模型失效的核心诊断点）*

| 方法与核心假设 | 检查与诊断方式 | 违背时的典型后果 | 补救/替代路径 |
| :--- | :--- | :--- | :--- |
| **经典判别：多元正态** | 多元 Q-Q 图、Shapiro-Wilk 检验 | 分类边界扭曲，错分率升高 | 稳健判别、Logistic 回归 |
| **经典判别：等协方差矩阵** | **Box's M 检验**（敏感度高，大样本易显著） | 线性判别（LDA）失效且偏向大样本组 | 改用二次判别（QDA）或 Logistic |
| **kNN：无参数（依赖距离）** | 检查特征维度与量级差异 | **维数灾难**，噪声特征主导距离计算 | 降维（PCA）、严格特征选择与标准化 |
| **决策树：样本独立同分布 (IID)** | 检查数据是否存在时间序列或空间自相关 | 严重的数据泄漏（Data Leakage）与过拟合 | 采用时序交叉验证、混合效应树 |

## 6. 效应量与区间

- **分类预测模型**：
  - **AUC 及其 95% 置信区间 (CI)**：报告精度的核心指标（0.5 为随机，1.0 为完美）。
  - **混淆矩阵推导指标**：**准确率（Accuracy）、敏感度（Sensitivity/召回率）、特异度（Specificity）**。需注意在类不平衡数据中，单纯的准确率具有欺骗性。
- **聚类模型**：
  - **轮廓均值（Mean Silhouette）**：整体聚类质量度量。
  - **类内直径/质心距离**：描述类的物理边界与中心。

## 7. 与相关方法的取舍

- **神经网络 (Neural Networks) 与 Logistic 回归**：均位于 SPSS 的其他独立菜单，但同属有监督分类。Logistic 适用于需要高解释性与推断变量效应的场景；神经网络适用于处理高度非线性的复杂模式，但属“黑盒”模型；判别/树介于两者之间。
- **无监督到有监督的探索链**：一种常见的探索性研究范式是：先用**聚类**发现未知亚型，将聚类结果作为标签，再运行**判别分析或决策树**（事前判定/事后解释），以提取区分亚型的关键业务规则。
- **混合模型 (Mixture Models)**：如果聚类假设数据由多个概率分布（如高斯混合模型 GMM）叠加而成，而非简单的几何距离，应考虑使用潜类别分析（LCA）或有限混合模型。

## 8. 实现速查

- **SPSS 语法**：`TWOSTEP CLUSTER`（二阶）、`QUICK CLUSTER`（K-均值）、`CLUSTER`（系统聚类）、`TREE`（决策树）、`DISCRIMINANT`（判别分析）、`KNN`（最近邻）、`ROC`。
- **R 语言**：`stats::kmeans`、`stats::hclust`、`rpart::rpart`、`class::knn`、`pROC::roc` / `pROC::roc.test` (DeLong检验)。
- **Python (scikit-learn)**：`sklearn.cluster`、`sklearn.tree`、`sklearn.neighbors`、`sklearn.discriminant_analysis`、`sklearn.metrics.roc_auc_score`。

## 9. 报告清单

在撰写学术论文的「统计方法」与「结果」部分时，应当逐项核对报告以下细节：

*   **数据预处理**：
    *   明确报告用于保障可重复性的**随机种子（Random Seed）**。
    *   明确变量的尺度转换或**标准化方法**（如 Z-score）。
    *   **验证策略**：报告训练集与验证集的划分比例（如 70/30）或交叉验证折数。
*   **聚类分析（无监督）**：
    *   距离度量方式（如欧氏距离、曼哈顿距离）。
    *   聚类算法与连接法（如系统聚类的 Ward 法）。
    *   最终确定的类数 $k$ 的**选择依据**（如轮廓系数峰值、肘部法则、业务可解释性）。
*   **预测分类（有监督）**：
    *   **判别**：先验概率的设定（相等或基于样本量计算）、协方差矩阵检验结果。
    *   **树模型**：具体算法（CHAID / C&RT）、分裂准则、最小节点样本数限制及剪枝策略。
    *   **kNN**：最近邻数 $k$ 的调参依据及距离度量公式。
*   **模型评估**：
    *   测试集/验证集上的**混淆矩阵**（必须包含敏感度、特异度或 F1-Score）。
    *   **ROC 分析**：报告最佳截断值（Cut-off）的选择准则（如 Youden 指数），以及带 95% CI 的 AUC 值。若比较多个模型，需报告 DeLong 检验的 $p$ 值。
