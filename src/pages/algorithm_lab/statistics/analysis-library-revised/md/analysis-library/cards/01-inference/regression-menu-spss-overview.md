# 回归（Regression）— 菜单总览

- **slug**: regression-menu-spss
- **aliases**: REGRESSION, LOGISTIC, PLUM, NLR
- **菜单**：**分析 → 回归**（Analyze → Regression）
- **说明**：此菜单为 SPSS 中最核心的建模枢纽。具体子项是否可见，取决于所安装的 SPSS 版本及授权模块（如 CATREG 依赖 Categories 模块）。**注意：计数型结局（泊松/负二项回归）不在本菜单，需转至“广义线性模型”菜单。**

## 1. 回答什么问题

本菜单下的过程旨在探究**解释变量（预测变量，\(X\)）**与**因变量（结局变量，\(Y\)）**之间的统计关联或进行预测。按**因变量的数据类型与研究目的**，可分为以下几类核心路径：
- **连续均值结构**：普通多元线性回归（Linear）、单变量曲线拟合（Curve Estimation）、处理高维共线性的偏最小二乘（PLS）。
- **分类与有序结构**：二分类（Binary Logistic、Probit）、无序多分类（Multinomial Logistic）、有序多分类（Ordinal）。
- **分布特征与非线性设定**：探究条件分位数特征（Quantile）、指定显式非线性函数形式（Nonlinear）。
- **因果推断与特定数据结构**：处理内生解释变量的两阶段最小二乘（2SLS）、针对分类预测变量进行最优量化的分类回归（CATREG）。

## 2. 不适用 / 易滥用

- **自动线性建模（Automatic Linear Modeling）的过度解释**：该过程包含自动变量筛选、离群值处理与数据变换，本质属于**探索性数据分析（EDA）**。若无**独立的验证集（Validation set）**，其直接输出的 \(p\) 值与效应量极易因“过拟合（Data leakage/Overfitting）”而严重失真，禁止直接作为确证性假设检验的结论报告。
- **线性回归用于严重偏态或有界结局**：若因变量为严格非负的计数数据、过度偏态或存在明显的上下限边界，使用普通最小二乘法（OLS）会导致预测值越界或违背同方差假设。应转用 **广义线性模型（GENLIN）**。
- **忽略数据的层级/重复测量结构**：若样本存在嵌套（如学生嵌套于班级）或重复测量（纵向数据），残差独立的假设被打破。继续使用普通回归会导致标准误被严重低估（Type I 错误率激增），应改用 **混合模型（MIXED / GLMM）**。
- **混淆 PLS 的预测导向与推断导向**：偏最小二乘回归（PLS）主要用于高维数据（\(p > n\)）下的**预测**。其提取的潜变量成分难以直接赋予清晰的理论解释，且其系数的假设检验逻辑与 OLS 不同，不适用于传统的单变量因果推断。

## 3. 数据与设计前提

- **样本量（自由度消耗）**：
  - **线性模型**：通常要求 \(n > 50 + 8k\)（\(k\) 为预测变量数）以保证估计的稳定性。
  - **Logistic 等非线性模型**：依赖最大似然估计（MLE），需满足“每个预测变量对应至少 10-15 个事件（EPV, Events Per Variable）”的经验法则，否则易出现极大标准误（分离现象/准分离现象）。
- **缺失值机制**：SPSS 默认多为“列表删除（Listwise deletion）”。若缺失比例高且非完全随机缺失（MCAR），列表删除会引入选择偏倚。需在“选项”中明确处理策略，或在建模前进行**多重插补（Multiple Imputation）**。

## 4. 模型或检验统计量（含自由度逻辑）

- **OLS（多元线性）**：整体模型适配度依据 \(F\) 检验；单个系数依据 \(t\) 检验；解释力度依据 \(R^2\) 与调整后 \(R^2\)。
- **Logistic（二元/多元/有序）**：整体模型使用似然比检验（Likelihood Ratio Test, 渐近 \(\chi^2\) 分布）；单个系数依赖 Wald \(\chi^2\) 检验；解释力度参考各种**伪 \(R^2\)**（如 Cox & Snell, Nagelkerke）。
- **分位数回归（Quantile）**：采用单纯形法（Simplex）或内点法等线性规划算法求解；推断默认依赖渐近分布假设，小样本下建议选用自助法（Bootstrapping）估计标准误。
- **2SLS（两阶段最小二乘）**：统计量的有效性极其依赖于**工具变量（IV）**的两个前置条件：相关性（与内生变量强相关，防范弱工具变量问题）与外生性（与误差项不相关）。

## 5. 假设与诊断

下表归纳了本菜单下主流过程的核心统计假设、诊断方法及违背后果：

| 假设/前提 | 检查方式 | 违背时的典型后果 | 对应主要子过程 |
|------|----------|------------------|----------------|
| **残差独立** | Durbin-Watson 统计量、残差时间序图 | 标准误被低估，假阳性率（Type I 错误）膨胀 | 线性回归等 |
| **同方差性** | 残差-预测值散点图、Breusch-Pagan 检验 | OLS 估计效率下降，置信区间（CI）失准 | 线性回归等 |
| **线性/链接正确** | 残差图、ROC 曲线、校准曲线（Calibration） | 模型设定错误，预测偏误与推断失真 | 线性、Logistic |
| **比例优势假设** | 平行线检验（Test of Parallel Lines） | 模型设定失效，各层级的真实关系被掩盖 | 有序多分类（Ordinal） |
| **内生性（观察性研究）**| 理论设计辩护、Hausman 检验 | OLS/Logit 系数产生**有偏且不一致**的估计 | 2SLS |
| **无严重多重共线性** | VIF（方差膨胀因子）、容忍度、条件指数 | 系数极不稳定，方向甚至反转，检验效能锐减 | 多元线性、Logistic |

## 6. 效应量与区间

- **OLS**：报告非标准化系数（原始尺度）、**标准化系数（\(\beta\)）**（比较相对重要性）及效应量偏 \(\eta^2\) 或 \(R^2\) 变化量（\(\Delta R^2\)）。
- **Logistic**：核心效应量为 **优势比（OR, Odds Ratio）** 及其 **95% 置信区间（CI）**。
- **分位数回归**：报告特定分位数（如中位数 \(\tau=0.5\)）下的**分位斜率**及由 Bootstrapping 产生的 CI。

## 7. 与相关方法的取舍

- **GENLIN（广义线性模型）**：本菜单下的 Logistic、Probit 等在数学原理上属于 GLM 框架，与 `分析 → 广义线性模型` 跑出的系数与标准误在同等设定下**常数值等价**。但 GENLIN 界面提供了更底层的分布与链接函数组合（如**泊松分布**、**负二项分布**均只能在 GENLIN 中实现）。
- **共线性处理手段比较**：面对严重共线性的高维数据，除本菜单提供的 **PLS** 外，研究者常需评估以下策略：
  - **岭回归（Ridge）/ Lasso**：以引入偏差为代价降低方差，兼具变量筛选功能（可通过 SPSS 扩展包 `Ridge/Lasso` 实现）。
  - **主成分回归（PCR）**：先降维再 OLS，与 PLS 类似但 PCR 不考虑 \(Y\) 的信息，PLS 提取成分时同时最大化解释 \(X\) 和 \(Y\)。
- **混合模型（Mixed Models）**：遇到纵向追踪数据或多中心数据，应舍弃本菜单，转至 `分析 → 混合模型` 以拟合随机效应。

## 8. 等效实现与速查

- **SPSS 语法**：`REGRESSION` (线性), `LOGISTIC REGRESSION` (二元), `NOMREG` (多元), `PLUM` (有序), `NLR` (非线性), `2SLS`, `QUANTILE REGRESSION` 等。*(注：部分模块如 QUANTILE 需 v24 及以上版本，CATREG 需 Categories 模块)*。
- **R 等效实现**：
  - `stats::lm` (线性), `stats::glm` (Logistic/Probit), `stats::nls` (非线性)。
  - `quantreg::rq` (分位数回归)。
  - `ivreg::ivreg` (或使用 `AER`, `systemfit` 处理多方程 2SLS)。
  - `MASS::polr` (有序), `nnet::multinom` (无序多分类)。
- **Python 等效实现**：
  - `statsmodels.api` 提供 OLS、GLM、Logit、QuantReg 等严谨统计推断实现。
  - `scikit-learn` 提供偏预测导向的 PLS、Logistic 回归（默认带 L2 正则化，需注意）。
  - `linearmodels` 提供 2SLS 等工具变量推断。

## 9. 报告清单（Reporting Checklist）

向期刊投稿时，科研级的方法学报告应涵盖：
1. **过程名、软件版本与估计算法**（如 OLS 还是 MLE，是否使用 SPSS v28 的稳健标准误选项）。
2. **缺失值处理策略**（如列表删除、均值替换或多重插补）。
3. **因变量的具体编码与参考水平**（尤其针对 Logistic 回归，必须明确谁是 Baseline）。
4. **模型检验与诊断结果**（如 D-W 统计量、VIF 范围、平行线检验 \(p\) 值）。
5. **点估计与不确定性**：未标准化系数、标准化系数 / OR 值及其对应的不确定性（**95% CI**）与确切的 \(p\) 值。
6. **模型比较/解释度**：整体 \(F\) 检验或似然比检验结果，\(R^2\) 或伪 \(R^2\)，嵌套模型间的 \(\Delta R^2\)。
7. **探索性声明**：若使用了自动线性建模或逐步回归（Stepwise），需明确报告其为探索性分析，并详述交叉验证或独立验证集的结果。

## 附录：子菜单一览与选用决策路线

### 附表 A：菜单子项一览

| 子项（中文版意译） | 英文界面原名 | 核心功能一句话总结 |
|--------------|------------|--------|
| **自动线性建模** | Automatic Linear Modeling | 自动筛选特征与数据变换；探索性极强，极易过拟合，需严格验证。 |
| **线性** | Linear | OLS 多元线性回归，基础建模核心。 |
| **曲线估算** | Curve Estimation | 用于单变量 \(X\) 的多项式或特定曲线族（如对数、指数）拟合。 |
| **偏最小二乘** | Partial Least Squares (PLS) | 应对极度共线性或高维变量，提取潜变量进行预测。 |
| **二元 Logistic** | Binary Logistic | 针对二分类 \(Y\) 的 Logit 链接函数极大似然估计。 |
| **多元 Logistic** | Multinomial Logistic | 针对无序、名义多分类 \(Y\) 的建模（自动设立参考组）。 |
| **有序** | Ordinal | 针对等级/有序数据 \(Y\) 的建模，依赖比例优势假设。 |
| **概率** | Probit | 与 Logistic 类似，但采用标准正态累积分布函数作为链接（常用于生物测定/毒理）。 |
| **非线性** | Nonlinear | 用户自定义复杂的显式非线性函数表达式（即 \(y=f(X,\beta)\)），采用迭代算法求解。 |
| **权重估算** | Weight Estimation | WLS（加权最小二乘法），用于已知异方差结构的纠正。 |
| **二阶最小二乘** | 2-Stage Least Squares (2SLS)| 引入工具变量（IV），分两阶段回归以消除内生性带来的估计偏误。 |
| **分位数** | Quantile | 估计 \(X\) 对 \(Y\) 不同条件分位数（而非均值）的影响，对异常值稳健。 |
| **最优标度 / CATREG** | Optimal Scaling (CATREG) | 将名义/有序分类预测变量进行最优量化赋值后的回归分析。 |

### 附表 B：因变量类型 → 常规决策起点

| 因变量 \(Y\) 类型 | 常规首选过程 | 备用或拓展过程 |
|------------|------|--------|
| 连续、近似正态、独立 | **线性 (Linear)** | 若不满足同方差：加权 (WLS)<br>若关注极值/尾部：分位数 (Quantile) |
| 二分类 (0/1) | **二元 Logistic** | **概率 (Probit)** |
| 有序多分类 (如 Likert 量表) | **有序 (Ordinal)** | 若平行线假设严重不满足：降级使用 多元 Logistic |
| 名义多分类 (无固定大小顺序)| **多元 Logistic** | 无 |
| 连续但受制于强烈内生性 \(X\)| **二阶最小二乘 (2SLS)** | 无 |
| 高维预测变量，强共线性 | **偏最小二乘 (PLS)** | SPSS 扩展包中的 Ridge/Lasso |
| 连续，但大量分类预测变量需要赋值 | **最优标度 (CATREG)** | 对所有分类变量做哑变量化后使用线性回归 |
| 计数型结局 (非负整数，如次数) | **(不在本菜单)** | 必须转至 **广义线性模型 (GENLIN) -> 泊松/负二项** |
