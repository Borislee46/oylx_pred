# Q-Q 图（Q-Q Plots）

- **slug**: qq-plot-spss
- **aliases**: 分位数-分位数图、正态 Q-Q 图
- **菜单**：**分析 → 描述统计 → Q-Q 图**（Analyze → Descriptive Statistics → Q-Q Plots）
- **与 P-P 图的对照**：**P-P 图**比较的是**累积概率**（对分布中部的偏离更敏感）；**Q-Q 图**比较的是**分位数**（对分布**尾部的偏离更敏感**）。两者对话框选项基本同构。

## 1. 回答什么问题

Q-Q 图是一种探索性数据分析（EDA）工具，用于通过视觉检验样本分布是否与**理论分布**（如正态分布、指数分布、伽马分布等）相符。

它将样本的分位数与指定的理论分布分位数绘制在散点图中。如果样本数据来自该理论分布，图中的点应紧密地分布在一条对角**参考直线**附近。

## 2. 不适用 / 易滥用

- **样本量过小的误判（$n < 20$）**：由于随机抽样误差，小样本的 Q-Q 图即使来自完美正态分布，也常呈现出剧烈的随机波动，容易导致「误拒」正态性。
- **样本量过大的过度敏感（$n > 1000$）**：大样本下，轻微且在实际研究中可忽略的偏离也会在视觉上显得非常清晰。需结合实际研究背景判断偏离的实质意义。
- **离散变量或强结（Ties）变量**：若数据为定序变量或存在大量相同数值（结），图中会出现阶梯状或水平线段。此时尾部偏离的解读需极度谨慎，应结合测量精度与结处理方式综合判断。
- **重复作为独立证据**：在 SPSS 的「探索（Explore）」功能中勾选「含检验的正态图」所生成的 Q-Q 图，与此菜单生成的 Q-Q 图本质相同，不可在论文中当作两条独立的假设检验论据。

## 3. 数据与设计前提

- **数据类型**：主要用于**连续型（尺度）变量**。名义（分类）变量不适用 Q-Q 图。
- **独立同分布假设（i.i.d.）**：图形解读的前提是样本点是独立抽取的。对于**时间序列数据**，由于存在自相关，通常需要先进行**差分或季节差分**（见附录），使残差序列平稳后再绘制 Q-Q 图进行正态性检验。

## 4. 模型与检验统计量

Q-Q 图本身是**描述性（图形诊断）** 工具，不产生单一的假设检验 $p$ 值。
在构建图形时，理论分位数通常需要通过**比例估算公式**（如 Blom 公式 $\frac{r - 3/8}{n + 1/4}$，其中 $r$ 为秩次，$n$ 为样本量）来近似计算。
是否在输出图形的同时配合输出正态性检验（如 Shapiro-Wilk 或 K-S 检验），取决于具体的软件界面与版本。

## 5. 假设与诊断（核心读图指南）

Q-Q 图的形状解读**高度依赖于坐标轴的设定**。**SPSS 的默认设定为：X 轴为理论分位数（Expected），Y 轴为实际观测值（Observed）。**
在此前提下，偏离参考直线的典型形态对应如下诊断：

| 图形形态（X轴=理论，Y轴=观测） | 统计学含义 | 诊断说明与后果 |
| :--- | :--- | :--- |
| **U 型**（下凸） | **右偏**（正偏态） | 数据高端有长尾；可能需要对数或平方根变换。 |
| **倒 U 型**（上凸） | **左偏**（负偏态） | 数据低端有长尾；可能需要平方或指数变换。 |
| **S 型**（两端陡峭偏离） | **重尾**（峰度 $> 0$） | 极端值比理论分布更多（如近似 t 分布）；增加离群值风险。 |
| **反 S 型**（两端平缓交叉）| **轻尾**（峰度 $< 0$） | 数据分布比理论分布更集中且极端值少（近似均匀分布）。 |

### 进阶诊断：去趋势 Q-Q 图（Detrended Q-Q Plot）
SPSS 默认会随附输出一张「去趋势正态 Q-Q 图」。
- **图意**：该图将参考直线「拉平」为 X 轴。Y 轴展示的是**观测值与理论参考线之间的残差（差值）**。
- **解读**：如果数据完美符合理论分布，点应当在 $Y=0$ 的水平线附近呈**无规律的随机散布**。若出现明显的系统性模式（如抛物线、波浪线或明显的漏斗状异方差），则提示偏离该分布，可放大局部偏离细节。

## 6. 效应量与不确定性表达

- **效应量**：图形诊断通常不报告单一的效应量。少数文献会报告样本分位数与理论分位数之间的**相关系数（$r$）**，越接近 1 表示拟合越好。
- **置信带（Confidence Bands）**：SPSS 原生 Q-Q 图不提供置信包络线，使得判断「偏离多远算异常」具有主观性。在追求高严谨度时，建议使用 R（`car::qqPlot`）或 Python（`statsmodels`）绘制带有 95% 置信带的 Q-Q 图，若多数点落在带内，则支持不拒绝原假设。

## 7. 与相关方法的取舍

- **P-P 图 vs. Q-Q 图**：P-P 图比较累积概率，对分布**中部**的拟合优度更敏感；Q-Q 图直接比较分位数，对分布**尾部**（如离群值、极端值）的偏离更为敏感。在回归残差分析中，Q-Q 图更为常见。
- **图形 vs. 假设检验**：
  - **Shapiro-Wilk 检验**（专用于正态性）与 **K-S 检验**（适用于多种分布的整体检验）提供客观的 $p$ 值。
  - **取舍原则**：大样本下，检验极易因为微小瑕疵报告 $p < 0.05$；此时应**以 Q-Q 图的视觉判断为主，检验结果为辅**。二者应当**并用**而非相互替代。

## 8. 实现速查

- **SPSS**：语法为 `PPLOT`，子类型指定为 `/TYPE=Q-Q`（详细设定见附录）。
- **R**：
  - 基础包：`qqnorm(y)` 配合 `qqline(y)`。
  - 进阶推荐：`car::qqPlot(y)`（**默认附带 95% 置信带，强烈推荐**）。
- **Python**：
  - `scipy.stats.probplot(data, dist="norm", plot=plt)`
  - 进阶推荐：`statsmodels.graphics.gofplots.qqplot(data, line='s')`。

## 9. 报告清单与标准话术

在学术论文的「统计分析」小节中报告数据分布特征时，应写明诊断工具与关键设定。

**报告要素清单**：
1. 采用的图形（Q-Q 图）及目标参考分布（如正态分布）。
2. （可选）所用的比例估算公式（如 Blom）及是否经过数据变换（如对数变换）。
3. 视觉诊断结论（点与参考直线的贴合程度，尾部形态）。
4. 结合假设检验（如 Shapiro-Wilk）的最终判断。

**论文报告话术模板（填空式）**：
> "数据的正态性通过绘制正态 Q-Q 图（采用 Blom 比例估算公式）与 Shapiro-Wilk 检验进行综合评估。图形显示，数据点基本沿对角参考线均匀分布，无明显系统性偏离 [或：尾部出现明显的 S 型/U 型偏离]，结合 Shapiro-Wilk 检验结果（$W = [统计量]$, $p = [P值]$），认为该变量（或回归残差）近似服从正态分布 [或：表现出显著的右偏/重尾特征，需进行数据变换/采用稳健标准误]。"

## 附录：SPSS 对话框选项释义

### 变量
指定一个或多个**尺度（Scale）**连续变量进入分析。若选入多个变量，系统将分别输出。

### 检验分布
| 设定项 | 统计含义与操作提示 |
| :--- | :--- |
| **检验分布** | 可选正态、均匀、指数、伽马、帕累托、拉普拉斯等理论分布族。 |
| **自由度（df）** | 若检验分布选择 t 分布或卡方分布，必须手动输入自由度。 |
| **分布参数** | 指定理论分布的位置参数与标度参数（如正态分布的 $\mu$ 和 $\sigma$）。<br>选择**「根据数据估算」**（默认），系统按样本均值和标准差生成参考线；<br>选择**「定制」**，需输入固定先验值。 |

### 转换（变换处理）
| 选项 | 统计含义 |
| :--- | :--- |
| **自然对数** | 对原始数据先取自然对数（$\ln$），再绘制 Q-Q 图，用于检验对数正态性。 |
| **将值标准化(Z)** | 对数据进行 Z 分数标准化后再作图。注意：若同时在「分布参数」中设定了 $\mu=0, \sigma=1$，切勿重复解释。 |

### 差异（序列/时间数据处理）
专为时间序列或带自相关数据设计。横截面数据（Cross-sectional）**通常留空不用此块**。
| 选项 | 统计含义 |
| :--- | :--- |
| **差异（差分）** | 执行普通差分以消除趋势，输入差分阶数（如 1 代表一阶差分）。 |
| **季节性差异** | 执行季节差分，需配合下方设定**「当前周期长度」**（如月度数据设为 12）。 |

### 比例估算公式（分位数逼近算法）
在经验累积分布函数的阶跃点上，用平滑公式近似连续理论分布的分位数。各公式导致点位略微偏移，大样本下差异可忽略；小样本时结论需结合 $n$ 谨慎判断。
| 选项 | 公式 ($r$为秩次，$n$为样本量) | 常见场景 |
| :--- | :--- | :--- |
| **Blom** | $\frac{r - 3/8}{n + 1/4}$ | **SPSS 默认**，正态分布下表现优良的万用公式。 |
| **Rankit** | $\frac{r - 1/2}{n}$ | 预期正态分数位置，提供均值无偏估计。 |
| **Tukey** | $\frac{r - 1/3}{n + 1/3}$ | Tukey 推崇的稳健性公式。 |
| **van der Waerden** | $\frac{r}{n + 1}$ | 经典经验累积概率转换公式。 |

### 结（Ties）处理
当样本中存在相同数值（同分值 / 结）时，如何分配它们的秩次：
| 选项 | 处理逻辑 |
| :--- | :--- |
| **平均值（Mean）** | 给所有相同数值分配它们的平均秩次（**最常用，默认推荐**）。 |
| **高 / 低** | 绑定同分值，统一赋予它们本应占据的最高或最低秩次。 |
| **强制中断同分值** | 将同分值视为由于测量精度受限导致的偶然相同，强行打散它们。**谨慎使用**，易在图中产生虚假的局部波动。 |
