# 相关性：双变量 / 偏相关 / 距离 / 典型相关

- **slug**: correlation-spss-suite
- **菜单**：**分析 → 相关**（Analyze → Correlate）
- **子项**：**双变量**、**偏相关**、**距离**、**典型相关**（依版本与模块组合）。

## 1. 回答什么问题

- **双变量（Bivariate）**：评估两个连续或有序变量间的整体关联程度及显著性（Pearson / Kendall tau-b / Spearman）。
  - *注：当样本量较小且数据中存在较多**结值（Tied ranks，即相同秩次）**时，优先推荐 Kendall tau-b 而非 Spearman。*
- **偏相关（Partial）**：在统计上控制一个或多个第三变量（混杂变量）后，评估两个变量间的**净线性关联**。
- **距离（Distances）**：计算样本（个案）或变量之间的**不相似性（或相似性）矩阵**，通常作为聚类分析、多维尺度分析（MDS）的数据预处理步骤。
- **典型相关（Canonical Correlation, CCA）**：在两组多变量集合（集合 $\mathbf{X}$ 与集合 $\mathbf{Y}$）之间，寻找使组间相关系数最大的**典型变量对**（线性组合），用于揭示两组变量间的整体关联结构。

## 2. 不适用 / 易滥用

- **Pearson 的局限**：仅能量度线性关联，非线性对称关系（如 U 型）可能导致 $r$ 接近 0；对**离群值**极度敏感。
- **偏相关的控制陷阱**：控制变量必须**有理论或因果图（DAG）依据**（如阻断后门路径），忌无脑放入所有可用变量；控制变量过多会导致**有效样本量（自由度）**显著下降。
- **距离度量的量纲灾难**：若各变量**量纲/方差**不同，计算欧几里得等距离前**必须标准化**；二元度量（如 Jaccard）与连续度量切勿在同一矩阵中直接混用。
- **CCA 的解释误区**：多重共线性严重或小样本时极其**不稳定**；新手常仅看“典型相关系数”而高估模型，正确的解释必须结合**典型载荷（Loadings）**与**冗余指数（Redundancy，即解释的跨组方差比例）**。

## 3. 数据与设计前提

- **独立同分布（i.i.d.）**：通常假设横截面独立观测。若数据存在时间序列自相关或嵌套结构，普通的 Pearson 检验其标准误会严重偏误，需改用时间序列模型或多层模型。
- **缺失值处理**：SPSS 默认提供“成对删除（Pairwise）”和“列表删除（Listwise）”。成对删除可保留更多数据，但可能导致相关矩阵非正定；报告时必须说明缺失处理机制并报告**有效 $n$**。

## 4. 模型或检验统计量（含自由度逻辑）

- **Pearson ($r$)**：检验总体 $\rho=0$ 的统计量为 $t=\frac{r\sqrt{n-2}}{\sqrt{1-r^2}}$，双变量检验的自由度 $df = n-2$。
- **偏相关**：检验偏相关系数时，每增加一个控制变量，系统损失 1 个自由度。其检验自由度为 **$df = n - 2 - k$**（$k$ 为控制变量的个数）。这就解释了为何控制过多变量会导致统计功效显著下降。
- **Spearman / Kendall**：基于秩次或一致对/不一致对；显著性检验可为渐近（大样本）或精确概率（依赖软件具体实现，如 SPSS Exact Tests 模块）。
- **CCA**：核心统计量为各维度的**典型相关系数 $\rho_k^*$**；使用 **Wilks' Lambda**、Pillai's Trace 等多元统计量对典型相关对逐一进行联合显著性检验。

## 5. 假设与诊断

| 假设 | 适用方法 | 检查方式 / 诊断 | 违背时的典型后果 |
| :--- | :--- | :--- | :--- |
| **双变量正态性** | Pearson (特别是小样本推断) | 散点图、Shapiro-Wilk 检验 | p 值与置信区间 (CI) 不可靠 |
| **线性关系** | Pearson, 偏相关 | 散点图矩阵、残差图 | $r$ 严重低估真实的关联程度 |
| **多元正态性** | 典型相关 (推断检验) | Mardia's 多元正态检验、Q-Q 图 | Wilks' Lambda 等检验功效扭曲、p 值失真 |
| **独立观测** | 所有推断性相关 | 研究设计审查 (有无时间/空间聚类) | 标准误 (SE) 偏小，假阳性激增 |
| **度量与类型匹配** | 距离计算 | 审查数据字典与软件选项 | 产出无意义的距离矩阵，毁掉后续聚类/MDS |

## 6. 效应量与区间

- **双变量 / 偏相关**：除了报告 $r$ 或 $\rho$ 及其方向（+/-），更重要的效应量是 **$r^2$（决定系数）**，它代表一个变量解释另一个变量方差的比例。
- **CCA**：必须报告 **平方典型相关（Squared Canonical Correlation, $R_c^2$）**，它代表一对典型变量间的共享方差。
- **不确定性**：强烈建议报告通过 Bootstrap 计算的置信区间（CI），其对偏离正态性的数据具有稳健性。

## 7. 与相关方法的取舍

- **相关 vs 回归**：在双连续变量且模型仅包含单一自变量时，Pearson $r$ 与简单线性回归的**标准化斜率**在数值和显著性上完全等价。但在需要控制多个混杂因素（尤其是包含非线性项或交互项）时，**多元回归分析**比偏相关更灵活且易于解释。
- **偏相关 vs 回归残差相关**：控制 $Z$ 后 $X$ 与 $Y$ 的偏相关，在严格线性假设下，等价于 $X$ 对 $Z$ 回归的残差与 $Y$ 对 $Z$ 回归的残差之间的 Pearson 相关。
- **PCA/因子分析 vs CCA**：主成分分析（PCA）旨在**单一**变量集合内部降维；而典型相关分析（CCA）旨在探究**两组**独立变量集合之间的桥梁（关联结构）。
- **非参数偏相关**：若混杂变量严重偏离正态，传统的线性偏相关可能失效，可采用基于秩变换的 Spearman 偏相关（部分统计软件或 R 包提供支持）。

## 8. 实现速查

- **SPSS GUI/Syntax**：
  - 双变量：`CORRELATIONS`；偏相关：`PARTIAL CORR`；距离：`PROXIMITIES`。
  - **典型相关的特殊性**：SPSS 标准菜单中通常没有直接的 CCA 选项。需通过 Syntax 调用 `MANOVA` 命令（配合 `DISCRIM`），或运行 SPSS 安装目录下自带的宏脚本（如 `Canonical correlation.sps`）。
- **Python**：
  - 基础：`scipy.stats.pearsonr`, `pandas.corr()`。
  - **偏相关/矩阵（强烈推荐）**：使用 **`pingouin`** 库，`pingouin.partial_corr()` 和 `pingouin.pairwise_corr()` 输出极尽详尽（含 CI、p值、自由度，对标 SPSS 体验）。
  - 距离：`sklearn.metrics.pairwise_distances`。
  - CCA：`sklearn.cross_decomposition.CCA`。
- **R**：
  - 双变量：`cor.test()`；偏相关：`ppcor::pcor()`。
  - 距离：基础 `dist()` 或 `vegan::vegdist()`。
  - CCA：基础 `cancor()` 或 `CCA` 包。

## 9. 报告清单

撰写学术论文“统计分析”小节与结果时的报告要点：
- **核心系数**：明确使用的相关类型（Pearson / Spearman / Kendall）及其理论或数据诊断依据（如因存在严重偏态而采用秩相关）。
- **数据基础**：有效样本量 $n$、缺失值的处理方式（Listwise / Pairwise 删除）。
- **偏相关特有**：清晰列出所有被控制的协变量名单，必要时简述理论依据。
- **距离矩阵特有**：报告采用的具体度量标准（如欧式、Jaccard）以及标准化方法（如 Z-score 转换）。
- **CCA 特有（易错警告）**：
  - 必须区分并分别报告 **典型权重（Canonical Weights）**（即标准化系数，用于计算得分）与 **典型载荷/交叉载荷（Canonical / Cross-loadings）**（结构相关系数，用于赋予典型维度以实际意义，新手切忌将权重当作载荷解释）。
  - 报告提取的典型函数数量及其 Wilks' Lambda 显著性。
  - 报告跨组的 **冗余分析（Redundancy Analysis）**，说明各典型变量实际解释了对侧原始数据总方差的百分之几。

## 附录 A：双变量相关

**核心配置**：支持将多个变量两两组合生成相关矩阵。
**相关系数选择**：Pearson（连续/正态）、Kendall tau-b（序数/含大量结值的小样本）、Spearman（序数/非线性单调）。
**显著性**：双尾/单尾（仅在具有强烈的方向性先验时使用单尾）。
**注意事项**：“标记显著性”（打星号）常用于速览，但绝不能替代对效应量（$r$ 的绝对值）本身的专业解读。**Bootstrap CI** 对结果的稳健性至关重要，具体见 [bootstrap-spss-dialog.md](../01-inference/bootstrap-spss-dialog.md)。

## 附录 B：偏相关

控制一个或多个“控制变量”后的 Pearson 型（线性）偏相关矩阵。
如果需要计算非参数版本的偏相关，在 SPSS 中往往需要先对原始变量和控制变量分别求秩（Rank Cases），再对秩次变量进行偏相关计算（即手工实现秩偏相关）。

## 附录 C：距离度量参数

构建距离/相似度矩阵是降维与聚类（[参见《聚类分析》卡片]）的前提。
- **区间变量**：欧几里得、平方欧氏、切比雪夫、块（Manhattan）、明可夫斯基（需设定参数 $p$）。
- **计数变量**：卡方距离、Phi 平方。
- **二元变量**：简单匹配（考虑双 0）、Jaccard（忽略双 0，生态学常用）、Dice 等。
- **数据处理选项**：
  - **标准化**：对于量纲不一的区间变量，必须在此步选择“按变量标准化”（如 Z 得分、范围到 0-1）。
  - **转换**：取绝对值、改变符号（将不相似性转换为相似性）。

## 附录 D：典型相关（通过宏/Syntax执行时）

在执行 CCA 时，常见的输出结果与保存项包含：
- **典型相关系数与 Wilks' Lambda**：判断整体关联是否显著。
- **特征值与典型根的方差比例**：反映该维度的解释力。
- **典型系数 (Weights)**：构建线性组合的权重。
- **典型载荷 (Loadings)**：原始变量与所在集合的典型变量间的相关性。
- **得分数据集**：将个案的典型变量得分（Canonical Scores）保存为新变量，供后续分析（如回归、聚类）使用。

## 附录 E：选用顺序决策表

| 目的与场景 | 数据特性 | 推荐路径 / 菜单 |
| :--- | :--- | :--- |
| **两两变量的整体关联** | 连续 / 序数 | 双变量 (Pearson / Rank) |
| **剔除混杂因素后的净关联** | 存在明确需控制的第三变量 | 偏相关 (Partial) |
| **准备聚类或 MDS 的输入矩阵** | 需计算样本间的拓扑关系 | 距离 (Distances) |
| **多 X 组与多 Y 组的整体桥梁** | 探究两组测量指标集合的结构关联 | 典型相关 (CCA Syntax/Macro) |
