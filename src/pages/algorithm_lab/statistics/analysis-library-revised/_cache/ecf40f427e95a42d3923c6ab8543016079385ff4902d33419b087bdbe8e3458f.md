# 时间序列：菜单总览 / 谱分析 / 自相关

- **slug**: time-series-spss-spectral
- **菜单**：**分析 → 预测** 或 **分析 → 时间序列预测**（Analyze → Forecasting / Time Series，视软件版本而定）
- **定位**：本卡片侧重于 SPSS 时间序列菜单的总览与基础检验（时域自相关 / 频域谱分析）。ARIMA 建模、季节性分解与向量自回归（VAR）的高阶设置建议参考各专用方法卡片。

## 1. 回答什么问题

对**等间隔**（或可处理为等间隔规则）的序列进行基础诊断与建模前导分析：
- **时域诊断**：评估当前值与历史值的线性依赖（自相关 ACF / 偏自相关 PACF），以及两序列间的先导-滞后关系（交叉相关）。
- **频域诊断**：将时间序列分解为不同频率的正弦/余弦波，识别隐藏的周期性（谱分析 / 周期图），以及评估两序列在特定频率下的相关性（相干性）。
- **建模与预测总览**：提供指数平滑、ARIMA（专家建模器）及季节性分解（STL）的快捷入口。

## 2. 不适用 / 易滥用

- **非平稳序列直接分析**：若序列存在明显趋势或异方差，直接进行谱分析与 ARIMA 阶数识别具有**强误导性**；必须先进行**差分**或**对数变换**以平稳化。
- **“时间因果模型”的因果谬误**：SPSS 菜单中的“时间因果模型（TCM）”本质多基于**向量自回归（VAR）**与**格兰杰因果检验（Granger Causality）**。它仅代表时间维度上的“先后预测性（Predictability）”，**绝非严格的反事实因果**，其实际应用需强学科理论约束。
- **过短的序列**：短序列会导致谱分析分辨率极差，长周期或隐周期特征难以有效辨识。

## 3. 数据与设计前提

- **等距采样**：数据点间的时间间隔必须一致。
- **缺失值处理**：传统时序模型对缺失值极其敏感，需在分析前插补，或使用支持状态空间表达的模型显式处理。
- **奈奎斯特频率限制（Nyquist Frequency）**：离散时间序列能识别的最高频率受采样率限制，即 $f_{max} = 0.5$（对应的最短可辨识周期为 2 个时间单位）。

## 4. 模型或检验统计量

### 时域分析
- **ACF / PACF**：滞后 $k$ 阶的相关系数。
  - **启发式定阶口诀**：对于平稳序列，若 ACF 截尾而 PACF 拖尾，提示 MA($q$)；若 PACF 截尾而 ACF 拖尾，提示 AR($p$)；若双拖尾，提示 ARMA($p,q$)。
- **Ljung-Box $Q$ 检验**：联合检验前 $k$ 阶自相关系数是否全为零，常用于检验模型残差是否已变为白噪声。

### 频域（谱分析）
- **周期图（Periodogram）/ 谱密度**：表示能量（方差）在不同频率 $\omega$ 上的分布。
- **平滑窗（Smoothing Window）**：原始周期图通常是不一致估计（方差不随样本量增加而衰减）。引入平滑窗旨在进行**偏差-方差权衡（Bias-Variance tradeoff）**——降低估计方差，但会牺牲一定的频率分辨率（引入偏差）。

## 5. 假设、诊断与超参数

| 核心假设 / 条件 | 检查与诊断方式 | 违背时的典型后果 |
| :--- | :--- | :--- |
| **序列平稳性**（建模前提）| ADF 检验、时序图目视诊断 | 伪回归；ACF 衰减极慢；模型设定错误 |
| **残差白噪声**（模型充分性）| 残差的 ACF 图、Ljung-Box 检验 | 遗漏信息；预测置信区间过窄（低估不确定性） |

**超参数敏感性说明**：
- **谱分析的窗类型与带宽**：并非统计假设，而是调参范畴。改变带宽或窗函数（如 Tukey-Hamming, Parzen）可能导致谱峰位置或高度偏移。建议报告**核心周期对不同窗函数的敏感性（稳健性）**。

## 6. 效应量与区间

- **预测值置信区间（CI）**：反映预测点的不确定性，随预测步长（Horizon）增加通常呈喇叭口发散。
- **谱峰（Spectral Peaks）**：频域图中的峰值对应的横坐标若为频率 $f$，其物理周期为 $1/f$。
- **平方一致性（Squared Coherency / 相干）**：介于 0 到 1 之间，解释两个时间序列在特定频率域上的相关强度（等价于频域的 $R^2$）。

## 7. 与相关方法的取舍

- **Python (statsmodels, Prophet, 深度学习) / R (forecast, fable)**：在严肃预测工程、自动化迭代与大规模在线部署中，常作为**首选生产栈**。
- **SPSS 传统向导**：适合**可审计报表生成、固定版本监管口径（如合规要求）以及教学对照**。其图形化界面便于快速目视探索，但状态空间模型（State Space Models）的灵活性不及 R/Python 专用包。

## 8. 实现速查

- **SPSS**：
  - 核心命令：`SPECTRA`（谱分析）、`ACF`（自相关）、`TSCMODEL`（时间序列建模器）。
  - **交叉验证实现提示**：SPSS 的测试集划分通常不在代码循环中实现，而是通过菜单设定**“忽略指定日期之后/最后 $N$ 个个案”**（Holdout sample）来保留验证集。
- **R 生态**：`stats::acf`，`stats::spectrum`，`forecast::auto.arima`，`astsa` 包。
- **Python 生态**：`statsmodels.tsa.stattools` (acf/pacf)，`scipy.signal.welch` (谱估计)，`pmdarima` (自动 ARIMA)。

## 9. 报告清单

在科研论文的方法与结果小节，建议规范报告以下要素：
- **序列设定**：采样频率/周期单位，是否进行差分（阶数 $d$）与季节差分（阶数 $D$）。
- **模型设定**：ARIMA 的最终阶数 $(p,d,q)(P,D,Q)^s$ 及其选择依据（如 AIC/BIC 最小化、专家建模器自动寻优）。
- **谱分析参数**：平滑窗的类型（Window Type）与带宽（Bandwidth）。
- **模型评估指标**：
  - 拟合优度：**平稳 $R^2$（Stationary $R^2$）**或常规 $R^2$。
  - 绝对误差：**RMSE**（均方根误差）、**MAE**或**MAPE**（平均绝对百分比误差）。
  - 白噪声检验：**Ljung-Box $Q$ 统计量**的值及其对应的 $p$ 值。
- **验证策略**：训练集与验证集的划分方式（时间截点或最后 $N$ 期）。

## 附录 B：谱分析选项详解（SPECTRA）

- **谱窗口（平滑窗）**：Tukey-Hamming, Tukey-Hanning, Parzen, Bartlett, Daniell。选择不同的窗用于调整谱密度的平滑度。
- **分析层级**：支持**双变量**交叉分析或**每变量分别**分析。
- **单变量图类型**：周期图（Periodogram）、谱密度。
- **双变量（交叉）图类型**：
  - **平方一致性（相干，Squared Coherency）**：频域的 $R^2$。
  - **相位谱（Phase Spectrum）**：指示在特定频率下一个序列领先另一个序列的时间步数。
  - **余谱（Cospectrum）**与**正交谱（Quadrature Spectrum）**、**增益（Gain）**。
- **横轴单位**：可切换为**频率**（默认）或**周期**（便于直观解释，如周期=12代表年度季节性）。

## 附录 C：自相关选项（ACF）

- **最大延迟（Maximum Lags）**：设置规则——建议覆盖至少 1～2 个完整的季节周期（如月度数据设为 24 或 36）。
- **标准误差近似方法**：
  - **独立模型（Independence Model）**：假设序列为纯白噪声（严格的 $\pm 1.96/\sqrt{n}$ 边界）。
  - **Bartlett 近似**：适用于平稳但存在低阶自相关的序列（如 MA 过程），边界会在显著的滞后阶数后自适应变宽，更为严谨。
- **在周期性延迟处标出**：辅助在 ACF 图中突出显示 $s, 2s, 3s$ 等滞后位置，便于识别季节性（需预先定义日期/时间变量）。
