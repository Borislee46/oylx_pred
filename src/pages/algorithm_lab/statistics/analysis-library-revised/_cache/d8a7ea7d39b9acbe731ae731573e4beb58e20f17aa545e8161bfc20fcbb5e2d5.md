# 交叉表（Crosstabs）—「统计」子对话框

- **slug**: crosstabs-statistics-spss
- **菜单**：**分析 → 描述统计 → 交叉表 → 统计(S)**
- **说明**：此对话框决定了交叉表分析的推断统计量与效应量。选项是否可用取决于变量的**测量级别**（名义、有序、尺度）与表格维数（\(2\times2\) 或 \(R\times C\)）。

## 1. 回答什么问题

在**列联表**上检验变量间的**独立性**或边际分布的**同质性**（如 Pearson 卡方检验），并基于特定的测量级别输出对应的**关联强度/效应量**（名义变量：Phi、Cramér's V；有序变量：Gamma、Kendall 的 \(\tau\)、Somers' \(d\)）。在特定设计下，还可评估**风险与优势比**（\(2\times2\) 表格的 RR/OR）、**配对一致性/边缘同质性**（Kappa、McNemar）以及进行**分层混杂控制**（Mantel–Haenszel 检验）。

## 2. 不适用 / 易滥用

- **期望频数过小违背经典准则**：当数据违背 Cochran 准则（**超过 20% 的单元格期望频数小于 5，或有任何单元格期望频数小于 1**）时，Pearson \(\chi^2\) 的渐近分布假设失效，可能导致 I 类错误率失控。应改用**精确检验（Fisher Exact）/蒙特卡洛模拟**，或从业务逻辑出发合并类别。
- **配对数据误用独立卡方**：对同一批对象在不同时间点/不同评定者下的重复测量，不能使用常规的 Pearson 卡方（独立性假设违背），必须使用 **McNemar 检验**（\(2\times2\) 表）或 **Bowker 检验**（多分类）。
- **将有序变量降级为名义变量**：若行列变量均存在明显顺序（如「轻/中/重度」），直接使用 Pearson 卡方会损失方向性信息且效能较低。应首选基于等级的统计量（**Gamma、Kendall 或 趋势检验**）。
- **混淆统计关联与因果关系**：卡方检验或效应量仅反映数学关联；因果推断必须依赖严格的研究设计（如随机化、前瞻性控制等）。

## 3. 数据与设计前提

统计量的选择与解释高度依赖于抽样方案与研究设计：
- **独立样本 vs. 配对样本 vs. 分层样本**：决定了是选用独立卡方、McNemar 还是 Mantel–Haenszel (MH) 检验。
- **风险（Risk）选项的适用性**：在 \(2\times2\) 表格中，**病例对照研究**（回顾性）只能解释**优势比 (OR)**；只有**队列研究 / 随机对照试验**（前瞻性）才能合理解释**相对风险 (RR)**。注意：SPSS 会在同一表格中输出 OR 和双向 RR，研究者极易读错行，必须根据设计和变量 0/1 编码方向谨慎提取。

## 4. 模型或检验统计量（含自由度与修正逻辑）

- **Pearson \(\chi^2\)**：\(\sum \frac{(O-E)^2}{E}\)，自由度 \(df = (R-1)(C-1)\)。检验行列变量是否独立。
- **Yates 连续性修正卡方（针对 \(2\times2\) 表）**：对于 \(2\times2\) 表格，SPSS 默认输出连续性修正结果 \(\sum \frac{(|O-E|-0.5)^2}{E}\)。当前学界对其是否过于保守存在争议，但通常在期望频数处于临界状态时可作为参考；大样本下与 Pearson 卡方结果趋同。
- **似然比 \(\chi^2\) (Likelihood Ratio)**：基于极大似然估计，\(2\sum O\ln(O/E)\)；\(df\) 与 Pearson 卡方相同，常用于对数线性模型中。
- **基于卡方的效应量（Phi / Cramér's V）**：由 \(\chi^2\) 与总样本量 \(N\)、表格维数导出，将关联强度标准化到 \([0, 1]\) 或 \([-1, 1]\) 区间。
- **基于排秩的统计量（Gamma / \(\tau_b\) / \(\tau_c\) / Somers' \(d\)）**：基于评估两组观测值中**一致对 (Concordant)** 与**不一致对 (Discordant)** 的相对比例。
- **Cochran–Mantel–Haenszel (CMH) 检验**：在控制分层变量（混杂因素）后，检验多个 \(2\times2\) 表的**公共 OR** 是否显著异于 1。

## 5. 假设与诊断

| 检验/统计量 | 核心假设与前提 | 检查方式 / 诊断位置 | 违背时的典型后果 |
|:---|:---|:---|:---|
| **Pearson \(\chi^2\)** | **Cochran 准则**：期望频数 \(E_{ij} \ge 5\) 的单元格 \(\ge 80\%\)，且无 \(E_{ij} < 1\) | 「单元格」对话框中勾选「期望计数」 | I 类错误失控，渐近分布不准确（需转精确检验） |
| **有序检验 (Gamma等)** | 变量具有单调递增/递减属性 | 检查编码字典及「单元格」中行列分布方向 | 统计量符号反转，或关联被抵消导致假阴性 |
| **Kappa/McNemar** | 样本非独立（配对/重复测量/同一对象两名评委） | 确认研究设计是否属于「匹配/配对」 | 若误用于独立样本，结论无效且无数学意义 |

## 6. 效应量与置信区间

在报告假设检验（\(p\) 值）的同时，必须报告**效应量**以反映实际业务意义（显著不等于重要）：
- **名义 × 名义**：勾选 **Phi \(\phi\)**（仅限 \(2\times2\) 具有方向性，范围 \([-1, 1]\)）或 **Cramér's V**（适用于任意维度表格，范围 \([0, 1]\)）。
- **有序 × 有序**：勾选 **Gamma \(\gamma\)** 或 Kendall 的 \(\tau\)。
- **效应的不确定性**：对于 **OR** 和 **RR**，SPSS 的「风险」输出默认包含 **95% 置信区间 (CI)**。如果 CI 跨越 1，则说明风险差异在 $\alpha=0.05$ 级别不显著。

## 7. 与相关方法的取舍

- **事后两两比较（Post-hoc）**：若 \(R\times C\) 表的整体卡方检验显著，研究者通常需定位具体差异来源。不应在「统计」子对话框盲目勾选，而应在**「单元格(Cells)」子对话框**中勾选**「比较列比例(z 检验)」**，并配合 **Bonferroni 调整**，以避免多重比较的 I 类错误膨胀。
- **对数线性模型 (Loglinear) / 逻辑回归 (Logistic)**：当涉及三个或以上分类变量的多重交互作用，或需要连续变量作为协变量时，交叉表能力受限，应转向回归建模框架。
- **趋势检验 (Cochran–Armitage)**：当一个变量为二分类（如发病/未发病），另一个变量为有序多分类（如暴露剂量分组）时，用于检验发病率的线性趋势。在 SPSS 中常需借用自定义表格模块或特殊编码计算。

## 8. 实现速查

- **SPSS Syntax**：
  ```spss
  CROSSTABS
    /TABLES=row_var BY col_var
    /STATISTICS=CHISQ RISK PHI GAMMA  /* 依需求调用卡方、风险、效应量等 */
    /CELLS=COUNT EXPECTED ROW COLUMN. /* 配合输出期望计数以检查假设 */
  ```
  *(注：若需 Fisher 精确检验，需附加 `/METHOD=EXACT`，见精确检验附录卡片)*
- **R**：
  - 基础检验：`chisq.test()`, `fisher.test()`, `mcnemar.test()`
  - 效应量与高级表格：`vcd::assocstats()`, `rcompanion::cramerV()`, `DescTools::CramerV()`
  - CMH 分层检验：`mantelhaen.test()`
- **Python**：
  - `scipy.stats.chi2_contingency` (含 Yates 修正与期望频数输出)
  - `statsmodels.stats.contingency_tables` (支持配对、分层表的高级处理)

## 9. 报告清单与 APA 格式示例

**报告核心要素**：
1. **样本概况**：有效样本量 \(N\)，是否有缺失值。
2. **假设检验检查**：简述是否满足期望频数准则（若不满足，说明采用了 Fisher 精确检验）。
3. **统计结果**：检验统计量的值（如 \(\chi^2\)）、自由度 \(df\)、样本量 \(N\) 及精确的 \(p\) 值。
4. **效应量/风险评估**：Cramér's V 值，或 OR/RR 值及其 95% CI。

**APA 报告示例**：
> **(1) 独立性卡方检验与效应量示例**：
> “Pearson 卡方检验表明，性别与购车偏好之间存在显著关联，\(\chi^2(2, N = 150) = 10.24, p = .006\)，关联强度为中等水平（Cramér's \(V = 0.26\)）。无任何单元格的期望计数小于 5，满足检验假设。”
> 
> **(2) 病例对照研究的风险分析示例**：
> “分析显示，吸烟与该疾病的发生显著相关，\(\chi^2(1, N = 200) = 8.45, p = .004\)。吸烟组患病的优势比为不吸烟组的 2.3 倍，\(OR = 2.30, 95\% \text{ CI} [1.25, 4.23]\)。”

## 附录 A：对话框选项详表

### 卡方 (Chi-square)
勾选后默认输出：Pearson 卡方、似然比卡方、线性对线性关联（需行列均为数值型编码）。若为 \(2\times2\) 表，自动附加 Yates 连续性修正卡方。**解读前提**：必须配合「单元格」中的期望频数使用。

### 名义变量统计量 (Nominal)

| 选项名称 | 统计学含义与适用场景 |
|:---|:---|
| **列联系数 (Contingency Coefficient)** | 基于 \(\chi^2\)，上界受限于表格维数（无法达到 1），通常不跨表比较。 |
| **Phi 和克莱姆 V (Phi and Cramér's V)** | **首选效应量**。对于 \(2\times2\) 表，\(\phi\) 等价于 Pearson 相关系数；对于更大表格，Cramér's V 范围稳定在 \([0, 1]\)。 |
| **Lambda** | 基于减少比例误差 (PRE) 逻辑；具有「对称」与「非对称」（指定依变量）两种输出。值为 0 不代表完全独立。 |
| **不确定性系数 (Uncertainty Coefficient)** | 基于信息论的熵计算，度量一个变量能消除另一个变量多少不确定性。 |

### 名义 × 区间 / 尺度 (Nominal by Interval)

| 选项名称 | 统计学含义与适用场景 |
|:---|:---|
| **Eta** | 适用于自变量名义、因变量连续的场景。**注意**：其平方值（Eta-squared）表示方差解释率，勿与 Pearson \(r\) 混淆。 |

### 有序变量统计量 (Ordinal)

| 选项名称 | 统计学含义与适用场景 |
|:---|:---|
| **Gamma** | 基于一致/不一致对的对称测度，忽略打结 (ties) 数据，范围 \([-1, 1]\)。 |
| **萨默斯 d (Somers' d)** | Gamma 的非对称扩展，对打结数据进行了惩罚校正。区分自变量与因变量。 |
| **肯德尔 tau-b / tau-c (Kendall's tau)** | 均包含打结校正。**tau-b** 适用于方形表（行数=列数）；**tau-c** 适用于非方形表（行数≠列数）。 |

### 相关性与其他 (Other)

| 选项名称 | 统计学含义与重点防呆提示 |
|:---|:---|
| **相关性 (Correlations)** | 输出 Pearson \(r\) 和 Spearman \(\rho\)。需确保变量编码存在有意义的数值距离或等级。 |
| **Kappa** | 测量两名评定者（或两次测量）对同一批样本的**分类一致性**。**切忌**用于评估两个独立变量的关联。 |
| **风险 (Risk)** | 输出 RR（相对风险）和 OR（比值比）及 95% CI。**高危陷阱**：SPSS 会在表格不同行同时列出 OR 和两个维度的 RR。读表时必须严防：病例对照只能看 OR 行；队列研究看 RR 行。 |
| **麦克尼马尔 (McNemar)** | 用于 $2\times2$ **配对数据**，检验边缘分布是否同质（如干预前后阳性率是否变化）。 |
| **柯克兰和曼特尔-亨塞尔 (CMH)** | 需要设定**层变量**。用于在控制分层变量（如不同中心、不同年龄段）后，计算总体校正后的公共 OR。配合检验公共 OR 是否等于 1。 |

## 附录 B：统计量选用决策树（实务指引）

进行交叉表分析时，请严格按照以下顺序进行决策：

1. **判定研究设计类型**：
   - 若是**配对/重复测量数据** \(\rightarrow\) 选 **McNemar** 检验（一致性选 **Kappa**）。
   - 若涉及**多中心/分层混杂因素**控制 \(\rightarrow\) 放入层变量并选 **CMH** 检验。
   - 若是常规**独立样本** \(\rightarrow\) 选 **卡方 (Chi-square)**，进入步骤 2。

2. **诊断期望频数准则**（在「单元格」中勾选「期望计数」）：
   - 若 \(\ge 20\%\) 的单元格期望计数 \(<5\)，或存在 \(<1\) \(\rightarrow\) 废弃 Pearson 卡方，改看 **Fisher 精确检验**结果。
   - 若 \(2\times2\) 表期望频数在临界值附近 \(\rightarrow\) 建议参考 **Yates 连续性修正**结果。
   - 若满足经典准则 \(\rightarrow\) 采用常规 **Pearson 卡方**。

3. **根据变量「测量级别」匹配效应量**：
   - **名义 × 名义** \(\rightarrow\) 勾选 **Phi 和 Cramér's V**。
   - **有序 × 有序** \(\rightarrow\) 勾选 **Kendall's tau-c** (非方表) 或 **tau-b** (方表) 或 **Gamma**。
   - **名义 × 连续** \(\rightarrow\) 勾选 **Eta**。

4. **针对特定医学/流行病学设计的 \(2\times2\) 表**：
   - 勾选 **风险 (Risk)**。
   - 若为**病例对照**（探究特定结果的回溯暴露情况） \(\rightarrow\) 报告矩阵第一行的 **OR (比值比)** 及 95% CI。
   - 若为**队列研究**（探究特定暴露的前瞻发病情况） \(\rightarrow\) 报告矩阵下方对应的 **RR (相对风险)** 及 95% CI。
