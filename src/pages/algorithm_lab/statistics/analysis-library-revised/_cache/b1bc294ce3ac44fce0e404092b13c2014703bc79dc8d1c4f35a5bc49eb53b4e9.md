# 多维展开（PREFSCAL）

- **slug**: prefscal-spss
- **菜单**：**分析 → 刻度 → 多维展开**（Analyze → Scale → Multidimensional Unfolding / PREFSCAL）
- **用途**：将**优先排序、成对比较或评分**等得到的非对称矩阵展开为**公共低维空间**。模型必须估计行对象（评价者）与列对象（刺激物）的联合坐标，并可选包含**个体差异**（加权或广义欧氏模型）。

## 1. 回答什么问题

在**多维展开（Multidimensional Unfolding）**框架下，将非对称的偏好或评分矩阵（例：消费者对不同品牌汽车的打分、选民对多位候选人的支持度排序）降维映射到直观的低维**公共空间**。

模型**必须同时估计**行对象（即评价者的“理想点”）与列对象（即刺激点）的坐标，并**可选估计**个体对不同维度的权重。通过迭代寻优的**最优变换**，使降维空间中的**模型距离**尽可能逼近**输入近似值**。解释的核心原则是：**评价者（理想点）与刺激点在空间中距离越近，代表偏好度或相似度越高**。

## 2. 不适用 / 易滥用

- **退化解陷阱（Degenerate Solutions）**：在非度量展开中，若不施加特定惩罚，极易出现所有坐标点聚集成簇的无意义解（此时应力值虚假地降为 0）。必须设定并报告惩罚参数。
- **维数过高**：应力值会随维数增加而人为压低；需通过惩罚机制、交叉验证或理论可解释性来约束过拟合。
- **样本量过小**：待估参数（坐标点）数量随行列数增加而剧增，小样本下解极不稳定。
- **输入非区间/比率级数据但未做变换**：若输入为等级排序（Ordinal）等非度量数据，必须启用**单调变换（Monotone transformation）**或**样条变换（Spline）**，并严格检查 **Shepard 图**以防退化。

## 3. 数据与设计前提

- **矩形数据结构**：多维展开处理的是**非对称的、矩形的（Rectangular）偏好/评分矩阵**（行是评价者，列是刺激物），而非标准 MDS 的对称方阵。
- **宽格式录入（Wide Format）**：在 SPSS 等软件中，数据须以宽格式录入。每一行代表一个独立的行对象（如单个评价者），被选入“变量（Variables）”框的每一列代表一个独立的刺激物（列对象），单元格内的值为具体得分或排序。
- **缺失与结（Ties）**：需根据数据测度级别预先决定结的处理策略（如：保持绑定、解除绑定）以及缺失值的插补或剔除机制。

## 4. 模型或检验统计量（含自由度逻辑）

- **基础距离模型**：模型在 $r$ 维空间中的基本代数表达式为 $d_{ij} = \sqrt{\sum_{t=1}^{r} w_{it}(x_{it} - y_{jt})^2}$。其中 $x_{it}$ 为行对象 $i$（理想点）在维度 $t$ 的坐标，$y_{jt}$ 为列对象 $j$（刺激点）在维度 $t$ 的坐标。$w_{it}$ 为可选的个体空间权重（当采用加权欧氏模型时）。
- **惩罚应力（Penalized Stress）**：PREFSCAL 并非普通优化，而是针对“退化解”设计的带惩罚项的损失函数。算法在最小化模型距离与变换后输入值的差异（Stress-1 或标准化应力）时，引入基于变异系数的**惩罚项**（Penalty），强制空间点保持适当离散。
- **迭代收敛**：通过主化算法（Majorization Algorithm）不断迭代，直至达到应力收敛标准或最大迭代次数。

## 5. 假设与诊断

| 假设/前提 | 检查方式 | 违背时的典型后果 |
| :--- | :--- | :--- |
| **最优变换设定合理**（单调/线性/样条） | 观察 **Shepard 图**与转换图的形态 | 拟合假象（退化解）或导致严重过拟合 |
| **空间维数足够** | 对比多维度的**逐维应力（碎石图）** vs 理论可解释性 | 强制挤压导致特征丢失，距离关系扭曲 |
| **全局最优解**（未陷入局部极小值） | 设置多随机起点（Multi-start）并对比最终应力值 | 得到次优的配置坐标，误导解释 |

## 6. 效应量与区间

- **拟合优度**：**最终惩罚应力值（Final Penalized Stress）**。越接近 0 拟合越好，但须结合模型惩罚参数的有效性共同评估。
- **公共空间坐标（Coordinates）**：构成最终多维尺度图的点位向量，解释时聚焦于“理想点-刺激点”的簇群聚集度及象限划分。
- **空间权重（Space Weights）**：（仅适用于加权模型）反映特定对象或个体在各个维度上的收缩/伸展效应。

## 7. 与相关方法的取舍

- **MDS（PROXSCAL/ALSCAL）**：适用于处理对象间的**对称相似性/距离方阵**；而 **PREFSCAL** 专门针对**两类不同集合（行与列）间的非对称偏好/排序数据**。
- **对应分析（Correspondence Analysis）**：适用于分类变量的**列联交叉频数**；而 **PREFSCAL** 面向的是**连续评分、排序或成对比较**的距离度量。

## 8. 实现速查

- **SPSS**：通过 `PREFSCAL` 命令或对话框调用；操作涉及大量极值与变换设定（详见附录 A、B）。
- **R**：主要依赖 `smacof` 包中的 `unfolding()` 函数及其扩展，其底层逻辑与 SPSS PREFSCAL 惩罚算法同源。
- **Python**：目前缺乏直接在顶层封装 PREFSCAL 惩罚项的主流简单库，通常需要借助 `smacof` 的移植版或依托基础科学计算库手动构建带变异系数惩罚的最优损失函数。

## 9. 报告清单

撰写研究方法与结果时，建议包含以下可核对的要素，确保研究的可复现性：
1. **数据与模型设定**：输入近似值类型（相似性或不相似性）、模型类别（恒等式、加权欧氏、广义欧氏）以及维数边界（最小与最大维数）。
2. **变换与结机制**：近似值的转换形式（如：无、线性、样条、等级）以及存在并列等级（Ties）时的处理方式。
3. **惩罚与优化参数（必须报告）**：为证明解未退化，必须报告**惩罚参数（Penalty Range & Strength）**，以及防止局部极小值的**多起点（Random starts）设置数目**。
4. **拟合指标**：最终应力值及迭代收敛情况。
5. **核心图表**：展示**公共空间图**，必要时提供 **Shepard 图**以验证变换合理性；若使用加权模型，应补充**私有空间/权重图**。

## 附录 A：模型设定（Model Options）

- **标度模型**：恒等式（无个体权重）、加权欧氏（INDSCAL 思想，个体对维度有特定权重）、广义欧氏。
- **近似值（Proximities）**：需指明输入数据代表“不相似性（距离）”还是“相似性”。
- **维数（Dimensions）**：设定迭代评估的最小与最大维数。
- **近似值转换（Transformations）**：
  - 类型：无（绝对）、线性、样条（多项式）、等级（非度量）；
  - 附加约束：结点设定、平滑化约束、有序性要求、是否允许截距。
  - 并列值（Ties）处理：保持结（绑定）、解除绑定以获得更低应力。
- **应用转换的范围**：逐行内（Row-conditional，常见于展开模型）、逐源内或跨所有源同时转换。

## 附录 B：算法选项（Algorithm Options）

- **初始配置（Initial Configuration）**：经典缩放、三角配置、Ross-Cliffe、对应分析坐标、**随机起点（需设定随机起点数以规避局部极小）**、质心法。
- **迭代终止条件（Iteration Criteria）**：应力收敛阈值、最小应力阈值、最大迭代次数。
- **惩罚机制（Penalty）**：防止非度量展开退化解的核心参数，包含**强度（Strength）**与**范围（Range）**调节。
- **定制配置**：支持从现有变量、活动数据集或外部文件读入自定义初始坐标；**注意：数据格式要求行对象的坐标必须位于列对象坐标之前**，且变量数量需与设定维数严格匹配。

## 附录 C：图表输出（Plots）

- **公共空间与比较图**：最终公共空间散点图（行对象与列对象的相对位置）、多起点收敛比较图。
- **拟合与诊断图**：
  - **Shepard 图（谢泼德图）**：散点展示原始近似值与变换后距离的映射关系，是诊断退化和过拟合的最重要图表。
  - **转换图**、拟合散点图、残差图、逐维应力图（用于判断最佳维数）。
- **权重与私有图**：空间权重图、个体私有空间图（仅在使用加权欧氏等含权重模型时有效）。
- **样式**：可对行对象与列对象在空间图中的标记样式进行定制以增强区分度。
