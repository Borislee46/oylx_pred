# 一般线性模型 — 单变量（GLM Univariate）

- **slug**: glm-univariate-spss
- **菜单**：**分析 → 一般线性模型 → 单变量**（Analyze → General Linear Model → Univariate）

## 1. 回答什么问题

对**连续因变量**拟合一般线性模型 $y = X\beta + \varepsilon$。本过程是最常用的方差分析（ANOVA）、协方差分析（ANCOVA）及普通多重回归的通用引擎。
支持**固定因子（分类）**、**随机因子**、**协变量（连续）**及其**交互项**的构建。核心输出包括：基于特定平方和类型的 **F 检验**、**参数估计**、**估计边际均值（EMM）**及成对比较、**稳健标准误**和各种残差诊断。

## 2. 易滥用与不适用场景（防坑指南）

- **严重非正态、离散计数、二分类结局**：本过程假定残差服从正态分布。若结局明显违背（如泊松计数、概率），应改用 **广义线性模型（GENLIN）** 或 **广义线性混合模型（GLMM）**。
- **重复测量或纵向相关数据**：单变量 GLM 假定观测值**相互独立**。处理同一受试者的多次测量，必须使用 **重复测量 GLM**（多元方法）或 **混合线性模型（MIXED）**。
- **含协变量或非平衡设计时的“事后比较”**：
  - 🛑 **高危操作**：主界面中的“事后比较（Post Hoc）”按钮仅基于**原始未调整的组均值**进行比较（如 Tukey HSD），且**不支持含有协变量的模型**。
  - **正确做法**：必须在“EM 平均值”菜单中请求成对比较，此时使用的是依据模型**调整后的边际均值（Adjusted Means）**。
- **非平衡设计下的随机因子**：GLM 处理随机因子采用的是基于矩估计的 ANOVA 法。在非平衡数据下，该方法极易产生负方差且检验效能低下。强烈建议改用 **MIXED 过程（基于 REML 估计）**。
- **事后功效（Observed Power）**：软件提供的基于样本算出的“观测功效”存在逻辑循环（与 p 值完全同构），不可作为真实检验功效的证据，解读需极度谨慎。

## 3. 数据与设计前提

- **非平衡设计与平方和（Sum of Squares）选择**：各单元格样本量（$n$）不相等时，主效应的检验对平方和提取顺序极度敏感。**Type III（默认）** 评估边际贡献（前提是包含所有交互项），**Type I** 是序贯提取。必须明确报告所选用的类型。
- **缺失值**：默认采用列表删除（Listwise Deletion）。若缺失比例较高，需考虑多重插补（Multiple Imputation，需确保插补模型涵盖 GLM 交互项）。

## 4. 模型与检验统计量

- **检验统计量 (F)**：分子均方（效应）与分母均方（误差）之比。
- **自由度 (df) 逻辑**：分子 df 对应效应参数个数；分母 df 的确定依赖于**期望均方（Expected Mean Squares, EMS）**。纯固定效应下分母为残差均方；引入随机因子后，分母可能变为交互项均方甚至无法精确构造（此时应用 Satterthwaite 近似）。
- **可估函数（Estimable Functions）**：在空单元格（设计矩阵奇异）存在时，部分交互作用或主效应无解。对比检验本质是通过正交的 **L 向量**矩阵对模型参数进行线性组合的假设检验。

## 5. 假设与诊断

下表列出了运用单变量 GLM 的核心统计学假设及违背后果：

| 假设 | 推荐检查方式 | 违背时的典型后果与应对 |
|------|----------|------------------|
| **独立性** | 依据实验设计判断；Durbin-Watson 检验（时间序列） | 标准误（SE）严重偏倚，第一类错误率失控。需改用 MIXED 处理聚类/重复测量。 |
| **残差正态性** | 残差直方图、Q-Q 图、Shapiro-Wilk 检验 | 小样本下 F 检验名义水平偏离；大样本下因中心极限定理具有一定稳健性。 |
| **方差齐性** | 残差-预测值散点图、Levene 检验、BP/White 检验 | 扭曲 SE 和置信区间，F 检验失效。应对：使用**稳健标准误（HC 族）**。 |
| **回归斜率齐性**<br>*(仅限 ANCOVA)* | 将`因子 × 协变量`的交互项纳入模型进行检验 | 若交互项显著，说明协变量对结局的影响因组别而异，**不能剥离协变量直接解释主效应**。 |
| **线性与可加性** | 偏残差图、失拟检验（需有重复观测单元） | 模型拟合存在系统性偏差。可能需要增加高次项或变换。 |

*注：SPSS 新版引入的**稳健标准误（HC0–HC4，MacKinnon–White 校正族）**在存在异方差时，对**系数的统计推断（SE, p 值, CI）**进行校正，但**不改变参数的点估计值**。*

## 6. 效应量与区间

- **效应量估算**：通常报告 $\eta^2$（Eta-squared）或**偏 $\eta^2$（Partial $\eta^2$）**。
  - **重要限制**：SPSS 默认输出偏 $\eta^2$。在多因素设计中，各项的偏 $\eta^2$ 相加往往**大于 1**。跨研究比较时需注意其与广义 $\eta^2$（Generalized $\eta^2$）的数学差异。
- **置信区间（CI）**：强烈建议报告**参数估计值**和 **EMM（估计边际均值）** 的 95% CI，以此反映不确定性，而非仅依赖 p 值。

## 7. 实现速查（含关键防坑代码）

### SPSS
- 菜单：如标题。语法过程为 `UNIANOVA`（无随机效应时）或 `GLM`。详见附录对话框释义。

### R 语言
使用 `car` 包进行非平衡设计的 Type III 检验，及 `emmeans` 提取边际均值。
```r
# 🛑 世纪巨坑警告：R 默认对比编码为虚拟编码（treatment）。
# 计算 Type III 平方和前，【必须】更改为正交编码（如和编码），否则主效应结果完全错误！
options(contrasts = c("contr.sum", "contr.poly"))

model <- lm(Y ~ FactorA * FactorB + Covariate, data = df)
car::Anova(model, type = "III")

# 提取并比较 EMM（自动按协变量均值调整）
library(emmeans)
emmeans(model, pairwise ~ FactorA)
```

### Python
使用 `statsmodels`。同样需要注意 Type III 的对比编码设定。
```python
import statsmodels.formula.api as smf
import statsmodels.api as sm
# 🛑 必须在公式中指定 C(Factor, Sum) 以符合 Type III 假设
model = smf.ols('Y ~ C(FactorA, Sum) * C(FactorB, Sum) + Covariate', data=df).fit()
sm.stats.anova_lm(model, typ=3)
```

## 8. 报告清单（科研文体）

在论文的「统计方法」与「结果」部分，建议涵盖以下要素：
1. **模型设定**：明确指出纳入的固定因子、随机因子、连续协变量及交互项。
2. **平方和类型**：非平衡设计强制注明（如：“采用 Type III 平方和以控制设计不平衡”）。
3. **检验结果**：报告 F 值、分子与分母自由度、精确 p 值及效应量（如：$F(2, 105) = 4.32, p = .016, \text{partial } \eta^2 = .076$）。
4. **组别均值比较**：**强制报告估计边际均值（EMM）**及其标准误（SE）或 95% 置信区间。勿在含有协变量的模型中报告原始均值。
5. **多重比较校正**：如 Bonferroni, Tukey HSD, 或 Sidak 校正方法。
6. **假设检验摘要**：简述 Levene 检验或残差正态性检验结果；若使用了**稳健标准误**（如 HC3），需明确说明以应对异方差。

## 附录 A：主对话框（Analyze → GLM → Univariate）

| 设置项 | 统计学含义与操作建议 |
|----|------|
| **因变量** | 连续型响应变量。 |
| **固定因子** | 分类自变量（如：实验组别、性别）。模型将估计其各水平的固定效应。 |
| **随机因子** | 效应来源于更广泛总体中的随机抽样。**注**：非平衡数据建议改用 `MIXED` 过程。 |
| **协变量** | 连续型自变量（控制变量）。用于 ANCOVA，降低误差方差。 |
| **模型 (Model)** | 设定全模型或自定义项。可选择主效应、双因子交互、嵌套（Nested）等，以及设定**平方和类型 (Type I/II/III/IV)**。 |
| **对比 (Contrasts)** | 用于固定因子的预设正交或非正交对比（简单对比、偏差、Helmert、多项式等）。 |
| **图 (Plots)** | 绘制基于模型估计的轮廓图（横轴与图例）。直观展示主效应与交互作用。 |
| **事后比较 (Post Hoc)** | 🛑 **仅限无协变量的组别比较**。基于未调整的原始组均值。 |
| **EM 平均值 (EM Means)** | **强烈推荐**。输出模型调整后的边际均值（LSMEANS）。勾选“比较主效应”可进行带有协变量的成对比较。 |
| **保存 (Save)** | 见附录 B。 |
| **选项 (Options)** | 见附录 C。 |

## 附录 B：保存（Save）菜单核心输出

支持将模型中间结果追加为数据集的新变量，用于后续诊断：
- **预测值**：未标准化、加权、标准误。
- **诊断统计量**：**Cook 距离**（全局强影响点）、**杠杆值 (Leverage)**（自变量空间的极端点）。
- **残差**：未标准化、标准化、学生化（Studentized，推荐用于找寻离群值）、已删除残差。
- **系数统计**：将估计的参数保存为新数据集（可结合稳健协方差矩阵）。

## 附录 C：选项（Options）菜单诊断工具

- **显示内容**：描述性统计、效应量估计（偏 $\eta^2$）、参数估计值（ $\beta$ 系数）。
- **方差齐性**：
  - **Levene 检验**：经典的残差齐性检验。
  - **异方差检验**：引入了计量的标准做法（Breusch-Pagan 检验、White 检验及其 F 统计量形式）。
- **稳健标准误**：当怀疑异方差时，可勾选“参数估计值的稳健标准误”，提供 **HC0 至 HC4** 系列校正（推荐小样本使用 HC3 或 HC4）。
- **模型诊断图**：分布-水平图（Spread vs. Level）、残差图。
- **失拟检验 (Lack of Fit)**：当存在协变量且部分观测单元在所有预测变量上具有完全相同的取值（重复观测）时可用。

## 附录 D：方差成分过程（VARCOMP 独立菜单）

*注意：方差分量的估计在 SPSS 中是一个独立的菜单路径（**分析 → 一般线性模型 → 方差成分**），不与“单变量”合并。*

- **适用场景**：主要目的是估算随机效应贡献的方差比例（如量表信度理论、测量系统分析 G&R），而非假设检验。
- **估计方法**：支持 MINQUE、ANOVA（矩估计）、ML（最大似然）、REML（限制最大似然）。
- **建议**：复杂交叉分类或嵌套的随机结构，直接使用 `MIXED` 过程更为稳健灵活。
