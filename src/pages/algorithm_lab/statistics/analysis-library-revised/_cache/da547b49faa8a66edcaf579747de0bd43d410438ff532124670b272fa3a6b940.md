# 降维（Dimension Reduction）— 菜单总览

- **slug**: dimension-reduction-menu-spss
- **菜单**：**分析 → 降维**（Analyze → Dimension Reduction）
- **标签**：EFA, PCA, Correspondence-Analysis, CATPCA

## 1. 回答什么问题

降维分析旨在将**高维多变量**信息压缩为**低维度**的综合指标，同时尽可能保留原始数据中的变异信息或结构特征。在 SPSS 中，主要包含三种不同视角的降维工具：
- **因子分析 / 主成分分析（Factor / PCA）**：提取连续变量背后的潜变量结构（EFA）或寻找方差最大的正交主成分方向（PCA）。
- **对应分析（Correspondence Analysis, CA）**：将分类变量列联表中的行与列降维，以几何空间中点与点的距离展示类别间的关联。
- **分类主成分分析 / 最优标度（CATPCA）**：针对混合测量级别（名义、有序、连续）变量，在进行非线性量化的同时提取主成分。

## 2. 不适用 / 易滥用

- **EFA 与 PCA 概念混淆**：这是最常见的错误。PCA 是一种纯数学的数据压缩方法（无误差项，最大化方差解释）；探索性因子分析（EFA）是一种测量模型，假设观测变量由潜因子和特定误差（唯一方差）构成。尽管在 SPSS 中主成分法常被用作 EFA 的默认提取方法，但两者的**解释目的截然不同**。
- **样本量严重不足**：因子分析与对应分析依赖于协方差/相关矩阵或列联表的稳定性。变量数多而样本量少会导致协方差矩阵非正定或结果严重过拟合（一般建议题项与样本量比例至少 1:5 到 1:10）。
- **CATPCA 的非单调变换过拟合**：若对有序或连续变量允许自由的非线性变换，极易过度拟合样本噪声，导致结果无法推广。需依赖理论约束或进行交叉验证。

## 3. 数据与设计前提

- **因子分析（EFA）**：
  - **适度相关**：变量间需存在有意义的相关性（相关矩阵非单位矩阵）。
  - **分布假设**：若采用**最大似然法（ML）**提取因子，需严格假设变量服从多元正态分布；若数据存在严重偏态或峰度异常，应改用**主轴因子法（PAF）**。
- **对应分析（CA）**：
  - **充足频数**：基于交叉列联表，要求单元格期望频数不能过低（经验法则与卡方检验类似：期望频数 $< 5$ 的单元格不应超过 20%）。
  - **无负值**：数据矩阵（通常是频数或计数）必须全为非负数。
- **最优标度（CATPCA）**：
  - **测量级别准确**：必须正确声明变量是名义（无序）、有序还是数值型，这将直接决定其量化（变换）时的约束条件。

## 4. 模型或检验统计量（含自由度逻辑）

- **因子分析（EFA）**：
  - **KMO 测度**（Kaiser-Meyer-Olkin）：比较观测相关系数与偏相关系数的相对大小。
  - **Bartlett 球形度检验**：检验相关矩阵是否显著异于单位矩阵，统计量近似服从 $\chi^2$ 分布，自由度为 $p(p-1)/2$（$p$ 为变量数）。
  - **特征值（Eigenvalue）**与**共同度（Communality）**。
- **对应分析（CA）**：
  - **惯量（Inertia）**：衡量行/列轮廓偏离平均轮廓的程度，总惯量等于皮尔逊卡方统计量除以总样本量（$\chi^2/N$）。
  - **奇异值（Singular Value）**：协方差矩阵分解后的特征值平方根。
- **分类主成分分析（CATPCA）**：
  - **方差解释比例（VAF / Variance Accounted For）**：最优量化变换后，主成分对变换后数据的方差解释率。

## 5. 假设与诊断

| 假设/前提条件 | 检查方式 / 统计量 | 经验阈值 / 经验法则 (Rule of Thumb) | 违背时的典型后果 |
| :--- | :--- | :--- | :--- |
| **EFA: 矩阵可分解性** | KMO 抽样适度测度 | KMO $\ge 0.60$ (或 0.70 为佳) | 不适合进行因子分析 |
| **EFA: 变量非独立** | Bartlett 球形度检验 | $p < 0.05$ (拒绝单位矩阵假设) | 提取不出公共因子 |
| **EFA: 多元正态** (仅限 ML 法) | 峰度/偏度，Mardia 检验 | 若偏态严重 | ML 拟合优度检验失真；应改用 PAF 法 |
| **EFA: 因子数量与结构** | 碎石图、残差相关矩阵 | 特征值 $> 1$；非对角线残差 $< 0.05$ | 因子解释牵强，或遗漏重要潜变量 |
| **CA: 列联表频数** | 交叉表单元格期望频数 | 期望频数 $< 5$ 的单元格 $\le 20\%$ | 低频类别造成异常值，点位置严重误导 |

## 6. 效应量与区间

降维方法本身主要作为数据预处理或探索工具，传统上较少报告置信区间，但需报告以下反映“降维效果”的指标：
- **累积方差解释率（%）**：提取的主成分/因子解释了原始数据总方差的百分比。
- **因子载荷（Factor Loading）**：变量与因子之间的相关系数（正交旋转下）。通常 $> 0.40$ 被认为具有实质解释意义。
- **惯量比例**：对应分析中，报告前一两维解释总惯量的百分比（类似方差解释率）。
- **不确定性评估**：现代方法推荐使用 Bootstrap 对因子载荷或对应分析中点的坐标进行重抽样，以评估其稳定性（需借助 R/Python 或 SPSS 附加模块）。

## 7. 与相关方法的取舍

- **PCA vs. EFA**：若目的仅为减少自变量数量并消除多重共线性（用于后续回归），首选 **PCA**；若目的在于编制问卷、探索不可观测的潜变量（如“焦虑”、“满意度”），并认为指标存在测量误差，必须使用 **EFA**。
- **对应分析（CA） vs. 对数线性模型（Log-Linear）**：**CA** 是一种**几何展示**技术，直观揭示类别间的邻近关系，但不提供参数推断；**对数线性模型**则是对列联表频数进行**模型化**，提供主效应与交互作用的严格统计检验。
- **CATPCA vs. 项目反应理论（IRT）**：处理分类题项（如多选题、李克特量表）的降维时，CATPCA 是一种非参数/半参数的数据驱动方案；若追求更严谨的测量学属性（难度、区分度、被试能力估计），应转向 IRT 模型。

## 8. 实现速查

- **SPSS Syntax**：
  - EFA/PCA：`FACTOR` 过程（详见子对话框卡片）。
  - 对应分析：`CORRESPONDENCE`。
  - 最优标度：`CATPCA`。
- **R 语言生态**：
  - 因子分析：首选 `psych` 包（`fa()` 函数），全面优于内置 `factanal()`。
  - 对应分析与 PCA：`FactoMineR`（`CA()`，`PCA()`）。
  - 最优标度：`Gifi` 包或 `homals` 包。
- **Python 生态**：
  - 因子分析：强烈推荐 `factor_analyzer` 包（`from factor_analyzer import FactorAnalyzer`）。*注：避免使用 `sklearn.decomposition.FactorAnalysis`，因其不支持心理学常用的因子旋转（如 Varimax/Promax）。*
  - PCA：`sklearn.decomposition.PCA`。
  - 对应分析：`prince` 包。

## 9. 报告清单

撰写科研论文时，依据不同方法，需在“数据分析”或“结果”部分报告以下结构化要素：

**【因子分析 (EFA) 报告要素】**
1. **适用性检验**：报告 KMO 值（通常要求 $>0.7$）及 Bartlett 球形度检验的近似卡方值、自由度与 $p$ 值。
2. **提取与旋转策略**：明确说明使用的提取方法（如主轴因子法 PAF 或主成分法 PC）与旋转方法（如最大方差正交旋转 Varimax，或斜交旋转 Promax/Oblimin）。
3. **因子保留依据**：说明保留因子的标准（特征值 $>1$、碎石图拐点、或平行分析），并报告提取出的因子能解释的**累积方差百分比**。
4. **因子载荷矩阵**：报告旋转后的因子载荷表（为体现简单结构，通常隐去绝对值 $< 0.30$ 或 $0.40$ 的交叉载荷），报告各因子的共同度，并对潜因子进行合理命名。

**【对应分析 (CA) 报告要素】**
1. **总惯量与检验**：报告列联表的总惯量及对应的卡方独立性检验结果。
2. **维度提取与解释率**：报告各维度的奇异值、惯量以及前两维的**累积惯量解释比例**。
3. **几何解释**：提供双标图（Biplot），并解读行点与列点在特定象限或轴向上的聚集情况（注意：行点与列点间的绝对距离不能直接解释，应基于原点方向解释其对应关系）。

**【最优标度 (CATPCA) 报告要素】**
1. **测量级别声明**：说明各个变量在模型中被设定为何种级别（名义、样条有序等）。
2. **拟合度**：报告总方差解释率（VAF）。
3. **量化结果**：必要时展示非线性变换后的类别量化图。
