# 探索性因子分析（EFA）— SPSS 因子对话框

- **slug**: factor-analysis-spss
- **菜单**：**分析 → 降维 → 因子**（Analyze → Dimension Reduction → Factor）

## 1. 回答什么问题

探索性因子分析（EFA）旨在从一组多题项/多变量的相关结构中提取**少数潜在因子（Latent Factors）**，以解释观测变量间的**共同方差（Shared Variance）**。其核心逻辑是：观测变量之间的相关性是由背后的潜在构念（因子）所引发的。通过**旋转（Rotation）**技术，EFA 能够使因子载荷矩阵趋向简单结构，从而赋予因子明确的理论解释。

> **核心辨析：EFA vs. PCA（主成分分析）**
> - **EFA**：模型包含**唯一方差（Unique Variance，含测量误差）**，仅对变量间的共同方差进行降维。提取方法常为**主轴因子法（PAF）**或**最大似然法（ML）**。
> - **PCA**：不包含误差项，重在对观测变量的总方差进行正交分解与信息浓缩。在社会科学与心理测量中，若目的是识别潜在构念，应使用 EFA 而非 PCA。

## 2. 不适用 / 易滥用

- **提取个数纯靠特征值 > 1（Kaiser 准则）**：极易导致高估因子数量（提取出过多无意义的碎步因子）。应结合**平行分析（Parallel Analysis）**、**碎石图（Scree Plot）**及**理论可解释性**综合判定。
- **将因子得分等同于真实潜变量**：计算出的因子得分（Factor Scores）存在**不确定性（Factor Indeterminacy）**与估计误差，将其直接带入后续回归模型会低估真实效应（建议使用 SEM/CFA 处理复杂路径）。
- **多维结构强迫抽取单因子**：即使 KMO 极高，若数据实质为多维，强行提取单因子会导致模型拟合极差且掩盖真实结构；必须由理论主导。
- **未验证的单维度提纯**：直接对未经检验的题项池进行 EFA 剔除题项以“凑”出好结果，属于数据挖掘而非测量构建。

## 3. 数据与设计前提

- **样本量充足**：常见经验法则为题项数的 5~10 倍（$n/p$ 比例），且绝对样本量通常建议 $> 150$ 或 $200$（视共同度大小而定；共同度普遍 $> 0.6$ 时样本量要求可放宽）。
- **数据连续性与分布**：经典 EFA 假设数据连续或近似连续（如 5 点或 7 点李克特量表）。
  - **进阶提示**：对于类别较少（如 3 点或 4 点）且**严重偏态**的顺序（Ordinal）数据，使用传统的 Pearson 相关矩阵会导致因子载荷被低估、析出人为的“难度因子”。此时应考虑使用**多项相关矩阵（Polychoric Correlation）**（需借助 R 或 SPSS 宏实现）。
- **多重共线性处理**：极端高相关（$r > 0.9$）的变量可能导致相关矩阵非正定（Singular），需审查并考虑合并或删除冗余题项。

## 4. 模型或检验统计量

- **KMO 抽样适切性检验（Kaiser-Meyer-Olkin）**：衡量变量间偏相关性相对大小。整体 KMO 应 $> 0.6$（理想状态 $> 0.8$）；同时可观察反映像矩阵（Anti-image）对角线的单变量 KMO。
- **Bartlett 球形检验**：
  - $H_0$：总体相关矩阵为单位阵（即变量间彼此独立）。
  - **判断**：必须**拒绝 $H_0$**（$p < 0.05$），才表明数据存在足够的相关性以支持提取因子。
- **共同度（Communality, $h^2$）**：提取出的所有因子对某个观测变量方差的解释比例。通常要求提取后的共同度 $> 0.3$ 或 $0.4$。

## 5. 假设、诊断与动态迭代删题

EFA 往往是多次迭代的过程。以下是假设违背的诊断与常见的**题项删减原则**：

| 检查维度 | 检查指标与标准 | 典型后果或操作建议 |
| :--- | :--- | :--- |
| **整体适用性** | KMO $< 0.6$ 或 Bartlett 检验不显著 | 变量间缺乏共同基础，**不适合**做因子分析。 |
| **单题有效性** | 提取后共同度（$h^2$）$< 0.3$ 或 $< 0.4$ | 该题项与潜在因子关联极弱，建议**优先考虑剔除**。 |
| **简单结构性** | 存在**严重交叉载荷（Cross-loading）** | 即某题在两个因子上的载荷均 $> 0.4$ 且差值 $< 0.2$。建议**剔除**以保证因子纯度。 |
| **因子饱满度** | 某因子下只包含 1~2 个题项 | 因子不稳定。若无强理论支撑，应考虑**剔除该因子及相关题项**，或重新指定提取因子数。 |
| **模型拟合度** | 再生矩阵与残差矩阵（Residuals） | 若绝对值 $> 0.05$ 的非冗余残差比例较高（如 $> 50\%$），说明当前因子数**未能充分解释**原相关矩阵，需增加因子数。 |

## 6. 旋转方法与矩阵解读（核心设定）

旋转的目的是逼近“简单结构（Simple Structure）”，使每个变量尽量只在一个因子上具有高载荷。

### 6.1 正交旋转 vs. 斜交旋转
- **斜交旋转（Oblique Rotation, 如 Promax, Direct Oblimin）**：**允许因子之间存在相关性。** 行为与社会科学中的潜变量（如焦虑与抑郁、满意度与忠诚度）几乎总是相关的。**实务建议：默认首选斜交旋转。** 若结果显示因子间相关系数极低（如所有 $|r| < 0.2$），可为了简约性退回正交旋转。
- **正交旋转（Orthogonal Rotation, 如 Varimax）**：**强制因子之间完全独立（$r = 0$）。** 仅在明确假设因子相互独立，或为了规避后续回归的多重共线性时使用。

### 6.2 斜交旋转下的矩阵解读
如果使用了斜交旋转，SPSS 会输出两个关键载荷矩阵，需正确区分：
1. **模式矩阵（Pattern Matrix）**：控制了其他因子后，因子对变量的**唯一贡献（偏回归系数）**。**论文中主要报告此矩阵的载荷。**
2. **结构矩阵（Structure Matrix）**：变量与因子之间的**零阶相关系数**。由于因子间相互相关，此矩阵含有冗余方差，通常仅作辅助参考，不作为界定因子的主要依据。

## 7. 与相关方法的取舍

- **与 PCA（主成分分析）**：若仅需将几十个指标合成为几个综合指数用于预测，且不关心变量背后的理论构念，选 PCA；若需开发量表、探索潜在心理或理论特质，必须选 EFA。
- **与 CFA（验证性因子分析）**：EFA 用于“探索”未知结构（变量可在所有因子上自由载荷）；CFA 用于“验证”已有理论或 EFA 提出的先验结构（强迫变量只在指定因子上载荷，其余固定为 0）。通常需将样本对半拆分，一半做 EFA，一半做 CFA。

## 8. 实现速查与避坑指南

- ⚠️ **SPSS 的终极避坑警告**：在 SPSS `分析 -> 降维 -> 因子` 的“提取”面板中，**软件默认方法是“主成分（Principal Components）”**。如果执行真正的 EFA，**必须手动将其更改为“主轴因子（PAF）”或“最大似然（ML）”**。
- **R 语言**：强烈推荐使用 `psych::fa()` 函数。它默认支持平行分析 (`fa.parallel`)、PAF/ML 提取、多种斜交旋转及多项相关矩阵支持，远优于基础包的 `factanal`。
- **Python**：使用 `factor_analyzer` 包，可指定 `method='ml'` 或 `'minres'`，并支持 `promax` 旋转。

## 9. 标准报告清单 (Reporting Checklist)

一篇严谨的量化论文的方法/结果部分，应报告以下 EFA 细节：
- [ ] **缺失值处理机制**（如成对删除 Pairwise、多重插补等）。
- [ ] **因子提取方法**（如主轴因子法 PAF 或 最大似然法 ML，**切忌写“主成分”**）。
- [ ] **因子保留的决策依据**（必须说明：如结合平行分析、碎石图特征及理论可解释性，而非仅靠特征值 $>1$）。
- [ ] **旋转方法**（如 Promax 斜交旋转 或 Varimax 正交旋转；若选正交需说明合理性）。
- [ ] **KMO 值**（$>0.6$）与 **Bartlett 球形检验结果**（$\chi^2$, $df$, $p$ 值）。
- [ ] **累计方差解释率**（提取后的初始或旋转平方和载入，通常 $> 50\%$ 或 $60\%$）。
- [ ] **载荷表**：报告斜交旋转下的**模式矩阵（Pattern Matrix）**或正交旋转下的旋转矩阵。明确说明为了清晰起见，隐藏了低于多少（如 $0.3$ 或 $0.4$）的载荷。
- [ ] **共同度表（Communality）**（可选，或在正文说明均大于阈值）。
- [ ] **因子相关矩阵（Factor Correlation Matrix）**：若使用斜交旋转，必须附加报告此矩阵。

## 附录：SPSS “因子”对话框实务操作指南

为避免盲目点击菜单，以下为标准 EFA 流程的推荐设置（针对量表开发或潜变量提取场景）：

### 附录 A：描述 (Descriptives)
- **统计**：勾选“单变量描述（Univariate descriptives）”（检查异常值）和“初始解（Initial solution）”。
- **相关性矩阵**：**必须勾选“KMO 与 Bartlett 的球形度检验”**。推荐勾选“反映像（Anti-image）”以检查对角线上的单题 KMO 值；勾选“再生（Reproduced）”以评估模型拟合残差。

### 附录 B：提取 (Extraction)
- **方法 (Method)**：**🚨 必须修改！** 将默认的“主成分”改为**主轴因子（Principal axis factoring, PAF）**（不对数据正态性作严格假设，适用性广）或**最大似然（Maximum likelihood, ML）**（当数据严格符合多元正态分布时推荐）。
- **分析 (Analyze)**：默认选择“相关性矩阵（Correlation matrix）”。
- **显示 (Display)**：勾选“未旋转的因子解”和**“碎石图（Scree plot）”**。
- **提取依据**：先保留“基于特征值大于 1”跑第一次以查看碎石图；结合平行分析后，第二次运行需改为**“固定的因子数（Fixed number of factors）”**并输入确定的数字。

### 附录 C：旋转 (Rotation)
- **方法 (Method)**：
  - 首选：**Promax** 或 **直接斜交（Direct Oblimin）**（允许因子相关，符合绝大多数现实场景）。
  - 备选：**最大方差法（Varimax）**（仅当你确定因子间必须正交/不相关时）。
  - *注：Quartimax 和 Equamax 在现代研究中极少使用。*
- **显示 (Display)**：勾选“旋转后的解（Rotated solution）”和“载荷图（Loading plot(s)）”。

### 附录 D：因子得分 (Factor Scores)
- 勾选“保存为变量（Save as variables）”。
- **方法**：**回归（Regression）**法最为常用（得分的方差最大）。Bartlett 法或 Anderson-Rubin 法可在需要得分完全不相关时使用（仅限正交模型）。
- 勾选“显示因子得分系数矩阵”。

### 附录 E：选项 (Options) 与 缺失值
- **缺失值 (Missing Values)**：SPSS 默认“成列删除（Exclude cases listwise）”，如有任何题目缺失，整行数据作废；若样本因随机缺失锐减，请改为**“成对删除（Exclude cases pairwise）”**。
- **系数显示格式 (Coefficient Display Format)**：
  - 勾选“按大小排序（Sorted by size）”（便于阅读结构）。
  - 勾选“取消显示绝对值小于...的系数（Suppress small coefficients）”，建议填入 **`0.30` 或 `0.40`**。这将使得模式矩阵变得极为清晰，一眼识别交叉载荷（空白处即表示载荷低于该阈值）。
