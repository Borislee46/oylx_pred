# 比较平均值 — Means / ANOVA / 比例（选项与事后）

- **slug**: compare-means-options-anova-posthoc-proportions
- **菜单**：**分析 → 比较平均值** 下 **平均值**、**单因素 ANOVA**、**单样本/独立/配对比例**（比例功能视软件版本而定）。
- **说明**：本文档梳理了均值比较与比例推断的核心逻辑及软件实现选项。附录术语已修正界面可能的 OCR/汉化识别错误，以标准统计学用语为准。

---

## 1. 回答什么问题

本模块集成了连续变量与分类变量在不同设计下的差异性检验：

- **【Means / 均值描述】**：按**分组变量**（单层或多层交叉）输出各单元格的描述性统计量（$M, N, SD$），并可附加单因素 ANOVA 表及线性趋势检验。
- **【单因素 ANOVA】**：检验**多组独立样本**的总体均值是否完全相同（$H_0: \mu_1 = \mu_2 = \dots = \mu_k$）。在拒绝 $H_0$ 后，通过**事后检验（Post-hoc）**探究具体哪两组之间存在显著差异，并提供方差不齐时的稳健估计（Welch / Brown–Forsythe）。
- **【比例 / Proportions】**：
  - **单样本**：检验样本比例是否等于理论假设值。
  - **独立两样本**：检验两独立群体的事件发生率差值是否为 0。
  - **配对样本**：检验同一群体在不同条件/时间点下的边际比例是否发生改变（即 McNemar 检验的扩展）。

## 2. 不适用与易滥用场景

- **多因子或含协变量设计**：若存在多个自变量交叉或需控制连续混杂变量，应使用 **GLM（一般线性模型） / ANCOVA**，而非单因素 ANOVA。
- **方差不齐时滥用标准事后检验**：当 Levene 检验提示方差不齐时，若继续使用 LSD 或 Tukey HSD，将导致 I 类错误率失控。**应改用 Welch ANOVA 搭配 Games–Howell 事后检验。**
- **事后检验的“族错误率（FWER）”膨胀**：无节制地进行两两比较（如直接使用无校正的 LSD）会大幅增加假阳性。应根据研究目的选择：探索性全比较用 Tukey HSD，明确的对照组比较用 Dunnett。
- **比例检验中的渐近 Wald 陷阱**：在样本量较小、存在稀疏单元格（期望频数 $<5$）或比例接近 $0$ 或 $1$ 时，基于正态近似的 Wald 法及其 CI 极不可靠。**此时应优先选择 Wilson、Score 或精确检验（Exact binomial）。**

## 3. 数据与设计前提

数据结构的正确预处理是调用对应检验模块的基础：

- **【ANOVA / Means】数据形态与前提**：
  - **长数据格式（Long format）**：一列为分类因子（组别），另一列为连续响应变量。
  - **独立性**：各组观测值必须相互独立。若是同一批受试者的多次测量，必须使用**重复测量 ANOVA**。
- **【比例检验】数据形态与结构差异**：
  - **配对比例**：要求数据为**宽格式（Wide format）**（如“前测”和“后测”各占一列），或频数加权格式，且必须是“同一对象在不同条件下的二分类测量”。
  - **独立比例**：要求两组受试者完全独立，不重叠。

## 4. 模型或检验统计量（含自由度逻辑）

- **【ANOVA】**：
  - 经典 $F$ 统计量：$F = MS_{Between} / MS_{Within}$，自由度为 $df_1 = k-1$，$df_2 = N-k$。
  - **Welch $F$**：利用各组样本方差进行加权修正，自由度 $df_2$ 变为基于组内方差和样本量计算的非整数渐近自由度，对异方差具备强稳健性。
- **【ANOVA 事后检验】**：
  - 构造两两比较的 $t$ 统计量或基于学生化极差分布的 $q$ 统计量。
- **【比例检验】**：
  - **检验统计量**：依据实现选项，计算二项分布精确概率、Score 统计量或 Wald $Z$ 统计量。
  - **置信区间（CI）**：通过反演检验（如 Clopper-Pearson）或闭式渐近公式（如 Agresti-Coull）求得。

## 5. 假设与诊断

| 核心假设 | 检查与诊断方式 | 违背时的典型后果 | 推荐替代方案 |
| :--- | :--- | :--- | :--- |
| **残差/组内正态性**<br>*(ANOVA)* | Q-Q 图、Shapiro-Wilk 检验<br>*(注意：是各组内正态，而非整体正态)* | 小样本下 $F$ 检验的实际 I 类错误率偏离名义水平 $\alpha$ | Kruskal-Wallis 检验 (非参数) |
| **方差齐性**<br>*(ANOVA)* | Levene 检验、残差-拟合值图 | 严重扭曲 $F$ 值及事后检验的 $p$ 值（组间样本量不等时更甚） | **Welch ANOVA** + **Games-Howell** 事后检验 |
| **独立性**<br>*(ANOVA/比例)* | 审查实验设计方案 | 标准误 (SE) 估计严重偏小，极其容易得出假阳性结论 | 采用配对检验、重复测量模型或多层线性模型 |
| **大样本渐近**<br>*(比例 Wald)* | 经验法则：$np \ge 5$ 且 $n(1-p) \ge 5$ | Wald 置信区间覆盖率严重低于标称水平（如 95% CI 实际只有 80%） | **Wilson Score** 或 **Exact (精确二项)** |

## 6. 效应量与区间

- **【ANOVA】**：
  - 报告偏埃塔平方 $\eta_p^2$ 或埃塔平方 $\eta^2$（单因素下两者相等）。
  - **经验解释标准（Cohen, 1988）**：$0.01$（小效应），$0.06$（中等效应），$0.14$（大效应）。
  - 事后检验必须报告**两组均值差**及其 **95% 置信区间**。
- **【比例检验】**：
  - 根据设计报告 **率差（Risk Difference）**、**率比（Risk Ratio）** 或 **优势比（Odds Ratio）** 及其 95% CI。
  - **必须明确标注 CI 的计算方法名**（如“基于 Wilson Score 方法计算 95% CI”）。

## 7. 与相关方法的取舍

- **非参数检验 (Kruskal–Wallis)**：当 ANOVA 的正态性被严重违背且存在极端异常值时使用。注意：K-W 检验对比的是**平均秩**（或中位数），而非均值。
- **线性回归 (OLS)**：在对分类变量进行虚拟变量编码（Dummy coding）后，回归的全局 $F$ 检验与单因素 ANOVA 在数学上完全等价；若需引入连续协变量，则转为 ANCOVA/多元回归。
- **列联表卡方检验**：独立两样本比例相等检验，在统计量上与 $2 \times 2$ 独立性卡方检验（未校正）等价（$Z^2 = \chi^2$）。

## 8. 实现速查

- **R**：
  - **推荐（搭配 `tidyverse`）**：`rstatix` 包（`anova_test()`, `welch_anova_test()`, `tukey_hsd()`, `games_howell_test()`）。
  - **基础**：`aov()` + `emmeans::emmeans()`；`prop.test()`, `binom.test()`, `mcnemar.test()`。
- **Python**：
  - **推荐**：`pingouin` 库（现代科研首选，`pg.anova()`, `pg.welch_anova()`, `pg.pairwise_tukey()`, `pg.pairwise_gameshowell()`）。
  - **基础**：`scipy.stats.f_oneway`；`statsmodels.stats.proportion`。
- **SPSS**：通过 `MEANS`、`ONEWAY` 和 `PROPORTIONS`（语法依版本或有差异，如 `NPAR TESTS`）命令实现。

## 9. 报告清单与 APA 格式范例

科研报告中应清晰呈现推断的完整链路，避免仅报告 $p$ 值：

**【ANOVA 报告要素】**：$F$ 统计量、自由度（组间与组内）、$p$ 值、效应量 $\eta^2$。
> **APA 范例**：“单因素方差分析显示，不同干预组间的焦虑得分存在显著差异，$F(2, 87) = 5.43, p = .006, \eta^2 = 0.11$。”

**【事后检验报告要素】**：是否假定等方差、具体方法名、均值差、置信区间及多重比较校正后的 $p$ 值。
> **APA 范例**：“由于方差不齐，采用 Games-Howell 事后检验。结果表明，干预 A 组的得分显著高于对照组（均值差 $= 3.2, 95\% CI [1.2, 5.2], p = .012$）。”

**【比例检验报告要素】**：检验方法、统计量值、$p$ 值、效应量（如率差）及明确了算法名称的 CI。
> **APA 范例**：“独立样本检验表明，两组成功率差异显著（$\chi^2(1) = 6.72, p = .010$）。干预组成功率较对照组高 15%（Wilson Score $95\% CI [4\%, 26\%]$）。”

| 模块 | 选项 / 术语 | 统计学含义 |
| :--- | :--- | :--- |
| **统计(S)** | 中位数 / 均值 / 标准误 / 最值 等 | 在第一层分组上输出对应的汇总量。 |
| **单元格统计** | 平均值、个案数、标准差 | 输出最常用的描述统计量 $M, N, SD$。 |

### 附录 B：单因素 ANOVA — 事后多重比较

**💡 事后检验选择指南**：
- **比较所有组别（两两比较）**：首选 **Tukey HSD**。
- **所有组别与一个对照组比较**：首选 **Dunnett**。
- **预先计划的少数几个比较**：首选 **Bonferroni** 或 **Sidak**。

| 类别 | 方法名称 | 适用场景与统计特性 |
| :--- | :--- | :--- |
| **假定等方差** | **LSD (最小显著性差异)** | **无多重比较校正**；相当于做多次独立 $t$ 检验，族错误率（FWER）极高。 |
| | **Bonferroni** | 经典 $p$ 值乘子法；严格控制 FWER，但比较次数过多时极其保守（功效低）。 |
| | **Sidak** | 独立检验假设下，理论功效略优于 Bonferroni。 |
| | **Tukey HSD** | 基于学生化极差；**最常用的全面两两比较法**，功效与错误率控制平衡佳。 |
| | **Scheffe** | 适用于所有可能的复杂线性对比（不仅是两两）；极其保守。 |
| | **Dunnett** | **多组对单一控制组**；需在选项中指定控制类别，可做单侧或双侧。 |
| | SNK / Duncan / 其他 | 逐步检验法或针对不等样本量优化；现代统计由于其错误率控制争议，应用逐渐减少。 |
| **不假定等方差** | **Games–Howell** | **方差不齐且样本量不等时的首选**；基于 Welch 自由度修正。 |
| | Tamhane's T2 / Dunnett's T3 | 基于不同界值分布的保守异方差修正法。 |

### 附录 C：单因素 ANOVA — 选项

| 选项名称 | 统计学含义 |
| :--- | :--- |
| **描述** | 输出各组的 $M, SD, N, SE$ 及 95% 均值 CI。 |
| **方差齐性检验** | 执行 **Levene 检验**。显著（$p < .05$）提示拒绝等方差假设。 |
| **韦尔奇 (Welch)** | 当 Levene 检验显著时，**必须**勾选此项以输出稳健的 Welch $F$ 检验结果。 |
| **布朗-福塞斯 (Brown-Forsythe)** | 另一种针对异方差的稳健 $F$ 检验，将组均值替换为组中位数计算。 |
| **平均值图** | 绘制组均值的主效应折线图。 |

### 附录 D：单样本比例 — 选项

| 模块 | 方法选项 | 适用场景与特性 |
| :--- | :--- | :--- |
| **置信区间** | **Agresti-Coull / Wilson Score** | **推荐默认使用**。在 $p$ 极值或小样本时覆盖率优秀。 |
| | **Clopper-Pearson (精确)** | 极其保守，保证实际覆盖率绝对不低于标称水平（如严格 $\ge 95\%$）。 |
| | **Wald / Wald (连续性校正)** | 仅适用于大样本且 $p$ 接近 0.5。极端情况下可能计算出超出 $[0,1]$ 的荒谬区间。 |
| **检验** | **精确二项式 (Exact binomial)** | 精确概率计算，小样本必备。 |
| | **得分 (Score)** | 基于渐近卡方分布，大样本下表现稳健。 |
| | **检验值** | 设定原假设 $H_0$ 的期望比例。 |

### 附录 E/F：两样本比例（独立与配对）

| 模块 | 核心选项 | 统计学含义 |
| :--- | :--- | :--- |
| **独立比例 CI** | **Newcombe / Agresti-Caffo** | **推荐**用于独立两率差的区间估计，收敛与覆盖性能优异。 |
| **独立比例检验** | Hauck-Anderson / Wald H0 | 检验两组比例是否相等；Wald H0 变体在原假设下合并方差进行估计。 |
| **配对比例 CI** | Agresti-Min / Bonett-Price | 用于估计配对二分类数据（如治疗前 vs 治疗后）的边际比例差。 |
| **配对检验** | **麦克尼马尔 (McNemar)** | 经典的配对边际齐性检验（检验发生转变的非对角线频数是否对称）。 |
