# P-P 图（P-P Plots）

- **slug**: pp-plot-spss
- **aliases**: 概率-概率图、正态 P-P 图、Probability-Probability Plot
- **菜单**：**分析 → 描述统计 → P-P 图**（Analyze → Descriptive Statistics → P-P Plots）
- **姊妹篇**：[qq-plot-spss-dialog.md](qq-plot-spss-dialog.md)（二者对分布特征的敏感区域存在核心差异）。

## 1. 回答什么问题

评估样本数据是否符合某种指定的理论分布（如正态分布）。P-P 图通过直接绘制数据的**经验累积分布概率 (Empirical CDF)** 与指定理论分布的**理论累积分布概率 (Theoretical CDF)** 构建散点图。若散点紧密贴合对角参考线，则表明假设分布与数据贴合良好。

**核心特性**：由于累积概率在接近 0 和 1 的两端变化空间被压缩，P-P 图对**分布的中部（集中趋势区域）差异极为敏感**，而其姊妹方法 Q-Q 图则对尾部异常更敏感。

## 2. 不适用 / 易滥用

- **大样本下的过度检验补救**：大样本下，传统的分布检验（如 Kolmogorov-Smirnov 检验）对微小的非系统性偏离极其敏感（极易得出显著的 $p < 0.05$）。此时应**更依赖 P-P 图的视觉判断**，避免因检验功效过大而误判数据不可用，但需谨慎区分轻微的视觉波动与实质性的分布违背。
- **小样本波动**：样本量极小（如 $n < 20$）时，经验 CDF 呈明显阶梯状，图形波动大，难以稳定推断总体分布。
- **离散/分类数据**：名义、有序或二分类变量使用连续分布 P-P 图毫无意义。
- **重复计数证据**：若同时报告 P-P 图、Q-Q 图与 K-S 检验，应视其为相互补充的单一证据链（如检验探查整体、P-P 图确认中部、Q-Q 图确认尾部），切勿将其写成“多项独立指标同时证明正态性”。

## 3. 数据与设计前提

- **变量类型**：必须为连续型尺度变量（Scale）。
- **参数假定**：理论分布的参数（如正态分布的均值 $\mu$ 和标准差 $\sigma$）可以是**先验固定**的，也可以是**由样本数据估算**的。若由样本估算，需注意这会降低图形对均值/方差偏离的敏感度（因为理论模型已被强制拉近样本）。

## 4. 模型或检验统计量

P-P 图本质上是一种**启发式可视化诊断工具**，本身不产生检验统计量或 $p$ 值（严格的检验统计量如 K-S 距离或 Anderson-Darling 统计量由专门的检验过程输出）。图中的对角参考线代表 $F_n(x) = F(x)$。

## 5. 假设与诊断

通过观察散点偏离对角线的形态，可以诊断具体的分布违背模式：

| 图形偏离形态 | 对应的分布偏离诊断（以正态分布为基准时） |
| :--- | :--- |
| **紧贴对角线** | 数据较好地符合参考分布。 |
| **呈现“S 型”曲线** | 数据的**方差或峰度**与理论分布不匹配（如尾部过轻或过重，尽管 P-P 图的尾部视觉被压缩，但中部的 S 型弯曲已能提示此问题）。 |
| **呈现“倒 S 型”曲线** | 同样提示方差或峰度的系统性偏离。 |
| **弓形（整体偏向一侧）** | 数据的**偏度**（Skewness）存在问题，或样本均值与预设的理论均值存在偏差。 |
| **阶梯状严重** | 样本量过小，或数据存在严重的离散化/四舍五入（Ties 过多）。 |

*注：若需精准评估尾部（如极端离群值），应切换至 Q-Q 图或偏离 P-P 图（Detrended P-P Plot，显示残差）。*

## 6. 效应量与区间

P-P 图属于探索性数据分析（EDA），不涉及独立的效应量报告。评估重点在于偏离的**系统性与幅度**。现代统计软件较少为 P-P 图直接绘制置信带，但在部分 R 包中可提供逐点置信区间以辅助视觉推断。

## 7. 与相关方法的取舍

- **与 Q-Q 图取舍**：Q-Q 图比较的是分位数（Quantiles），其横纵坐标刻度被拉伸，**对尾部极值非常敏感**。若研究重点是极值或尾部风险，首选 Q-Q 图；若重点是数据主体部分（中心 80% 的区域）的拟合，首选 P-P 图。
- **与 K-S 检验取舍**：K-S 检验正是基于经验 CDF 与理论 CDF 之间的最大垂直距离（$D$ 统计量）构建的。P-P 图相当于 K-S 检验距离的直观展现。两者通常搭配使用。

## 8. 实现速查

- **SPSS**：图形界面见附录。基础 Syntax 如下：
  ```spss
  PPLOT /VARIABLES=Var1 /TYPE=P-P /DIST=NORMAL.
  ```
- **Python**：使用 `statsmodels` 库直接调用（注意不仅有 `qqplot`，也有专用的 `ppplot`）：
  ```python
  import statsmodels.api as sm
  import matplotlib.pyplot as plt
  # 假设 data 为一维数组
  probplot = sm.ProbPlot(data)
  probplot.ppplot(line='45')
  plt.show()
  ```
- **R**：专用的 `EnvStats` 包提供了便捷的绘图函数 `EnvStats::ppPlot(data, distribution = "norm")`；基础包也可通过手动计算 `ecdf()` 与 `pnorm()` 并绘制 `plot()` 实现。

## 9. 报告清单与模板

**报告要素**：指定的参考分布族、参数估算方式（预设还是样本估计）、采用的比例估算公式（如 Blom、Tukey）、是否进行了预转换（如对数或差分），以及样本量 $n$。

**标准报告模板范例**：
> **中文**：通过观察正态 P-P 图，数据点基本均匀分布在对角参考线两侧，未见明显的“S 型”或弓形系统性偏离，表明数据中段较好地符合正态分布假设，可支持后续的参数检验。
> 
> **英文**：Visual inspection of the Normal P-P plot indicated that the data points closely followed the diagonal reference line without systematic 'S-shaped' or bowed deviations, suggesting the assumption of normality was reasonably met for the central distribution.

## 附录：SPSS 对话框选项指南

### 变量 (Variables)
指定需要进行分布检验的尺度变量。可同时移入多个变量，系统会分别出图。

### 检验分布 (Test Distribution)

| 选项 | 含义与实操建议 |
| :--- | :--- |
| **检验分布** | 下拉可选正态 (Normal)、均匀 (Uniform)、指数 (Exponential) 等理论分布。 |
| **自由度 (df)** | 当选择 t 分布或卡方分布时激活，需用户依据理论设定自由度。 |
| **根据数据估算** | 默认勾选。直接使用样本的均值和标准差（或对应的分布参数）作为理论分布的参数。 |
| **位置 / 标度等参数** | 取消“根据数据估算”后激活，允许手动指定总体的确切参数（如已知总体 $\mu$ 和 $\sigma$）。 |

### 转换 (Transform)

| 选项 | 含义与实操建议 |
| :--- | :--- |
| **自然对数** | 对原始数据先进行 $\ln(x)$ 转换，常用于右偏数据或检验对数正态分布。 |
| **将值标准化(Z)** | 先计算 Z 分数。**注意**：若“分布参数”已选择“根据数据估算”，再勾选标准化无额外意义，反而可能改变解释。 |

### 差异 / 差分 (Proportion Estimation)
*注：此模块主要针对时间序列数据，横截面数据（Cross-sectional data）请保持默认的“无”。*

| 选项 | 含义与实操建议 |
| :--- | :--- |
| **差异 (Difference)** | 进行一阶或高阶差分，以平稳化时间序列。 |
| **季节性差异** | 进行季节性差分，需配合指定**当前周期长度**。 |

### 比例估算公式 (Proportion Estimation Formula)
由于经验累积概率的计算在样本点上有多种平滑估算方法，SPSS 提供以下标准公式（$i$ 为排秩，$n$ 为样本量）。通常保持默认的 Blom 即可，不同公式对大样本结果影响极微：

| 选项 | 公式特征与适用场景 |
| :--- | :--- |
| **Blom** | 默认项。公式约化为 $\frac{i - 3/8}{n + 1/4}$，普适性最强。 |
| **Rankit** | 公式为 $\frac{i - 1/2}{n}$，与期望的正态顺序统计量高度相关。 |
| **Tukey** | 公式为 $\frac{i - 1/3}{n + 1/3}$，Tukey 推荐的稳健估计法。 |
| **van der Waerden** | 公式为 $\frac{i}{n + 1}$，经典非参数统计中的标准平滑分母。 |

### 结的分派 (Ties)
当数据中存在完全相同的数值（Ties / 结）时，如何分配累积概率：

| 选项 | 含义与实操建议 |
| :--- | :--- |
| **平均值 (Mean)** | 默认。为相同的值分配其所在秩的平均经验概率。**推荐做法**。 |
| **高 / 低 (High / Low)** | 统一分配该组同分值所占据的最高秩或最低秩的概率。 |
| **任意打破结 (Break ties arbitrarily)** | 强制为相同数值按数据行出现的先后顺序分配不同的递增累积概率。此举会消除台阶效应，但改变了数据原本的聚集事实，**仅用于特定的探索（如测试检测限），解释需极其谨慎**。 |
