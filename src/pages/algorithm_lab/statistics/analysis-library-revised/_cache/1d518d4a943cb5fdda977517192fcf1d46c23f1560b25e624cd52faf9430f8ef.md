# Bootstrap（自助法）

- **slug**: bootstrap-general
- **aliases**: 重抽样、拔靴法；SPSS/软件界面常写为「Bootstrap」

## 1. 回答什么问题

对某**统计量** $T$（均值差、相关系数、回归系数、OR 等）在**不依赖强参数分布假设**（如严格正态性）时，用**有放回重抽样**近似其**抽样分布**，进而得到 **Bootstrap 标准误 (SE)**、**置信区间 (CI)** 或**p 值**。本质是用「经验数据模拟数据生成机制」的蒙特卡洛近似方法。

## 2. 不适用 / 易滥用

- **统计量非光滑（极易踩坑）**：常规简单 Bootstrap 要求统计量是平滑的（如均值、比例、回归系数）。对于**中位数（Median）、最大值/最小值等极值统计量**，由于其在小样本下非光滑，简单 Bootstrap 会导致分布严重离散和区间扭曲。
- **样本极小或层内 $n_h$ 极小**：Bootstrap 不增加任何超出原始样本的信息量。若原始样本无法代表总体特征（烂数据或极小样本），Bootstrap 分布本身极不稳定，无法「拯救」设计缺陷。
- **独立同分布（i.i.d.）严重违背**：对具有明显聚类（Clustering）或时间序列（Time Series）结构的数据，简单 Bootstrap 必然导致标准误低估。需采用专门的**聚类 Bootstrap** 或 **块 Bootstrap (Block Bootstrap)**。
- **有限总体**：若抽样比很大、需进行有限总体校正（FPC），传统自助法需修改抽样设计。

## 3. 数据与设计前提

- **经典简单 Bootstrap**：从 $n$ 个观测中**有放回**抽取 $n$ 次构成一个伪样本，重复 $B$ 次。
- **分层重抽样**：必须保持各层**样本量结构**与原始数据一致，在各层内部独立有放回抽样。适用于临床试验的多中心数据或按人口学特征的分层抽样。
- **缺失值处理（交互影响）**：重抽样前需明确缺失值处理规则。若是成对/列表删除（Listwise deletion），需在软件中全局设定；若结合多重插补（MI），通常推荐先插补后 Bootstrap，或使用专门的组合算法。
- **可复现性（核心原则）**：必须固定**随机数种子 (Random Seed)** 与重复次数 $B$。
  - **$B$ 的取值经验**：若仅为估算标准误（SE），$B=50 \sim 200$ 通常已足够；若需构建置信区间（尤其是严重依赖尾部形态的 BCa 区间），**$B \ge 1000$ 是强制性底线**（建议 $B=2000$ 至 $10000$）。

## 4. 模型或检验统计量（含区间构造逻辑）

**点估计的报告原则**：**点估计必须使用基于原始样本计算出的统计量 $T$**，而不能用 Bootstrap 重抽样分布的均值 $\bar{T}^*$。若两者相差极大，说明统计量存在严重偏差，需使用 BCa 校正或反思模型。

常用的区间估计方法：
- **百分位 CI (Percentile)**：直接以 $T^*_b$ 的 $\alpha/2$ 与 $1-\alpha/2$ **分位数**为端点；**不**假定 $T$ 呈正态分布，直观且最常用。
- **BCa (偏差校正与加速区间)**：在百分位基础上，利用数据同时做**偏差 (Bias)** 与**偏度/加速 (Acceleration)** 校正。对小样本偏态分布更为稳健，但计算量大，且高度依赖足够大的 $B$ 与合理的统计量光滑性。
- **Bootstrap t**（部分软件支持）：用重抽样估计 $SE(T^*)$，再结合原始统计量构造类似于 $t$ 分布的区间。

## 5. 假设与诊断

| 假设 | 检查方式 | 违背时的典型后果 |
|------|----------|------------------|
| 代表性样本 | 抽样设计审查 | 外推无效，置信区间反映的是伪总体的噪声 |
| 统计量**光滑** | 确认是否为极值/分位数统计量 | 区间严重扭曲、覆盖率失效（如中位数的 CI） |
| 独立同分布 | 聚类/空间/序列结构诊断 | CI 覆盖偏离名义水平，SE 严重低估 |

## 6. 效应量与区间

- 报告格式：**原始样本点估计** + **Bootstrap CI**（必须注明区间类型，如百分位或 BCa）。
- 建议将 Bootstrap CI 与**传统参数/解析 CI** 并列或对照报告。若两者一致，增强结果稳健性说服力；若差异巨大，提示原数据的正态或大样本渐近假设可能不成立。

## 7. 与相关方法的取舍

- **置换检验 (Permutation Test)**：在零假设下数据**可交换 (Exchangeable)** 时更贴切，专用于精确检验；Bootstrap 更偏向保留原数据结构的**抽样分布近似**与区间估计。
- **Jackknife (刀切法)**：每次剔除一个样本。计算量固定为 $n$ 次，对非光滑统计量同样敏感甚至表现更差，目前在算力充裕下多被 Bootstrap 替代。

## 8. 实现速查

- **SPSS**：Bootstrap 在 SPSS 中属于独立的高级模块（Add-on）。**注意：若对话框中该按钮呈灰色或缺失，说明当前许可证未激活此模块。**它常作为具体过程（均值、相关、回归等）的附加选项嵌入。
- **R**：

```r
library(boot)
# 1. 定义统计量提取函数 (d: 数据, i: 重抽样索引)
stat_func <- function(d, i) { mean(d$x[i], na.rm=TRUE) }

# 2. 执行 Bootstrap (设置随机种子以保证可复现)
set.seed(2023)
b <- boot(data, stat_func, R = 2000)

# 3. 提取置信区间
# 注：若 type="bca" 报错（常因样本极小或极值导致雅可比矩阵不可逆），可退化使用 "perc"
boot.ci(b, type = c("perc", "bca"))
```

- **Python** (使用工业级 `scipy` API，优于手写 for 循环)：

```python
import numpy as np
from scipy.stats import bootstrap

# 设定稳健的现代随机数生成器
rng = np.random.default_rng(2000000)
x = df["x"].dropna().values

# Scipy 1.7+ 原生支持，直接计算 BCa 或 Percentile
res = bootstrap((x,), np.mean, confidence_level=0.95, 
                n_resamples=2000, method='bca', 
                random_state=rng)

print(f"Original Stat: {np.mean(x):.4f}")
print(f"Bootstrap 95% CI: [{res.confidence_interval.low:.4f}, {res.confidence_interval.high:.4f}]")
```

## 9. 报告清单

撰写方法学与结果部分时，应明确提供以下信息保障可复核性：
1. **重抽样次数 $B$**（通常报告 1000 或 2000 以上）。
2. **随机数种子 (Seed)**（如果适用）。
3. **CI 的具体类型**（百分位法 / BCa 法）。
4. **抽样策略**（简单全样本 / 分层，若分层需报告分层变量名）。
5. **点估计的来源**（明确说明点估计为原始样本估计值）。
6. **缺失值的处理策略**（多重插补或直接剔除）。

## 附录：SPSS Bootstrap 子对话框选项说明

### 执行 Bootstrap

勾选后，SPSS 将在后台对主过程输出的参数（如回归系数 $B$、相关系数 $r$）做重抽样，在输出表中额外增加 `Bootstrap SE`、`显著性 (双侧)` 与 `置信区间` 列。

### 样本数(N)

即 Bootstrap 重复次数 $B$。界面默认通常较小，建议正式发表前修改为 `1000` 或 `2000`。需根据样本量与模型复杂度权衡计算耗时。

### 设置梅森旋转算法种子(S) / 种子(D)

指定 **Mersenne Twister** 算法的具体数值，固定种子是确保同行或审稿人能完全**复现**同一区间的唯一途径。

### 置信区间

| 选项 | 含义 | 选择建议 |
|------|------|----------|
| **级别(%)(L)** | 置信度，默认为 95 | 视研究规约而定 |
| **百分位数(E)** | 仅依据分位数截断 | 适合对称分布、计算速度快 |
| **加速纠正偏差(BCa)** | 引入偏差与偏度校正 | **首选**，对偏态更稳健，但 $B$ 必须足够大且可能因样本特征计算失败 |

### 抽样

| 选项 | 含义 |
|------|------|
| **简单(M)** | 忽略子群结构，直接对全样本有放回抽取 $n$ 次。通常适用于简单随机抽样数据。 |
| **分层** | 按指定的【分层变量】在各自层内独立重抽样。合并后每层的样本量与原始数据严格一致。 |

- **分层变量(R)**：移入分类变量。适用于自然分层设计（如：临床试验中的干预组与对照组、多中心数据的中心 ID），或必须保持极不平衡的分类类别频数结构不被重抽样破坏时。**简单** Bootstrap 通常不必指定分层。
