# 非参数检验（独立样本 / 相关样本）

- **slug**: nonparametric-tests-spss
- **aliases**: NPAR、秩检验（Rank Tests）、分布自由方法（Distribution-Free Methods）
- **菜单**：**分析 → 非参数检验**（Analyze → Nonparametric Tests）
- **界面**：SPSS 新版多采用**目标 / 字段 / 设置**工作流（对应 `NPTESTS` 过程）；经典旧版对话框为独立的特定检验（对应 `NPAR TESTS` 过程）。论文报告时请以软件具体实现的版本为准。

## 1. 回答什么问题

在**不强加正态性或等方差**等严格参数假定的前提下，比较**独立样本**或**配对/区组样本**的**位置、分布形状或边际结构**是否一致。此类检验多基于**秩次（Ranks）**或**符号（Signs）**，其推断目标通常为检验**随机占优（Stochastic Dominance）**或**分布齐性**；仅在满足特定前置假设（如各组分布形状相同）时，才严格等价于对**中位数（Median）**等位置参数的比较。

## 2. 不适用 / 易滥用

- **将 Mann-Whitney / Kruskal-Wallis 误称作「均值检验」**：秩检验默认评估的是**随机占优**（即一组观测值系统性大于另一组的概率是否不等于 0.5）。只有在**假定各组分布形状和方差完全相同**时，检验才严格转化为「中位数差异」或「位置漂移」的检验。这与 t 检验 / ANOVA 的推断目标有本质区别。
- **忽视多重比较的族错误率（FWER）**：$k$ 样本检验（如 K-W 检验、Friedman 检验）获得全局显著（$p < \alpha$）仅代表「至少有一组/一个处理不同」。必须进行**事后成对比较**，并应用 Bonferroni 或 FDR 等校正以控制假阳性。
- **不加鉴别地使用「自动选择检验」**：虽然现代软件提供「自动决定合适检验」的功能，但极大地降低了方法的可复现性与透明度。在学术论文中，宜**预先登记/明确说明**具体使用了何种检验及其判定逻辑。

## 3. 数据与设计前提

- **独立性 / 匹配性**：
  - **独立样本**：组间观测单位必须相互独立。
  - **相关样本**：数据必须具备严格的配对或区组结构（如同一个体多时点测量、或严格匹配的配对被试）。选错设计结构将导致检验完全无效。
- **测量尺度**：目标变量通常要求至少为**有序分类（Ordinal）**，或偏态严重的**连续变量（Continuous）**。名义分类变量（Nominal）的比较应转向卡方检验或边际齐性检验。

## 4. 模型或检验统计量分类

为贴合研究设计与备择假设，非参数检验可按设计类型分为以下四类：

### 4.1 两独立样本（Two Independent Samples）
- **Mann-Whitney U 检验（M-W U）**：计算两组的秩和。大样本下统计量 $U$ 可近似转化为标准正态 $Z$ 分布。检验随机占优；若分布形状一致，则检验中位数差异。
- **Kolmogorov-Smirnov 两样本检验（K-S 两样本）**：基于两组经验分布函数的最大垂直距离。对位置、尺度和形状的**任何差异**（整条分布）都高度敏感。
- **Wald-Wolfowitz 游程检验**：基于两组合并排序后的“游程（Runs）”数，检验混合随机性。

### 4.2 k 个独立样本（$k$ Independent Samples）
- **Kruskal-Wallis 检验（K-W 检验）**：M-W U 检验在多组下的推广。基于全局秩和，渐近服从自由度 $df = k-1$ 的卡方分布。与 M-W 类似，形状相同时解释为中位数差异，否则为随机占优。
- **Jonckheere-Terpstra 检验（J-T 检验）**：针对**有序分组**（如：低剂量、中剂量、高剂量）的特定备择假设，检验各组中位数是否存在先验的**单调递增/递减趋势**。功效高于无方向性的 K-W 检验。

### 4.3 两相关样本（Two Related Samples）
- **Wilcoxon 符号秩检验（Wilcoxon Signed-Rank）**：计算配对差值的绝对值秩次并赋予原差值符号。**核心假设是配对差值的分布是对称的**。比单纯的符号检验利用了更多信息（大小与方向）。
- **符号检验（Sign Test）**：仅考虑配对差值的正负符号，忽略差值大小。功效通常低于 Wilcoxon，但无需差值对称性假设。
- **McNemar 检验**：针对**二元配对**（如 0/1, 成功/失败）数据，评估两时点或两配对间的边际比例是否发生显著改变。

### 4.4 k 个相关样本（$k$ Related Samples）
- **Friedman 检验**：在各个随机区组（被试）**内部**对 $k$ 个处理进行独立排序（秩次 1 到 $k$），随后检验各处理的平均秩是否有显著差异。
- **Cochran's Q 检验**：McNemar 检验在 $k$ 轮重复测量下的推广，专用于**二元相关结局**的边际差异检验。

## 5. 假设与诊断

| 核心假设 / 现象 | 检查与诊断方式 | 违背或触发时的典型后果及应对 |
| :--- | :--- | :--- |
| **设计结构错配**（独立 vs 相关） | 核查实验设计与数据表结构 | **致命错误**：检验统计量与自由度完全错误，推断无效。 |
| **分布形状不一致**（M-W / K-W） | 绘制各组直方图、箱线图或 Q-Q 图 | 无法解释为「中位数差异」，必须严谨表述为「分布位置/随机占优存在差异」。 |
| **配对差值不对称**（Wilcoxon） | 绘制配对差值的直方图或检查偏度 | 检验实际上比较的是**「伪中位数（Pseudomedian）」**而非真实中位数。严重不对称时应退化使用符号检验。 |
| **结值过多（Many Ties）** | 软件通常会报告结值数量及校正系数 | 导致基于大样本渐近正态的 $p$ 值出现偏差。**应对**：样本较小时，必须请求软件执行**精确检验（Exact Test）**或置换检验。 |
| **分组变量未正确排序**（J-T） | 检查因子水平（Factor Levels）顺序 | 导致单调趋势的备择假设方向错误，得出相反结论。 |

## 6. 效应量与置信区间

非参数检验的 $p$ 值仅表明差异的存在，学术报告需结合以下标准效应量（Effect Sizes）以量化差异幅度：

| 检验类型 | 推荐的效应量指标 | 解释与计算说明 |
| :--- | :--- | :--- |
| **Mann-Whitney U** | Rank-biserial correlation ($r$) | $r = 1 - 2U / (n_1 n_2)$。也可报告 **Cliff's Delta** 或简单的 $Z / \sqrt{N}$。 |
| **Kruskal-Wallis** | Eta-squared ($\eta^2_H$) 或 Epsilon-squared ($\varepsilon^2$) | 衡量组间秩差异解释的总秩变异比例，$\eta^2_H = (H - k + 1) / (N - k)$。 |
| **Friedman** | Kendall's $W$ (肯德尔协同系数) | 范围 0 到 1，评估区组（被试）间排位的一致性 / 效应大小。 |
| **(位置差异估计)** | **Hodges-Lehmann 估计量** | 两样本（独立/配对）位置漂移的**稳健点估计**及相应的**精确置信区间 (CI)**。 |

## 7. 与相关方法的取舍

- **vs. 参数检验（t 检验 / ANOVA）**：当数据大致服从正态分布且方差齐性满足时，参数检验功效（Power）通常更高，且能直接提供具有现实意义的均值差估计。若样本量极大（$N > 1000$），非参数检验对极微小但无实际意义的形状差异可能过度敏感。
- **vs. 置换检验（Permutation Tests）**：当样本量极小但可交换性（Exchangeability）假设成立时，置换检验或精确检验（Exact Test）比依赖大样本渐近理论的传统非参数检验更为可靠。
- **vs. 有序逻辑回归（Ordinal Logistic Regression）**：当因变量为多分类有序变量，且需要**控制混杂协变量（Covariates）**时，应直接使用比例优势模型（Proportional Odds Model）等回归架构，而非单纯的无协变量秩检验。

## 8. 实现速查与实务避坑

- **SPSS**：
  - **新版优势**：在 `NPTESTS` 过程（分析 → 非参数检验 → 独立/相关样本 → 目标：自动）中，若 K-W 检验或 Friedman 检验全局显著，双击结果表格打开**模型查看器（Model Viewer）**，SPSS 会**自动提供带有 Bonferroni 校正的成对事后比较（Step-down）**结果。这是极大提升实务效率的功能。
  - **经典版**：通过 `NPAR TESTS` 语法或经典旧对话框仍可精细控制。
- **R 语言**：
  - 函数：`wilcox.test()`, `kruskal.test()`, `friedman.test()`。
  - **避坑**：`wilcox.test` 遇到数据中存在结值（Ties）时，会默认弹出 Warning 且无法计算精确 $p$ 值。若需处理复杂结值与精确推断，强烈推荐使用专业包 `coin`（如 `wilcox_test()`, `kruskal_test()` 提供了基于渐近、置换及精确的全面计算框架）。
- **Python**：
  - 库：`scipy.stats.mannwhitneyu`, `kruskal`, `friedmanchisquare`。
  - **避坑**：调用 `mannwhitneyu` 时，务必显式设定 `alternative`（双侧或单侧）；针对小样本有结值情况，注意 `method='exact'` 还是 `'asymptotic'` 参数的正确选择。

## 9. 报告清单（科研写作必查）

撰写非参数检验的结果时，禁止仅报告 $p$ 值，应包含以下要素：
1. **研究设计**：明确说明数据结构（独立/配对/区组）。
2. **描述性统计量（强制）**：必须报告各组的**中位数（Median）**以及离散程度，通常为**四分位距（IQR）**或 25%、75% 分位数（如 `Median [Q1, Q3]`）。
3. **检验名称及版本**：指明具体检验（如 Mann-Whitney U 检验）及是否使用了精确检验（如“基于精确概率法”）。
4. **统计量与 p 值**：报告检验统计量值（如 $U$、$Z$ 或 $H$/$\chi^2$ 及其自由度）和精确到三位小数的 $p$ 值。
5. **效应量**：报告对应的效应量（如 $r$, $\eta^2_H$, Kendall's $W$），必要时报告 Hodges-Lehmann 置信区间。
6. **事后多重比较**：若执行了 $k$ 样本全局检验，必须说明事后配对比较的方法及多重检验校正策略（如 Bonferroni 校正）。
7. **表述规范**：避免使用“两组均值存在显著差异”，改为“两组的分布位置/中位数存在显著差异”。

## 附录 B：独立样本 — 常用检验逻辑摘录

| 检验目标 | 检验方法 | 方法学要点 |
| :--- | :--- | :--- |
| **分布位置** | 曼-惠特尼 U (2 样本) | 基于秩和；仅在形状相同时严格解释为中位数差异。 |
| **整体分布** | 柯尔莫戈洛夫-斯米诺夫 (2 样本) | 基于 CDF 的最大垂直距离；对形状、位置、尾部均敏感。 |
| **混合随机性** | 瓦尔德-沃尔福威茨游程 (2 样本) | 检验两组合并排序后，数据是否随机交替出现。 |
| **极端反应** | 莫斯极端反应 (2 样本) | 对分布的两端（尾部）差异尤为敏感。 |
| **$k$ 组位置** | 克鲁斯卡尔-沃利斯 ($k$ 样本) | 全局秩检验；显著后必须搭配事后成对比较。 |
| **$k$ 组趋势** | Jonckheere-Terpstra | 备择假设设定为组间中位数存在单调递增或递减趋势。 |

## 附录 C：相关样本 — 常用检验逻辑摘录

| 数据形态 | 检验方法 | 方法学要点 |
| :--- | :--- | :--- |
| **二分类配对** | 麦克尼马尔 (McNemar) | 检验 2x2 表的非对角线元素（状态反转率）是否对称。 |
| **二分类重复** | 柯克兰 Q (Cochran's Q) | McNemar 的 $k$ 轮扩展；若显著，可开展成对的分类后测。 |
| **连续差值 (忽视幅度)**| 符号检验 (Sign) | 基于差值的二项分布检验；稳健但功效最低。 |
| **连续差值 (对称)** | 威尔科克森符号秩 (Wilcoxon) | 须满足差值对称分布的假设；功效高于单纯符号检验。 |
| **分类一致性** | 边际齐性 (Marginal Homogeneity)| McNemar 检验在多类别（$RxR$ 表）配对数据的扩展。 |
| **$k$ 个随机区组** | 弗里德曼 (Friedman) | 区组内排序；常用于多评委打分一致性或被试内设计分析。 |
