# 二元 Logistic 回归

- **slug**: regression-binary-logistic-spss
- **aliases**: 二分类 Logistic, 二元逻辑回归, 优势比 OR, LOGISTIC

## 1. 回答什么问题

在因变量为**二分类** \(Y\in\{0,1\}\) 的情况下，建立协变量 \(X\) 与结局发生概率的对数优势（**logit**）之间的线性模型：\(\mathrm{logit}(P(Y=1|X)) = \ln\left(\frac{P}{1-P}\right) = \beta_0 + X\beta\)。
- **推断目的**：控制混杂因素后，评估特定自变量对结局的独立关联效应，通常通过**优势比（Odds Ratio, OR）**及其置信区间进行量化。
- **预测目的**：计算特定协变量组合下结局事件发生的**预测概率**，用于风险分层、诊断分类或预测模型构建。

## 2. 不适用 / 易滥用

- **将 OR 误释为相对风险（RR）**：当结局非稀有事件（发生率通常 $>10\%$）时，OR 会在数值上显著夸大相对风险（RR）。若研究目的是估计 RR，应改用 **Poisson 回归（结合稳健方差，即 modified Poisson）**或 **log-binomial 回归**。
- **完全/准分离（Separation）与稀有事件**：当某个分类自变量能完美预测结局（如某亚组中事件发生率为 0% 或 100%）时，会导致极大似然估计下的系数与标准误（SE）**发散/极大**。此时需采用 **Firth 惩罚似然法（Firth's penalized likelihood）**、贝叶斯方法、或在临床合理前提下合并稀疏类别。
- **聚类 / 重复测量数据**：标准 Logistic 回归假设观测间**相互独立**。若存在嵌套或重复测量设计，需改用 **GEE（广义估计方程）**或**混合效应 Logistic 回归（GLMM）**。
- **自变量与 logit 关系的误设**：默认连续自变量与结局的对数优势呈线性关系，若违背（如 U 型关系），需引入**限制性立方样条（RCS）**、多项式或将其离散化为分类变量。

## 3. 数据与设计前提

- **结局与参考类别编码**：分析前需明确且统一编码结局（通常 1 = 关注事件/阳性，0 = 参照事件/阴性）。分类自变量**必须明确指定参考类别（Reference group）**，否则 OR 值无法解释。
- **样本量（EPV 准则）**：经验法则（Events Per Variable, EPV）建议，**每组事件数（结局中较少那类的例数）**与模型中的**参数个数（自由度）**之比至少应达到 10~20，否则极大似然估计的渐近性质不可靠，易出现小样本偏倚（过拟合、置信区间过宽）。

## 4. 模型或检验统计量（含自由度逻辑）

- **似然与估计**：模型通过最大化对数似然函数 \(\ell(\beta)=\sum_{i=1}^n [y_i \log P_i + (1-y_i) \log(1-P_i)]\) 求解，通常采用牛顿-拉夫逊（Newton-Raphson）等迭代算法进行**极大似然估计（MLE）**。
- **全局检验（模型显著性）**：常用**似然比检验（LR test）**、Wald 检验或得分检验（Score test）。统计量渐近服从 \(\chi^2\) 分布，自由度为模型新增的参数个数。推荐优先报告似然比检验。
- **系数推断**：通过取指数得到 \(\mathrm{OR} = \exp(\beta_j)\)。置信区间（CI）有两种常见计算方式：
  - **Wald CI**：基于参数估计值的渐近正态性（软件默认常见，如 SPSS、R 的 `default`），计算快，但在极值或小样本下可能欠准确。
  - **Profile Likelihood CI（轮廓似然置信区间）**：通过反演似然比检验得到，统计学上更精确，推荐在样本量小或边界效应附近时使用。
- **模型解释力与拟合优度**：
  - **伪 \(R^2\)**：如 Cox & Snell 或 Nagelkerke 伪 \(R^2\)，用于相对比较，但不能像 OLS 线性回归那样解释为“方差解释率”。
  - **Hosmer-Lemeshow (HL) 检验**：经典的校准度检验，但**存在争议**（其 p 值对连续变量的分组方式和组数高度敏感）。现代实践中，建议结合**信息准则（AIC/BIC）**、**Brier Score** 或直接绘制**校准曲线（Calibration plot）**。

## 5. 假设与诊断

| 假设 | 检查方式 | 违背时的典型后果 |
|------|----------|------------------|
| **独立观测** | 设计审查、数据收集逻辑排查 | SE 偏误，过度自信（p 值假阳性） |
| **无严重多重共线性** | 计算自变量的 **VIF（方差膨胀因子）**、容差 | SE 极度膨胀，OR 值失真甚至符号反转 |
| **线性于 logit** | **残差图**、**Box-Tidwell** 检验、样条拟合对比 | 模型错设，特定区间的预测校准度差 |
| **无严重分离/稀疏数据** | 软件收敛预警、**交叉表稀疏单元格**检查 | 估计极度不稳定、系数发散（需 Firth 惩罚） |
| **无过度影响点** | **标准化残差**、杠杆值、**Cook 距离** | 单个或极少数异常样本主导模型的估计结果 |

## 6. 效应量与区间

- 报告的核心效应量为 **OR** 及其 **95% 置信区间**。
- 在包含**交互作用项**或需面向非专业受众时，直接解释 OR 容易引起混淆，强烈建议报告**边际效应（Marginal Effects）**，或展示在代表性协变量模式下，结局**预测概率**的具体变化。
- 在预测语境下，需额外报告分类性能指标（**敏感度、特异度**）、**ROC 曲线及 AUC（C 统计量）**。

## 7. 与相关方法的取舍

- **Probit / 互补 log-log 回归**：使用正态累积分布或极值分布作为链接函数。通常与 Logistic 回归结果相近，但在尾部概率极小/极大时有差异，多用于计量经济学或特定生物检定。
- **条件 Logistic 回归**：专门用于**匹配（如 1:m 匹配的病例对照研究）**或**分层**设计，以消除层内基线差异带来的干扰。
- **多元/有序 Logistic 回归**：若结局为多于两类的无序分类变量（名义），需用多项式 Logistic；若为有序分类变量（等级），需用有序 Logistic（需满足比例优势假设/平行线检验）。详见 [regression-linear-logistic-curve-quantreg-spss-dialogs.md](regression-linear-logistic-curve-quantreg-spss-dialogs.md)。

## 8. 实现速查

### SPSS 实现
**分析 → 回归 → 二元 Logistic** 
- **分类（Categorical）按钮**：用于将多分类变量设为虚拟变量，**务必确认“参考类别”（第一个或最后一个）**。
- **选项（Options）按钮**：推荐勾选**霍斯默-莱梅肖拟合优度(H)**、**分类图**、**迭代历史记录**、**Exp(B) 的置信区间**（默认 95%）。

### R 实现

```r
# 拟合二元 Logistic 回归模型
fit <- glm(y ~ x1 + factor(x2), data = d, family = binomial(link = "logit"))
summary(fit)

# 提取 OR 及 95% CI
# confint(fit) 默认计算 Profile Likelihood CI（推荐，更精确但耗时）
# confint.default(fit) 计算 Wald CI（与 SPSS 等商业软件默认一致）
exp(cbind(OR = coef(fit), 
          `Profile 2.5%` = confint(fit)[, 1],
          `Profile 97.5%` = confint(fit)[, 2]))

# 若需 Firth 惩罚似然估计，可使用 logistf 包
# library(logistf); fit_firth <- logistf(y ~ x1 + x2, data = d)
```

### Python 实现

```python
import numpy as np
import statsmodels.api as sm

# statsmodels 不会自动添加截距项，必须显式添加
X = sm.add_constant(d[["x1", "x2"]]) 
y = d["y"]

# 拟合模型
logit = sm.Logit(y, X).fit(disp=False)
print(logit.summary())

# 提取 OR 及其 Wald CI
params = logit.params
conf = logit.conf_int()
conf['OR'] = params
conf.columns = ['Wald 2.5%', 'Wald 97.5%', 'OR']
print(np.exp(conf))
```

## 9. 报告清单

撰写学术论文时，建议按以下清单核对报告内容：
1. **变量定义与编码**：结局变量的定义（谁是 1，谁是 0）；**必须明确所有分类变量的参考类别（Reference group）**。
2. **样本构成与 EPV**：纳入分析的有效 N 以及结局事件的发生数（以证明样本量充足，未违反 EPV 法则）。
3. **模型评估指标**：
   - 全局检验（如模型似然比检验 $\chi^2$ 及 p 值）。
   - 模型解释力评估（如 Cox & Snell 或 Nagelkerke 伪 $R^2$）。
   - （如适用）Hosmer-Lemeshow 检验或校准度说明。
4. **核心效应量**：报告自变量的未调整及多因素调整后的 **OR 值、95% CI 及 p 值**。
5. **预测性能评估（预测任务）**：必须报告 **AUC（C-index）** 与校准度（Calibration）；必要时提供截断值及对应的灵敏度/特异度。
6. **敏感性与探索性声明**：若使用了逐步回归（Stepwise）进行变量筛选，必须说明其**探索性性质**及纳入/剔除准则（如 $P_{in}=0.05, P_{out}=0.10$）。若嵌套了多个模型（Model 1, Model 2...），需说明增量加入变量的逻辑。

## 附录：SPSS「二元 Logistic → 选项」界面词摘录

以下为 SPSS 软件内中文菜单常见勾选项与统计学含义的对照，便于核查与复现：

### 统计和图 (Statistics and Plots)

| 选项名称 | 统计学含义与用途 |
|----------|------------------|
| **分类图 (Classification plots)** | 绘制基于模型预测的 logit 分组条形图，直观评估两类样本的重叠情况。 |
| **霍斯默-莱梅肖拟合优度 (H)** | Hosmer-Lemeshow 检验，判断预测概率与实际发生率是否偏离过大（对连续变量分组方式极度敏感）。 |
| **个案残差列表 (Casewise listing of residuals)** | 输出每个样本的残差/标准化残差，用于识别异常值。 |
| **离群值 / 标准差倍数 (Outliers outside...)** | 配合上述残差列表使用，通常设为标准化残差 $>2$ 或 $3$ 以定位极端个案。 |
| **估算值的相关性 (Correlations of estimates)** | 输出参数估计值的相关矩阵，辅助判断多重共线性（高度相关可能预示共线性）。 |
| **迭代历史记录 (Iteration history)** | 显示 MLE 逐步逼近收敛的过程，若未收敛可借此诊断参数发散点。 |
| **Exp(B) 的置信区间 (CI for exp(B))** | 输出 OR 值的置信区间（默认 95%，即 Wald CI）。 |

### 显示与步进 (Display and Stepping Options)

| 选项名称 | 统计学含义与用途 |
|----------|------------------|
| **每个步骤 / 最后一个步骤** | 若使用逐步回归，决定是打印每一次变量进出的冗长报告，还是仅展示最终确定的模型。 |
| **步进概率：进入 / 除去** | 逐步回归的统计显著性阈值（通常设定 Entry=0.05, Removal=0.10）。 |
| **分类分界值 (Classification cutoff)** | 将连续的预测概率划分为 0 或 1 的阈值，默认 0.5。在不平衡样本中通常需要手动调整。 |
| **最大迭代次数 (Maximum iterations)** | MLE 算法的迭代上限，默认通常为 20。若遇严重共线性或分离，增加此值无济于事，模型仍不收敛。 |
| **在模型中包括常数 (Include constant in model)** | 是否拟合截距项 $\beta_0$（极少情况下依特定设计不勾选，绝大多数情况必须保留）。 |
