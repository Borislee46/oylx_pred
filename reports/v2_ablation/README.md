# V2: 五层概率调整链 Ablation Study

## 方法

在 12,344 条测试 case 上，逐层关掉概率调整链，比较排序变化。
所有层通过 Arbitrator 的衰减机制（decay=0.85^n）叠加，总惩罚上限 70%。

## 结果矩阵

| Layer | Kendall τ | Mean \|Δprob\| | Affected % |
|-------|-----------|----------------|------------|
| L2 语言惩罚 | 0.0232 | 0.0484 | 35.2% |
| L4 跨学部惩罚 | 0.0229 | 0.0351 | 19.5% |
| L1 GPA惩罚 | 0.0194 | 0.0096 | 46.8% |
| L3 跨专业惩罚 | 0.0185 | 0.0039 | 35.9% |
| L5 职业学位惩罚 | 0.2756 | ~0 | 0.2% |
| **全部关掉** | **0.0023** | **0.1410** | 100% |

## 关键发现

### 1. 五层调整链是系统排序的核心 — 不是锦上添花

全关掉后 τ≈0（XGBoost raw 概率排序与完整业务规则排序几乎无关）。
没有调整链 → raw XGBoost 排序跟业务规则排序完全独立。

**面试叙事**：
> "人们以为 ML 模型占主导，后处理只是微调。我做了 ablation 后发现——五层全关，τ 掉到 0。后处理不是微调，是系统的核心排序机制。"

### 2. 语言惩罚是单层概率影响最大的因子

- |Δprob| = 0.048（是其他层的 1.4-5 倍）
- 影响 35.2% 的 case
- 因为语言成绩有硬门槛——阶梯函数在门槛附近产生显著的离散概率跳变

### 3. 跨学部惩罚只影响 19.5%，不是之前以为的 49%

生产环境使用 CROSS_FACULTY_RULES：理学院 → 工程学院是允许的（不触发惩罚），理学院 → 法学院才会触发 ×0.3。这个设计允许相关学部之间自由流通。

### 4. 层间通过 decay 机制高度耦合

单个层关掉的 τ≈0.02（排序几乎重排），不是因为该层本身影响大，而是因为 decay 级联效应：关掉一层 → 剩余层的衰减减弱 → 所有剩余惩罚被放大。这是 Arbitrator 的设计特征，不是 bug。

### 5. 职业学位惩罚是精准的"外科手术式"规则

只影响 0.2% 的 case（MBA/商业管理类 + 无实习），τ=0.28。这是 5 层里唯一没有全局影响的层——它是针对特定场景的精确规则。
