# V2: 五层概率调整链 Ablation Study

## 方法

在 12,344 条测试 case 上，逐层关掉概率调整链，比较排序变化。
所有层通过 Arbitrator 的衰减机制（decay=0.85^n）叠加，总惩罚上限 70%。

## 结果矩阵

| Layer | Kendall τ | Mean \|Δprob\| | Affected % |
|-------|-----------|----------------|------------|
| L2 语言惩罚 | 0.0232 | 0.0484 | 35.2% |
| L4 跨学部惩罚 | 0.0229 | 0.0351 | 19.5% |
| L1 GPA惩罚 | 0.0194 | 0.0096 | 46.8% |
| L3 跨专业惩罚 | 0.0185 | 0.0039 | 35.9% |
| L5 职业学位惩罚 | 0.2756 | ~0 | 0.2% |
| **全部关掉** | **0.0023** | **0.1410** | 100% |

## 关键发现

### 1. 五层调整链是系统排序的核心 — 不是锦上添花

全关掉后 τ≈0（XGBoost raw 概率排序与完整业务规则排序几乎无关）。
没有调整链 → raw XGBoost 排序跟业务规则排序完全独立。

**重要方法学注记 (2026-05-13 二轮review)**：关掉单层后的 τ≈0.02 不完全反映该层的独立排序贡献——它包含了 decay 级联效应。关掉一层 → 剩余层的衰减系数变化 → 所有剩余惩罚被放大 → 排序变化被高估。更准确的解读是：**"调整链整体对排序至关重要"**（全关 τ≈0 证实了这一点），但单个层的 τ 值不可直接比较大小。

**面试叙事**：
> "人们以为 ML 模型占主导，后处理只是微调。我做了 ablation 后发现——五层全关，τ 掉到 0。后处理不是微调，是系统的核心排序机制。"

### 2. 语言惩罚是单层概率影响最大的因子

- |Δprob| = 0.048（是其他层的 1.4-5 倍）
- 影响 35.2% 的 case
- 因为语言成绩有硬门槛——阶梯函数在门槛附近产生显著的离散概率跳变

### 3. 跨学部惩罚只影响 19.5%，不是之前以为的 49%

生产环境使用 CROSS_FACULTY_RULES：理学院 → 工程学院是允许的（不触发惩罚），理学院 → 法学院才会触发 ×0.3。这个设计允许相关学部之间自由流通。

### 4. 层间通过 decay 机制高度耦合

单个层关掉的 τ≈0.02（排序几乎重排），不是因为该层本身影响大，而是因为 decay 级联效应：关掉一层 → 剩余层的衰减减弱 → 所有剩余惩罚被放大。这是 Arbitrator 的设计特征，不是 bug。

### 5. 职业学位惩罚是精准的"外科手术式"规则

只影响 0.2% 的 case（MBA/商业管理类 + 无实习），τ=0.28。这是 5 层里唯一没有全局影响的层——它是针对特定场景的精确规则。

## DS 批判反思 (2026-05-13)

V2 的 ablation 方法论本身就是优秀的面试素材——"关一层看排序变化"比"跑个 SHAP"更能展示系统思维。但有两个缺漏：

1. **Ablation 只测了排序影响（Kendall τ），没测校准影响（ECE per layer removed）。** 如果能补上"关掉语言惩罚后 ECE 怎么变"，就能区分"这一层是排序贡献大但校准破坏大"和"排序贡献小且校准破坏也小"——这对参数调优有直接指导。V5 已补上校准维度的缺口。

2. **Kendall τ 测的是差异，不是正确性。** τ=0.02 表示"关掉该层后的排序和全链排序几乎不同"，不是"该层让排序更准确"。全链本身是五层调整链的输出——它不是 ground truth。在没有外部 gold standard（真实录取排序）的情况下，调整链的价值来自：(a) 每层规则有教育领域的先验支持（见 DECISIONS.md），(b) 调整后 predictiveness 方向正确（高分段录取率确实更高）。如果面试官追问"怎么知道调整后的排序是对的"，回答应该是：**"录取不是 RCT，没有反事实 ground truth。我能证明的是——每层惩罚有领域逻辑支撑，且调整后的概率排名与实际录取率正相关。这是 business logic + statistical consistency 的联合论证，不是纯统计论证。"**

另外 decay 级联效应的发现被 2026-05 全链路诊断进一步验证了——5 层叠加后的联合效应确实失控。同时，关单层后的 τ 值包含 decay 级联效应（关一层→其余层衰减变化→排序变化被高估），V5 已补上此缺口。
