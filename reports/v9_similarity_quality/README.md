# V9: Cross-Major Similarity Quality Audit

## 动机

CrossMajor 是五层惩罚链中唯一对校准有正面贡献的层（V5: ΔECE=-0.0016）。但它的输入信号——embedding 相似度——从未被独立验证过。E5-large 模型输出的相似度到底准不准？0.89 的惩罚阈值有没有 empirical basis？

## 方法

在全量 61,716 行 cases.feather 上，将相似度缓存与录取结果关联，分析：
1. 相似度分布（range, spread, density）
2. 分桶录取率（similarity → admit rate）
3. 阈值附近的 cliff effect
4. 学校 tier 混淆检查

## 结果

### 相似度分布

| 指标 | 值 |
|------|-----|
| Range | [0.805, 0.972] |
| Span | **0.167** |
| Std | **0.028** |
| IQR | 0.042 |

**所有专业对被压缩在 0.17 的窄窗内**，标准差仅 0.028。E5-large 对任何真实专业对都不会输出低于 0.80 的相似度。

### 分桶录取率

| Bucket | N | Admit% | Δ vs Overall |
|--------|---|--------|---------------|
| 0.80-0.85 | 1,377 | **26.1%** | -7.8pp |
| 0.85-0.87 | 5,044 | 27.8% | -6.0pp |
| 0.87-0.89 | 9,755 | 28.7% | -5.1pp |
| 0.89-0.91 | 14,314 | 31.0% | -2.9pp |
| 0.91-0.93 | 12,058 | 30.8% | -3.1pp |
| 0.93-0.95 | 12,424 | 35.2% | +1.3pp |
| 0.95-1.0 | 1,460 | **39.5%** | +5.7pp |

**13.4pp 的全距差异**——相似度方向上是有效的。

### 🔴 阈值在噪音区，不是悬崖

| 区间 | N | Admit% | SE |
|------|---|--------|-----|
| 0.87-0.88 | 4,261 | 27.2% | ±0.67pp |
| **0.88-0.89** | **5,494** | **29.8%** | ±0.62pp |
| **0.89-0.90** | **7,173** | **29.0%** | ±0.54pp |
| 0.90-0.91 | 7,141 | 33.0% | ±0.56pp |

**0.88-0.89 vs 0.89-0.90: 差值 0.8pp, z≈1.0, p>0.3 — 不显著。** 0.89 不切在任何真正的录取率断层上——它切在分布最密集的区域，相邻 bin 的录取率在统计上不可区分。这是一个**噪音区**，不是悬崖。

真正的录取率跳变发生在 0.89-0.90（29.0%）和 0.90-0.91（33.0%）之间——z 更接近显著。这意味着如果要找一个有统计意义的阈值，应该在 0.90 以下，而不是刚好 0.89。

**修正后的叙事**：0.89 不是在"惩罚切在错误侧"——而是切在一个没有统计显著录取率差异的密集区。任何硬阈值在这个密度的区域都会有类似问题。这进一步加强了推荐 #2（连续惩罚替代硬阈值）和推荐 #1（降到 0.87——那个区域的录取率确实显著偏低）。

### 🟢 无学校层级混淆

| Tier | N | Mean Sim | Admit% |
|------|---|---------|--------|
| C9 | 2,280 | 0.9051 | 39.8% |
| 985 | 12,699 | 0.9053 | 30.9% |
| Other | 41,453 | 0.9065 | 31.0% |

C9 和双非的相似度均值几乎相同(0.905 vs 0.907)——嵌入模型不会因为本科学校好就给更高的相似度。

### Dead Zone

- `<0.80` 的最大惩罚区：**0 个 case**
- `<0.85`：仅 1,377 个 case (2.4%)
- 28.7% 的 case 低于当前阈值 0.89

## 建议

1. **阈值下调 0.89 → 0.87**（一行改动，最高 ROI）。0.87 只捕获 bottom ~10%，这些 case 录取率确实明显偏低（27.2%，与 higher bins 的差异在统计上显著）。0.89 在噪音区——相邻 bin 录取率差异不显著。
2. **硬阈值改为连续惩罚**。0.17 的窄区间内硬切一刀本质上是不稳健的——0.89 恰好在分布最密集区。连续 sigmoid 惩罚更稳健。
2. **硬阈值改为连续惩罚**。0.17 的窄区间内硬切一刀本质上是不稳健的
3. **最大惩罚区从 0.80 → 0.84**（匹配 empirical P1）
4. **LLM pilot（可选）**：50 对专业，DeepSeek vs E5 相似度对比
